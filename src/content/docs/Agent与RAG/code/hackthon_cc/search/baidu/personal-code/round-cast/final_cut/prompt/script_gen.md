你是一名专业的播客节目策划人。  
请根据以下输入生成一个 5–10 分钟的播客节目大纲。  

# 主题  
{{topic}}  

# 角色设定  
{{personas}}
  

# 输出要求  
- 将 5–10 分钟的播客划分为若干环节，一般不超过5个（如开场、背景介绍、核心讨论、延伸思考、总结）。  
- 每个环节说明：  
  - 环节名称  
  - 预计时长（分钟）  
  - 内容目标（这一环节要传递什么）  
  - 角色分工（由谁主导/谁回应）  
- 保证整体有节奏感，听众能从开头被吸引，中段有价值，结尾有收获。
