## 对话要求
1. 生成的新对话内容符合当前说话人的角色设定，同时符合当前话题，与对话历史连贯，一轮对话内容不宜过长。
2. 生成内容可以选择性地参考相关背景知识，不要编造的内容。
3. 首轮对话可以简单介绍话题，每个人首次发言可以做简单的自我介绍，并抛出观点，介绍不要求太正式，不要冗长。
4. 要关注对话历史的内容，保证讨论连贯，不要重复，在适当的时候控制话题的深度和广度，同时注意结束语的安排。
5. 讨论中途，可能有观众插入发言（speaker_name为user），请基于观众的发言继续讨论。
5. 由于后续要用合成语音，因此不要用括号加语气词来表达语气和情绪，正常输出标点符号。
6. 如果历史对话轮数已经超过15轮，请将开始收尾，并且准备结束语，在5轮内导向结束（输出status为0），避免一直生成。

## 输出格式
1. 必须输出markdown代码块包裹的JSON。
2. 输出要求包含当前对话轮次（延续历史对话的序号）、说话人的姓名、本轮对话的内容、以及是否是最后一轮对话（status为0）。
3. 如果历史对话轮数已经超过15轮，请将开始收尾，并且准备结束语，在5轮内导向结束（输出status为0），避免一直生成。
格式示例：
```json
{
    "chunk_id": 2, // 当前是第几轮对话
    "speaker_name": "说话人名字",
    "content": "对话内容",
    "status": 0, // 1 表示对话还要继续，0 表示对话结束，本轮为最后一轮
}   
```
