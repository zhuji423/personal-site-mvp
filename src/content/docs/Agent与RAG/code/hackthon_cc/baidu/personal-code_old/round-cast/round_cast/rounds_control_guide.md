# 讨论轮数控制功能指南

## 🆕 新增功能

现在你可以控制AI播客生成的讨论轮数了！通过调整轮数，可以获得从简洁到深入的不同层次讨论。

## 📊 轮数说明

| 轮数 | 讨论深度 | 总发言数 | 适用场景 |
|------|----------|----------|----------|
| **1轮** | 基础讨论 | 6段发言 | 快速了解观点 |
| **2轮** | 深入探讨 | 9段发言 | 观点碰撞与回应 |
| **3轮** | 全面分析 | 12段发言 | 多角度深度讨论 |
| **4轮** | 充分辩论 | 15段发言 | 复杂话题全面剖析 |
| **5轮** | 极致深入 | 18段发言 | 研究级深度讨论 |

## 🚀 使用方法

### 命令行参数控制

```bash
# 指定1轮讨论（默认）
python test_demo.py --topic "AI对教育的影响" --rounds 1

# 指定3轮深入讨论
python test_demo.py --topic "AI对教育的影响" --rounds 3

# 使用简写参数
python test_demo.py -t "AI对教育的影响" -r 2
```

## 📁 文件命名

轮数信息会包含在文件名中：
- `20240824_154532_AI对教育的影响_1轮.json`
- `20240824_154532_AI对教育的影响_3轮.json`

## 🎯 使用建议

### 1轮讨论 - 适合快速了解
- 快速获取基本观点
- 适合时间紧张的场景
- 生成速度快

### 2-3轮讨论 - 推荐日常使用
- 观点充分碰撞
- 深度适中，信息丰富
- 平衡质量与效率

### 4-5轮讨论 - 深度研究
- 全面深入分析
- 适合复杂话题
- 需要更多处理时间

## 🎭 不同轮数的讨论结构

### 1轮结构
```
1. 主持人开场
2. 经济学家分析
3. 打工人回应
4. 主持人总结
```

### 3轮结构
```
1. 主持人开场
2. 第1轮：经济学家 → 打工人 → 主持人调节
3. 第2轮：经济学家 → 打工人 → 主持人调节  
4. 第3轮：经济学家 → 打工人
5. 主持人总结
```

## ⚡ 性能提示

- 轮数越多，生成时间越长
- 每增加1轮约增加2-3秒处理时间
- 建议使用2-3轮获得最佳体验
