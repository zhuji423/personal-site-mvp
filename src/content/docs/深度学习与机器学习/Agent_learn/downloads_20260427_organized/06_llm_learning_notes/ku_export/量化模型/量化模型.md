# 量化模型
什么是模型量化简单来说，模型量化（Model Quantization）就是通过某种方法将浮点模型转为定点模型。比如说原来的模型里面的权重（weight）都是float32，通过模型量化，将模型变成权重（weight）都是int8的定点模型。

为什么需要模型量化随着深度学习（Deep Learning）的发现，其在计算机视觉（Computer Vision， CV）和自然语言处理（Natural Language Processing，NLP）等领域都取得了巨大的成功。通过深度学习，我们可以得到用于处理各种任务的高性能模型，这些模型大多都很复杂、一般只适合在GPU上进行推理，并不适合在板端进行推理，然而在实际应用时，很多场景都需要将模型部署到板端。

为了解决模型难以部署到板端的问题，我们就需要通过模型量化来降低模型的复杂性，这个过程不可避免的会发生精度损失。

量化前的浮点模型和量化后的定点模型的特点：

| 量化前的浮点模型 | 量化后的定点模型 |
| --- | --- |
| 参数量大（float32） | 压缩参数（int8） |
| 计算量大 | 提升速度 |
| 内存占用多 | 内存占用少 |
| 精度高 | 精度损失 |

怎么进行模型量化模型量化就是建立一种浮点数据和定点数据间的映射关系，使得以较小的精度损失代价获得了较大的收益，要弄懂模型量化的原理就是要弄懂这种数据映射关系。
