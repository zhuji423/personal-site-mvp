# 激活函数
1、激活函数的作用激活函数的作用是将线性分布转化为非线性分布，能更逼近我们的真实场景。

2、常见激活函数| 激活函数 | 公式 | 图像 | 备注 |
| --- | --- | --- | --- |
| Relu |  |  | 在目前使用是最多的ReLU永远只在隐藏层中使用一般可以从ReLU激活函数开始，但是如果ReLU不能很好的解决问题，再去尝试其他的激活函数 |
| tanh |  |  |  |
| sigmoid |  |  | Sigmoid函数以及它们的联合通常在分类器的中有更好的效果由于梯度崩塌的问题，在某些时候需要避免使用Sigmoid和Tanh激活函数 |
| softmax |  |  | 二分类函数sigmoid在多分类上的推广Softmax在输出层中使用是比较完美的，这里通常是需要获得输入数据对应的类别的各种概率将多分类的输出值转换为范围在[0, 1]和为1的概率分布 |



使用最多的Relu优势他们在 x ->∞ 时，输出就变成了恒定值，因为求梯度时需要对函数求一阶偏导数，而不论是sigmoid，还是tanhx，他们的偏导都为0，也就是存在梯度消失问题，最终也就会导致权重参数w ， b 无法更新。相比之下，Relu就不存在这样的问题，另外在 x > 0 时，Relu求导 = 1，这对于反向传播计算dw，db，是能够大大的简化运算的。使用sigmoid还会存在梯度爆炸的问题，比如在进行前向传播和反向传播迭代次数非常多的情况下，sigmoid因为是指数函数，其结果中某些值会在迭代中累积，并成指数级增长，最终会出现NaN而导致溢出。
