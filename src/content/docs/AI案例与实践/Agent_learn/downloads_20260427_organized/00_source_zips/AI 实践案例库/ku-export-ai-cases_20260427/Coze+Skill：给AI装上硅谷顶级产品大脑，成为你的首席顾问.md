# **2. Agent Skills**
#### 2.1 什么是Agent Skill
如果把 AI 比作“大脑”，那么技能（skill）就是它所掌握的“专业工具箱”或“操作手册”。它让 AI 从单纯的“信息生成者”转变为“任务执行者，通俗点说，Skill 就是 AI 的“外挂”和“手脚”**。**

Anthropic 于 2025 年 10 月推出Agent Skills，12 月被确立为开放标准的 AI 智能体能力封装技术。其核心是通过 “渐进式披露” 架构与标准化封装，解决传统提示词工程的上下文污染、复用性差，以及 MCP 协议 “仅能连接工具、无法指导使用” 的痛点，实现从 “工具拼凑” 到 “技能原生” 的跨越。

字节Coze平台于1月中旬进行了重大更新和宣发，直接上线了skill商店，极大地降低了用户使用agent的门槛。Skills 的生态，比 Workflow 时期更加广泛与细微：

* **Workflow 时代，**需要拖拉拽节点、配置参数、设计分支逻辑。本质还是"编程"，拦住了一大波没有开发经验的用户。能做出来的东西，也受限于平台提供的节点类型。
* **Skill 则有着更低的门槛，与更高的上限。**任何人都可以用自然语言描述方法论，告诉 Agent 这件事怎么做、用什么工具、参考什么素材。甚至调用 API，也只需要在对话框里塞一份接口文档。Agent 会根据你的指引，自己判断什么时候用什么。

****

#### 2.2 Lenny's Skill
**💡Lenny's Skill** 实现了从“听播客”到“用播客”的范式转变。它把原本需要听几百个小时才能内化的知识，变成了一个**随调随用的技能包**。

它以全球排名第一的产品播客 **Lenny’s Podcast** 为底层语料，深度封装了数百位硅谷顶级产品负责人、创始人（来自 Airbnb, Figma, Uber, OpenAI 等）的实战访谈文稿。通过将这些非结构化的“大佬私房话”转化为可被 AI 调用的**原子化技能**，它成为了每一位产品经理、运营和创业者的“数字外置大脑”。

与普通的 AI 相比，Lenny's Skill 有三个不可替代的优势：

* **结构化（Structured）：** 播客内容是碎片化的，而 Skill 是结构化的。它把几百小时的对话提炼成了诸如“北极星指标定义”、“用户增长飞轮”等具体的参数和逻辑步骤。
* **确定性（Deterministic）：** 提示词有时会“幻觉”或跑题，但 Skill 设定了严格的输出边界。当你调用这个 Skill 时，AI 必须参考 Lenny 访谈嘉宾中提到的方法论，确保输出的内容与嘉宾思想观点相符。
* **可复用（Reusable）：** 你不需要每次都把 Lenny 的总结复制一遍给 AI。一旦发布为 Skill，任何人只要点一下“添加”，就瞬间拥有了顶级大牛的知识储备。
