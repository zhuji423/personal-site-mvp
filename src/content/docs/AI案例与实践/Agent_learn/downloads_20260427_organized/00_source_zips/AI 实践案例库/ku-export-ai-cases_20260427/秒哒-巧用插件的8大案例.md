# 一、案例广场
## **案例 1：教育在线作业与批改系统**
**场景背景**

在线教育平台希望学生上传作业后自动识别并生成解析，同时支持语音播报。

**使用插件组合**

|**插件名称**|**功能亮点**|**使用场景**|
|-|-|-|
|通用文字识别（高精度版）|手写作业识别|作业OCR识别|
|多模态理解大模型|作业解析生成|自动批改作业|
|长文本语音合成|作业解析语音化|朗读作业解析|
|文本生成大模型|作业反馈生成|个性化学习建议|

**功能效果**

1. 上传作业 → 自动识别手写内容。
2. 自动生成解析 → 输出步骤与答案。
3. 解析语音化 → 朗读答案提示。
4. 自动生成反馈 → 给出学习建议。

**query 示例**

```
@通用文字识别 上传作业图片 "math_homework.jpg"
@多模态理解大模型 分析题目 "math_homework.jpg" 并生成分步解析
@长文本语音合成 文本 "题目解析：第一步计算..." 生成音频
@文本生成大模型 输入 "学生作业答案与解析" 输出学习建议文本
```
## **案例 2：企业差旅报销自动化**
**场景背景**

企业差旅管理繁琐，员工提交票据报销流程慢，财务部门需要快速识别票据并自动生成报销记录。

**使用插件组合**

|**插件名称**|**功能亮点**|**使用场景**|
|-|-|-|
|汽车票识别|全国各种车票识别|差旅票据自动识别|
|火车票识别|红/蓝票及电子票识别|差旅票据自动识别|
|飞机行程单识别|多航班信息识别，高精度|差旅票据自动识别|
|出租车票识别|全国出租车票识别|差旅票据自动识别|
|网约车行程单识别|结构化提取金额信息|差旅票据自动识别|
|通用文字识别（高精度版）|高精度OCR识别|手写备注提取|
|企业三要素认证|核验企业信息|企业票据验证|

1. 上传票据图片 → 调用对应票据识别插件提取票面信息。

```

@网约车行程单识别 上传网约车行程单图片
```

**使用插件组合**

|**插件名称**|**功能亮点**|**使用场景**|
|-|-|-|
|图片生成与编辑（iRag / Nano Banana）|高质量图生成，风格转换|商品主图或创意图片|
|图生视频 / 文生视频|静态图或文本生成短视频|商品短视频制作|
|图像内容理解|多维度图像分析|自动生成标签或描述|
|通用物体和场景识别|识别10万+物体场景|自动标签推荐|
|文本生成大模型|文案生成|视频描述、推荐文案|
|微信支付|Native支付、二维码生成|商品购买|

**功能效果**

1. 上传商品信息 → 生成主图或创意图片。
2. 生成短视频 → 通过 @图生视频 或 @文生视频。
3. 图片内容分析 → 自动生成标签。
4. 文案生成 → 输出推荐语。
5. 用户购买 → 调用 @微信支付 完成支付。

**query 示例**

```
@iRag 文本 "生成一张红色运动鞋高清主图"

@图生视频 上传图片 "运动鞋主图.jpg" 文本描述 "展示运动鞋360°效果"
@文生视频 文本 "介绍运动鞋的轻便舒适特性" 视频风格 "短促宣传片"
@图像内容理解 上传图片 "运动鞋主图.jpg"
@通用物体和场景识别 上传图片 "运动鞋主图.jpg"
@文本生成大模型 输入 "短视频主题与内容" 输出推荐文案
@微信支付 生成支付二维码 商品名 "红色运动鞋" 金额 399元
```
