# 背景
在商业广告的流量争夺战中，风控始终扮演着“守门员”的关键角色。为了博取眼球和点击，部分广告主会不断试探底线，制造出各类擦边、虚假或诱导违规的内容吸引流量。而随着短视频与 AIGC 技术的爆发式增长，广告物料的数量呈指数级上升，违规手段也从单一的关键词、敏感图，演变为图文结合、隐晦暗示等更加隐蔽和碎片化的形态，给商业风控带来了前所未有的挑战。我们面临的首要难题，是风险内容的极度稀疏性与长尾分布。真正的底线风险只占极小比例，这些高隐蔽性、强对抗性的变种不仅难以收集，更让传统依赖大量标注数据的训练模式捉襟见肘。其次，风控的判罚标准常带有主观性和场景依赖性，难以统一，这不仅让机器难以拿捏，甚至在人审中也常常出现认知偏差，导致审核效率低下。

## 1.1多模态大模型为商业风控提供了新的选择
在过去为了应对这些挑战，我们采用以 BERT、ViT 等为代表的判别式模型范式。虽在特定任务上表现尚可，但本质上缺乏对风控知识的理解和复杂的逻辑推理能力。当面对长尾风险或需要结合上下文判断的隐晦内容时，这些小模型难以理解广告背后的真实意图，导致漏判或误判频发。而多模态大模型（MLLM）的出现提供了全新的技术路线。大模型涌现出的类人智能使其不再是机械地记忆规则，而是能够基于通用知识去理解广告背后的深层意图，进行复杂的逻辑推理。这种从“识别特征”到“理解意图”的范式转变，不仅能实现对长尾风险的精准打击，更能通过生成式能力为客户提供清晰的违规解释，提升商业体验。



本文将介绍我们在商业风控场景下，**如何利用多模态大模型完成这一技术跃迁：从破解高质量训练数据挖掘的难题，到设计生成与判别融合的训练范式以平衡效果与效率，再到重塑视频风控以应对视频场景下的新挑战，**我们将逐一拆解这套技术实践的完整链路。

# 2.商业风控场景技术实践
## 2.1 第一阶段：小试牛刀 - 多模态大模型训练数据挖掘与标注
如前文所述，风险内容在海量物料中呈现极度稀疏且长尾的分布特性，传统的纯人工标注模式，其核心痛点在于：

* 风险样本获取难（“找不到”）**：** 风险物料稀疏且隐蔽，人工审核如大海捞针，效率极低。
* 标注结论难统一（“标不准”）： 人工标注人员难以记住所有复杂的风控细则与尺度，不同人的理解偏差导致标注质量不稳定，且容易遗漏隐晦的风险点。

为解决人工标注困难的问题，我们结合了多模态大模型的理解能力与 Agent 的执行能力，构建了自动化、高效率的智能数据飞轮，让风险样本的获取与标注流程实现了质的变化。

目标： 解决风险物料难找到”问题

方案：将抽象的初级风控标准作为指令输入给大模型，由大模型自主拆解这些标准，形成一套更为全面的风险管控细则清单。对海量广告物料进行逐条内容细则判断，充分挖掘出潜在、隐蔽的风险问题

## 2.2 第二阶段：大刀阔斧 - 商业风控领域多模态大模型训练与优化
商业风控因其种类繁多、标准复杂多变，直接使用大模型无法满足业务上的准召要求。因此，在完成高质量训练数据构建后，我们开启了商业风控领域多模态大模型的训练与优化。在架构选型上，我们采纳了主流且高效的 Vision Encoder + Projector + LLM 结构，并在模型迭代中遵循了循序渐进的“三阶段训练范式”，以确保模型效果和工程效率的最优化。

### **2.2.1 风控领域知识注入**
为使大模型更好地理解商业领域关注的物料内容与潜在风险，通过继续预训练方式注入了大量风控相关的领域知识。这一阶段的目标是实现“双重对齐”：让模型注意力聚焦于易出风险的关键区域，同时补充商业领域知识。训练数据与任务可分为两大类：

    1. 风控场景图文 Caption ：我们借助开源大尺寸MLLM对商业物料进行自动化标注，但侧重于识别和收集具有风控特色的 Caption 数据。这种标注方式旨在对齐模型对风险描述的理解。在训练过程中，我们采取冻结 LLM、仅解冻 Projector的策略进行继续预训练，以确保视觉特征能够有效地与风控领域的文本语义空间对齐。

### **2.2.2 训练范式创新 - 生成与判别多任务联合训练**
风控模型的目标是识别风险类别，由于细分风险类别高达上百种，不可能针对每一种类别都微调构建一个模型。初期我们利用强大的CoT能力，将单一的风控任务分解为物料理解、风险点分析、风险判断等多个子步骤，通过CoT输出风险点来实现不同的风险类别区分。然而，在线审核场景中，生成式 CoT 推理面临资源消耗高和概率难量化无法灵活管控的问题。

为解决这一“效果与效率”的矛盾，我们探索并落地了两种训练范式：

 Post-CoT 训练范式：判断结果在前，思考过程在后

生成与判别多任务融合范式

该方法巧妙地将结果标签前置，CoT 内容后置，形成“先给出结果，后给出思考过程”的结构。

* 训练优势： CoT 依然作为强大的辅助训练信号存在，引导模型进行深入思考。
* 推理优势： 在线审核时，可仅推理结果标签（如 "违规" 或 "合规"），所需的 Token 数少；同时，风险概率可从结果 Token 的 Logits 分布中提取，完美适配在线低延迟需求。

该方法通过多任务学习进一步优化效率，在 Prompt 的末尾引入一个特殊的判别 Token（如 `<CLS>` 或 `<assistant>`）。基于该Token的 Embedding，外接一个 MLP 判别头，进行高效的判别式分类任务推理。

* 融合优势： 模型一方面具备生成式任务的深度理解能力；另一方面获得了判别式任务的极致类别拟合与高效推理能力。
* 在线应用： 审核时可分离判别任务进行推理，大幅提升速度，且能直接输出高度可信的风险概率。



在业务实践中，我们发现 Post-CoT 与生判多任务可结合使用，并取得了理想的准召和效率效果。① Post-CoT (先回答后解释) 在低延迟的“快思考”识别任务中，效果不弱于 Pre-CoT，尤其在小尺寸模型中，Post-CoT 能避免 Pre-CoT 在过度思考时产生的幻觉。② 生成和判别多任务联合训练，判别头输出提供更高的识别准召和更优的效率，而生成头输出则提供可解释的风控分析过程和理由。联合训练模型如下图：

### 2.2.3 多场景反馈对齐
风控场景数据的极端稀疏性，导致模型于在线真实分布上极易出现严重的 OOD (Out-of-Distribution) 问题，引发灾难性的误判放大效应。此外，持续性的客户对抗行为更是加剧了这一难题。黑灰产和恶意客户为了规避平台监管，会不断调整其物料形式，导致线上数据分布时刻处于动态变化中。

我们可用一个案例量化理解这一挑战：

|假设在 100 万条内容中，某风险仅占 0.1%（1000 条）。训练阶段，我们通过采样将训练分布中风险比例调整至1:5 ～ 1:20。在该设定下，即使模型在离线评估中有 99% 的识别精度，部署至真实分布后仍会产生问题：面对约 99.9 万条非风险内容，1% 的误判率将带来约 1万条误报（假阳性），远高于真实的1000条风险样本规模。这将导致风险预测集合中误报占主导，整体风险识别精确率降至 10% 以下。|
|-|

该问题的本质在于训练分布与真实推理分布的不匹配。为了有效解决这一问题，必须构建反馈机制，对其进行针对性的反馈对齐，从而降低误报提升风险识别的精确率。根据第二阶段构建的生成与判别多任务融合架构，我们设计了两种互补的反馈对齐方式：

|**1) 判别式反馈对齐**该方式专注于优化判别头的决策边界。**流程：** 持续收集线上误报的难负例数据（即模型错误判断为风险的正常物料）。对这些难负例进行精细化标注后，直接将其作为负反馈信号，通过增量学习对判别头进行训练。**效果：** 判别头能够通过这种直接监督学习，强化对非风险内容的判断，快速提升在线识别精确率。|**2) 生成式反馈对齐**该方式专注于优化生成头的思考和分析过程，使其输出更符合人类专家认知。**流程：** 生成式输出是一个长序列 Token，难以直接分配优劣的反馈信号。需借助强化学习算法来做反馈学习。我们实践了 DPO  和 GRPO 等算法，通过优化模型生成 Logits 概率分布的方式，将专家评判（如对分析理由的正确性、逻辑性）注入到模型中。**效果：** 能够更好地优化模型风控任务的分析理解，使模型生成的 CoT 理由更合理，进一步提升模型的可解释性和决策可信度。|

通过这两种反馈对齐策略的协同作用，我们有效地降低了风控稀疏场景下线上线下分布不一致问题，将模型的识别能力从“离线高召回”拉升到“线上高精确”，确保了多模态大模型在真实商业风控场景中的稳定和可靠性。

## 2.3 第三阶段：不破不立 - 基于MLLM重塑视频风控
广告视频物料因其复杂性，传统审核主要依赖人审为主、模型为辅。一般第一步先通过特定规则进行视频抽帧，第二步抽取的每一帧接入图片风控模型进行审核。随着AIGC兴起，视频物料增速迅猛，带来了两大核心挑战：

**1）资源瓶颈：抽帧带来极致的资源挑战**

* 为规避审核，部分广告主会刻意插入小于 1 秒的风险帧。基于规则的抽帧极容易对抗，但对于高FPS视频全抽帧则资源消耗线性增长

**2）风险升级：视频时序信息带来新风险类型**

* 图片风控往往依赖于静态特征（例如色情的皮肤裸露），而视频则需要分析时序信息（如柱状物抽插动作、女性身体连续大幅上下起伏/前后抖动动作等），单图模型由于缺乏视频的时序信息，难以发现动作违规行为。

应对上述挑战，我们基于MLLM重塑视频风控能力：（1）视频抽帧由规则升级为基于关键帧模型抽帧；（2）建设专用的视频片段理解模型

### 2.3.1 基于关键帧模型的视频抽帧
广告视频往往由多个片段裁剪拼接而成，镜头片段的一张关键帧通常足以代表该片段的有效信息。我们通过镜头切分模型处理视频，划分场景并从中选取最具代表性的**场景中间帧作为关键帧**，仅对这些关键帧进行多模态大模型审核。实测结果表明，该方法可有效将视频审核量**减少约 66%**，极大地节省了资源开销。

在实际工程化部署上，我们进行了深度优化：

* **视频抽帧缓存优化：** 我们将低分辨率模型切场景模块与抽帧缓存模块进行联合部署。仅对高分辨率关键帧进行缓存，减少重复计算。
* **多模态大模型推理加速：** 为获得极致的低延迟和高吞吐，我们将 MLLM 结构进行拆解重组
    * Vision Encoder + Projector 部分，单独转换为 TensorRT (TRT) 引擎进行部署。
    * LLM 部分则通过 TensorRT-LLM 框架进行量化加速。通过这种多模块分批部署和 C++ 引擎加速，最大化计算资源利用率，大幅提升了整体并行推理能力。


### 2.3.2 视频片段全模态风控
针对动作类风险频发的场景，为精准捕捉到连续动作类风险和音画联合风险，我们构建了针对视频片段的全模态理解模型。我们从视频审核黑库中，按风险发生的时间进行片段截取，构造出包含时间序列信息的视频段样本。通过自动化识别与人工辅助相结合的方式，高效产出高质量的视频片段数据集。通过Omni全模态大模型以视频多图序列和音频特征作为输入，进行端到端的视频任务训练，从而赋予模型在时间维度上的感知和推理能力。实测模型对涉及连续动作类风险的识别准召得到了大幅提升。

业务实践中，为减小视频审核大模型的开销，我们采用了分级预筛选机制：建设小尺寸高召模型对所有视频帧进行快速的场景预筛选，仅在高召模型判断为高危的行业或场景中，才接入视频大模型进行最终的精细化审核。这确保了在不牺牲关键风险覆盖的前提下，将大模型的计算开销控制在可承受的范围内。

# 3.总结与展望
展望未来，我们将专注于以下关键方向，推动智能风控的持续发展：

* **全模态技术探索：** 深入研究视频全模态大模型应用空间，包括对长视频中因果链条和复杂行为的精准捕捉，以及其agent能力建设。
* **智能标注自主演进：** 持续探索利用大模型的 Agent 能力，升级自动化核验能力，实现数据驱动下的风控知识库的自动化生成与更新，构建能够持续进化的物料标注系统。
* **智能审核 Agent ：**建设从数据挖掘、模型微调、推理决策、反馈验证等风控全流程的端到端自动化系统。

通过持续的技术投入和创新实践，我们坚信多模态大模型将进一步提升商业风控的效率和效果，为平台和商业生态的健康发展提供坚实保障。
