#  主题1  数字人视觉效果评估实践——卞新兵 
AI正逐步成为视觉内容质量评估、审核、质检领域的重要新质生产力。相较于传统人工评估方式，AI在视觉客观效果分析的多个维度上展现出显著优势，包括处理效率、量化能力、评估一致性及细节敏感度等方面。



* **高效性 **：AI具备并行计算与自动化处理能力，可对大规模视觉样本集进行实时或近实时评估，响应速度达到秒级，显著提升整体评估吞吐量与作业效率。
* **可量化性 **：AI能够将视觉效果评估转化数值指标，实现主观评估结果的客观化、标准化表达，有效避免主观判断带来的偏差与不一致性。
* **一致性 **：AI评估系统具有高度的行为稳定性与重复性，在不同时间点或不同批次任务中，其评估逻辑与输出结果具备良好的复现性，从而保障评估流程的可靠性与公正性。
* **敏感度 **：AI具备像素级或亚像素级的异常检测能力，能够识别出人眼难以察觉或需刻意关注才能发现的细微缺陷，显著提升视觉质量控制的精度与全面性。



AI不仅在视觉效果评估中提供了更高的效率和一致性，还通过精确的量化机制和卓越的细节识别能力，为视觉质量保障体系带来了前所未有的技术升级与拓展空间。

### 一、背景
视觉技术部一直深耕数字人的形象制作、驱动技术，支撑MEG电商慧播星、ACG曦灵等数字人平台建设。数字人的生产流程是一个复杂的多模态协同的过程，其中视觉效果是用户最直观的感受，如何去保障数字人视觉效果，做到视觉效果对齐人类偏好、效果可量化一直是QA的重点工作。

#  主题2  医生数字人播报内容评估——王雪琼 
### 一、背景
#### 1、内容生产
24年Q4启动医生数字人直播，整体创建数字人、开播等复用慧播星能力，健康侧生产直播口播脚本及直播间问答对，并做策略优化。

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=5dad3929293e46c0940d4db3721e9df1&docGuid=zosii3CfUc6G6C "")
后期优化思路：

1. **分章节式处理+模型训练：**短线生成脚本大纲->分章节生成->各章节衔接，最后拼接成一篇完整的脚本；样本积累完成后，通过SFT+DPO的方式一步输出脚本
2. **构建丰富的内容库**：通过优秀案例的拆解多场景脚本大纲（科普类、手术类、中医类、医美类）；通过医典、精编、医生笔记、病案等构建**内容库**。
3. **构建医学直播语料库**：通过书籍、精编、其他优秀直播内容将抽象的医学知识做通俗易懂的医学名称解释语料库。通过直播黄金话术模板：场景化痛点描述 + 情绪渲染 + 解决方案+互动指令，实现用户教育、医生信任塑造与转化闭环
4. 同时**先验+后验数据飞轮**：先验明确评估标准，不断更新标准，进行周例行迭代；同时通过后验的**数据飞轮**积累沉淀优秀的内容，生产更优质的脚本。

#### 2、内容评估
脚本&问答生产完成后，需要交付医学团队进行质量评估，人工评估主要从专业性，准确性，逻辑性，完整性，丰富性，拟人化，易懂性，感染力，时效性几大维度进行打分，根据实际分数分布，统计内容的合格率、可用率、优质率。



此环节纯靠人工逐个沟通，既费时又存在反复确认情况。随着脚本&问答数量激增，人力根本无法满足，所以希望脚本&问答评估能够自动化进行，提升评估效率。

### 二、评测方案
#### 1、大模型评测
对标人工评估，以现有制定的脚本&问答的评估标准为基准，将标准细化于prompt，以指导DS-R1执行自动评估。

```
    维度1：专业性<expertise>，判断给定的文本[input]无医学及合规红线。
    评分标准如下：
        2分：正确使用医学和健康领域的专业术语；引用的数据和内容来源于权威医学期刊、研究机构、官方指南或真实医疗实践，避免虚构信息。严格遵守相关法律法规和平台规定，确保内容合法合规。
        -1分：存在医学和健康领域的专业术语错误；或引用的数据和内容非来源于权威医学期刊、研究机构、官方指南或真实医疗实践，存在虚构信息。严格遵守相关法律法规和平台规定，确保内容合法合规。
    维度2：准确性<accuracy>，判断给定的文本[input]表达、观点、信息是否准确。
    评分标准如下：
        3分：无错字错音造成语义理解错误；对于尚未有定论或存在争议的话题，应客观呈现多种观点，避免给出绝对性或误导性的结论；正文紧扣标题展开，不存在跑题偏题、答非所问和遗漏；无夸大疗效（比如安全、疗效保证等词）、无个人吹捧内容。因果关系表述准确，例如：糖尿病是最常见的血糖元凶，就是因果关系表述不准确
        2分：无错字错音造成语义理解错误；对于尚未有定论或存在争议的话题，应客观呈现多种观点，避免给出绝对性或误导性的结论；正文内容存在跑题（核心回答之外的内容跑题），不影响理解；存在夸大疗效（比如安全、疗效保证等词）、个人吹捧内容，但控制患者疗效预期。
        1分：有错字错音造成语义理解错误。少量需要多角度分析的问题仅呈现单一角度但在安全可解释范围内。正文内容存在大篇幅跑题，影响理解，准确性无法验证；存在夸大疗效（比如安全、疗效保证等词）、个人吹捧内容，未控制患者疗效预期。
        0分：正文内容存在大篇幅跑题，影响理解，准确性无法验证；存在夸大疗效（比如安全、疗效保证等词）、个人吹捧内容，未控制患者疗效预期。
    维度3：逻辑性<logicality>，判断给定的文本[input]，内容是否连贯
    评分标准如下：
        3分：全文自然连贯，没有拼接感，口播通顺；主播表达清晰流畅；逻辑严谨，每个段落各有重点，相互衔接，共同构成完整的篇章，段落内讲述内容一致。
        2分：全文基本连贯，口播通顺；主播表达较为清晰，但少量逻辑不清晰或情节跳跃的情况，不影响整体理解
        1分：全文拼接感严重；存在口播突兀错字错音；主播表达混乱；逻辑不清，存在少量漏洞或矛盾，多个段落内讲述内容不一致，存在较多情节跳跃的情况。
    维度4：完整性<completeness>，判断给定的文本[input]，结构、医生介绍、讲解是否完整。
    评分标准如下：
        3分：结构完整：有明确的开头、主体和结尾，能看出直播主题；医生介绍完整：必要的医生介绍、背景知识介绍 或 直播未提供进一步专业咨询途径；讲解完整：对于复杂疾病或专业的话题，鼓励观众持续关注和自我管理；内容能从多个维度进行讲解（例如疾病简介、疾病成因、疾病症状、治疗手段、就医指导、患者案例等）
        2分：结构完整：有明确的开头、主体和结尾，能看出直播主题；医生介绍完整：缺乏必要的医生介绍、背景知识介绍 或 直播未提供进一步专业咨询途径；讲解完整：对于复杂或专业的话题，未进行讲解。
        1分：结构完整：没有明确的开头、主体和结尾；医生介绍完整：缺乏必要的医生介绍、背景知识介绍 或直播未提供进一步专业咨询途径；讲解完整：对于复杂或专业的话题。
        0分：明显未完成讲解
    在完整性<completeness>维度评估时特别注意：
        1. 若文本结尾出现明显截断（如末句不完整、话未说完），无论其他要素是否完整，均直接判定0分
        2. 完整结尾需包含：总结陈述+行动呼吁+合规免责声明（如'本直播内容仅供参考，具体诊疗请遵医嘱'）
        3. 必须验证文本是否包含所有标点闭合（如双引号、括号必须成对出现）
    [错误示例]
        结尾：中医讲究'上工治未病'，与其 → 完整性0分（结尾截断）
    [正确示例]
        结尾：与其等待疾病形成，不如提前调理体质。大家有任何问题都可以在评论区留言，我们下周同一时间再见！ → 完整性3分
```

### 三、实践中遇到的问题
#### 1、平台选型
刚开始调研大模型评估时，有一些标准化平台可选，比如灵境平台、健康内部的评估平台，但是由于平台本身的功能问题/模型固定/流程黑盒，对于我们这种

（1）对不同模型效果需要对比，切换尝试

（2）需要不断根据模型输出，调整prompt

（3）未产出评估结果时，方便定位查找原因

均不太友好，所以最终自己写脚本实现整个评估流程

#### 2、评估标准
标准毕竟是比较宽泛的，人工评估在标准的基础上，会加上个人经验值，不同人对于同一个脚本的打分情况也有出入，所以需要反复跟评估人员对齐，我们遇到的几种情况有：

（1）标准太宽泛，需要细化标准，占比30%

（2）评估人员打分标准有出入，占比20%

### 四、名词解释
**脚本：**即数字人阅读的文案，也是最终的交付物。

**主题：**也是脚本的标题，通篇脚本主要围绕主题来展开。举例：以【天天喝奶茶，真的会得糖尿病吗？】的主题脚本，主要围绕糖尿病的诱因和奶茶的关系，同时脚本的主线是糖尿病的相关知识科普。

**大纲：**整体脚本的结构，脚本的完整脉络，也是**脚本逻辑性和完整性**的体现。举例： 以【糖尿病真的那么可怕吗？】为主题的脚本，大纲主题主要围绕 糖尿病的【开场-病因-症状-就医-治疗-预后-日常护理】为大纲进行讲述。

**章节：**大纲中每一个部分称为章节，章节包含整个部分的所有内容，是以大纲部分进行的扩写，章节中包含了每个部分的所有的要素。举例：在【开场】章节中，包含【打招呼问好】-【介绍主题】-【主要痛点介绍】-【患病人群介绍】-【病案补充】-【鼓励安慰】-【互动】等要素

**要素：**脚本中最小段落的具体意图，用于丰富脚本；**要素的多少和深度，直接影响脚本的拟人化和易懂性**。举例：【医学解释话术】用通俗易懂的比喻来解释复杂医学概念；【焦虑话术】通过合适的话术制造焦虑情绪，提升用户关注度；

**知识：**脚本中严肃的医学知识，必须经过严格审核，**主要体现脚本的专业性和准确性**。

**话术：**脚本套路中的其他知识，优秀的【互动话术】、优秀的【引导转化话术】都是话术内容。

### 五、目标
数字人直播效果主要由三个层面影响，**脚本质量**、**直播间内问答质量**、**数字人形象**。

**脚本质量**：丰富高质的脚本内容结合数字人形象，吸引用户观看，最大限度的做到【聚客】+【留客】+【锁客】。让用户留存和转化更好

**直播问答质量**：直播间内自动回复。交互越活跃，侧面说明脚本和回答（主题）越吸引观众，影响用户交互满足体验和转化决策

**数字人形象**：包含直播间装修、数字人表情，动作，口型以及整体的协调性，目前主要由慧播星平台负责。

**终极目标**：让数字人直播的脚本质量、问答满足、数字分身形象，都能形成媲美医生真人的直播内容，促进数字人直播转化。

### 二、实践分享
#### 2.1 评估方式跟业务系统是共同发展的
我们发现，随着业务系统的发展，评估指标、评估方式也都会随着发展。

* 2023年Q4，问答系统刚搭建起来，我们关注的是端到端的问答回复率（“有问必答”）。
* 2024年Q1，我们开始针对性地做问答LLM的微调，关注的是端到端的问答可用率（“不能答错”）。
* 2024年Q2，我们希望数字人在互动时要更接近真人，所以关注的是端到端的问答优质率（“像真人一样回答”）。
* 2024年Q3，我们发现长尾问题答得不好，主要是由于商品信息的不足，所以开始从知识的来源、抽取、检索等上游环节进行优化，更多关注的是相关知识的召回率。
* 2024年Q4，开始分行业垂类的进行针对性优化，所以不同的行业垂类又有不同的可用率、优质率标准。

可以说，评估指标决定了业务系统的上限。

确定评估指标，针对性优化业务系统，在评估指标足够高（例如可用率85%->95%、优质率1%->85%）之后，切换到更合适的评估指标。

#### 2.2 如何更好地标注？
##### 1）有哪些错误是不能忍的？
PM、RD、标注同学，三方应该先对“哪些错误是不能忍的”这个问题达成共识，进而形成对单条结果可用性的标准。

数字人问答的可用性标准如下：

```
存在以下情况，为0分
1. 模型幻觉/虚构，如：回复完全没有依据参考信息、或与现参考信息冲突（含价格、赠品、规格等商品和直播间信息）；
2. 过度效果承诺，如：“明显好转、绝对有效、100%有效”等；
3. 命中违禁词文档，如：“最便宜”等；
4. 逻辑错误，如：“69.99是一套的价格哦，就是一件外套”等；
5. 违背常识，如：“18cm的身高完全没问题”等；
6. 信息模糊，如：“价格只要13.9元，而且现在还有半价优惠”等；
7. 答非所问，如：提问 ”有运费险吗“，回复”7天无理由退货”；
8. 过于书面，如：没有任何类似真人说话的语气词；
9. 添加备注，如：“家人们看这里（敲黑板）”；
10. 回复含有动作/商品演示过程，如：“咱这就穿上白色款”；
11. 预设身份，如：“这位姐妹说得好”、”哥哥们“，“我老公也是这个体重”等；
12. 回复不全，如：用户一个query内有两个提问，只回复了一个；
```
一般而言，可用性标准以“不能xxx”、“不可以xxx”、“禁止xxx”等形式提出，是对模型结果的明确约束，很容易达成共识。

一旦违反，我们认为整条结果是无法采纳、不能使用的。

##### 2）标注任务应该尽量“好标”
标注任务应该设计得尽量“好标”：标准清晰明了、符合直觉，不需要太多斟酌。

假如我们要对文章的质量进行标注，从难到易的做法依次是：

1. 这篇文章能打几分？
2. 这篇文章是否优质？
3. 两篇文章中的哪一篇更好？
4. 在口语化方面，两篇文章中的哪一篇更好？
5. 在口语化方面，同样是开头段落，两篇文章中的哪一篇更好？

把任务拆得越细，就越容易对齐标准，标注起来就越快。因为拆得细，所以可以清晰地指出模型在哪些方面做得不好，指引策略迭代方向；因为标准明确，所以后面让大模型自动标注的成本也相对较低。

在数字人问答的场景中，我们将优质的标准拆分为以下维度：

```
【口语化】
1. 减少书面语和AI感，善用形象易懂的话术、语气词和缩略句，更拟真
2. 上下文衔接自然
【内容丰富】
1. 结构清晰有逻辑，减少无意义的水话
2. 避免生硬的重复逼单，做到结合卖点、有理有据
【舆情应对】
1. 维护直播间气氛
```


##### 3）跟谁的偏好对齐？
在达到了可用的标准之后，用哪种方式给出的回答其实都是对的，下一步是怎样回答得更好。

但每个人对“答得更好”的理解是不一样的，这本质上是一个偏好对齐的问题。

总会有分歧的时候，分歧出现时需要总结出一般情况，然后讨论直至达成共识。——这也是实际中最花时间的步骤。

#### 2.3 LLM-as-a-Judge 是可行、有必要，且有用的
经过长期的实践，我们发现用大模型进行自动标注（即 LLM-as-a-Judge）是可行的、有必要的，而且有用的。

* 可行的：在经过上述对标注任务的分维度细拆之后，通过调prompt就能让大模型直接标注的效果达到75%~90%。
* 有必要的：像问答效果这样的任务，受标注人员的主观判断很大，如果更换标注人员，甚至只是同一个人过一段时间，标注结果都可能发生较大的变化，而用大模型进行标注则相对稳定。
* 有用的：目前大模型做偏好对齐主要基于RLHF（Reinforcement Leanring with Human Feedback）的技术范式，其中涉及奖励模型的搭建，需要大量的偏好对数据，这些数据可以通过 LLM-as-a-Judge 的方式得到的。

#### 3.1 基于DRML动态装配引擎实现数字人资产编排和动作切换

* 在提测人像所在环境数据库中，查询character_meta表的记录，可解析到人像的动作列表、资产列表、以及应用appid、appkey等信息
* 通过config_schema可以解析到人像资产配置的多项信息，如相机位、发型、服装、鞋履、妆容等，这些信息可用于资产组合的拓扑编排。

#### 3.2 基于图片理解模型实现数字人效果的自动检测
**3.2.1 数字人效果检测**

首先对输入视频进行逐帧解析，生成时序图像序列。参考《数字人视觉评测白皮书》中的人像效果标准，利用图片理解模型评估数字人的人像效果是否达标，最终生成包含合规性判定结果及详细评估依据

* 模型选定

试用了ERNIE系列模型、Qwen系列模型、InternVL系列、DeepSeek、Llama模型等图片理解类模型，Llama-4对3D数字人效果识别准确度相对较高，且支持自训练，所以选定模型为Llama-4-Maverick-17B-128E-Instruct

**3.2.2 效果检测模型召回能力评估**

*  生成数据集
