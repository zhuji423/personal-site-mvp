# 优秀案例之「TOR助理」
**助理背景：**面向BEP的产研（RD、PM、QA等）700人左右，提供测试流程管理、测试环节提效、质效工具建设等多个能力，已发布至超助、服务号&机器人场景。

##### **❌ 痛点及需求**
**多入口记不清：**日常工作涉及的服务或平台较多，寻址不便利

**沟通协作流程繁琐：**不同角色或跨业务协同时，高频操作的使用和沟通成本较大

**操作步长多**：不同的操作需要在不同的平台之间来回跳转，学习和适应成本高

**交互体验待提升**：往往需要记住特定的命令或者熟悉具体的操作流程，缺乏个性化的智能推荐和记忆功能

##### **✅ 达成效果**
**入口精简高效：**聚焦如流产品搞定常规任务操作，一次开发即无缝覆盖超级助理、如流服务号及如流机器人场景

**沟通协作提效：**在群聊中使用智能机器人交互，实现流畅互动，任务执行结果一目了然，大幅提升团队协作效率

**智能化交互体验提升：**通过LGUI的方式高效完成任务执行，支持澄清和智能工具选择，用户无需记忆特定的命令等

**个性化推荐：**结合用户的使用习惯，支持千人千面的相关问题和解决方案等智能化推荐

**业务收益：**TOR助理累计**孵化了100+项子能力**，企业效率平台产研累计**渗透率达60%**，**使用次数超过3.8万**，**节省步长超过9万**，**解放产研人力 1076人天，**在用户体验和提效方面获得产研一致好评。
