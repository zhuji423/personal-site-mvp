# ▷ 我们的团队
SEP PMO团队负责SEP重点项目管理，积极实践AI内化在项目管理全流程的提效，已沉淀出很多的实战经验，并且在持续实践中。

# ▷ AI赋能项目管理的核心价值
AI不只是一个提效工具，更是一次认知升级和能力扩展的机会，让PMO借助AI成为能力更强、边界更宽、创造力更高的自己。

#### 思维转变
AI先干原则——将重复性任务优先交给AI处理,人则专注于质量把控和最终结果负责,实现提效减负

#### 效率跃迁
效率的双重提升,不仅通过AI将原本一小时的工作缩短至10-20分钟,更借助如流与智能体的结合,打破物理工位限制,在移动场景下随时随地完成工作

#### 能力扩展
角色边界的消融,AI让PMO能够突破传统推进落地的角色定位,深入参与组织管理、研发活动等关键职责的全流程
