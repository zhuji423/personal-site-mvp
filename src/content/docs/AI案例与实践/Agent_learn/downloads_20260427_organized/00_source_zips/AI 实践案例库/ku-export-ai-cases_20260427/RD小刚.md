# **💡 什么是RD小刚？**
基于AI Agent搭建的大商业研发智能体，作为一个不知疲倦、经验丰富的RD，能够根据产品MRD中的需求编写业务代码并进行测试，帮助产品MRD快速落地*。

*注：当前版本仅支持凤巢MRD检索端骨架代码生成，其余功能会陆续开放。
