## 一、背景
2025年，Agent（智能体）爆发，Coding Agent（编码智能体）是落地最快、关注度最高的赛道，改写着软件开发的范式，不再是趋势，而是慢慢走进现实！



业界各公司都在积极拥抱Coding Agent，Q3 TSC执行网络正式启动落地，希望在Coding Agent优秀研发实践的同时，提升研发效率！

## 二、目标及要求
指标：Zulu渗透率** **=  Zulu使用用户数 / （Zulu用户数 + 提交代码但没有使用Zulu人数）

* **Zulu月度使用渗透率 > 50%**

对大家要求

* **编码场景的成员**，建议每月在实际的研发场景**使用Zulu > 10次**（基于**真实工作代码库**来深度体验）
* **体验意见记录**到[Zulu使用问题&实践案例记录](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/8MCddZCpuH/yu9spOzG0p/9nUwQi5hInMuAR?t=mention&mt=doc&dt=doc)：使用的问题、实践案例分享等

## 三、Zulu能干什么
Zulu本身是**泛用**的，并非针对特定的编程语言、框架、开发场景设计，**任何与项目和代码有关的诉求都可以尝试使用Zulu解决**。

*对比IDE的话，能实现文件管理(文件生成等)、文件检索、控制台、打开文件处理，总的来说编码最基础的它都可以。*

## 三、Zulu亮眼场景满足你的刚需
注：以下场景均基于『云一朵』项目

### 1.代码定位与分析
基于Zulu可以查找和读取代码的能力，对于“找到XX的实现代码”，定位更精准，且基于代码文件全文进行解读更详细。

Query:  项目中有一个关于调用NA端协议的文件，请帮我找到它并详细解释其使用的方式以及列举所有的端协议

[附件]
### 2.模糊问题的排查解决（如bug查找、性能优化）
对于“**只有现象，原因不明**”的问题，可以把现象描述给Zulu，由Zulu自己查找定位问题再进行解决。

Query:  页面在首次加载时较慢，影响了用户体验，需要优化首次加载的速度

[附件]
### 3.日志定位修复
在有明确错误日志（线上、构建都行）的情况下，Zulu可以准确地提取关键字去查找代码，再分析问题并进行修复。

Query:  这个项目在线上运行时出现报错，结合一下日志片段分析原因并给出修复建议

``` 

Uncaught TypeError: Cannot read properties of undefined (reading 'isHistory')

```

[附件]
### 4.参考已有逻辑实现新业务
基于已经有的一个功能模块，生成出一个新的模块，如历史记录页面 VS 其他新页面。此类“**有样学样**”是大模型最擅长的领域，**建议提供足够的关联文件供模型参考**，Zulu**不会局限于单纯的代码仿写**，还会扩展到如配置文件、添加依赖等工作，全方位地解决业务问题。

Query:  参考当前代码库的历史页面逻辑，帮我新增一个页面

[附件]
