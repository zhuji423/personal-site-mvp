# 一、背景趋势： 从 “工具辅助” 到 “产设研合一”：AI 驱动的产设研范式革命
在 AI 深度赋能下，产品、设计、研发的传统协作模式正在发生根本性转变。**从 Figma AI 设计生成、GitHub Copilot 代码补全，到企业级产研一体化平台的兴起**，AI 已不再只是单点效率工具，而是贯穿需求、设计、研发全流程的核心生产力，正推动原本割裂分散的产设研流程，向更智能、更连贯的一体化方向升级。围绕这一行业变革，新的工作模式正呈现出三大核心特征：

* **全链路一体化闭环**：将需求、设计、研发整合成连贯工作流，由 AI 全程串联，消除环节间重复作图、重复沟通，实现从需求到交付的无断点流转。
* **多角色融合协同**：打破产品、设计、研发的角色边界，各角色可在统一流程中选择适配自身的工作方式，独立推进并实时联动，一站式完成开发闭环。
* **设计语义与研发语言打通**：各角色共用一套结构化描述体系，设计资产可直接转化复用，无需额外转译与重新理解。以 Design Token 为核心的统一规范，正成为企业级产品实现 “设计即代码” 的底层基础，从根源消除视觉还原偏差与沟通成本。

# 二、两个技术路线： Figma Base & Code Base 
基于这一行业趋势，我们探索出了两套适配不同业务场景的 AI 产设研一体化工作流：** Figma Base & Code Base **AI创新工作流，实现从**需求输入 → Demo生成 → 代码提交**的全流程贯通，提高工作效率。Figma Base路线适合对体验精度要求高的项目，Code Base适合快速研发落地场景，可根据项目情况灵活选择。

# Figma Base 路线
以Design Token为统一语言，在Figma make设计工具中实现高保真原型、实现从需求到设计再到代码一站式产出的全链路工作流

特点

**深度体验设计 / 高还原度 / 高复用度 / 协作灵活 **

# **Code Base 路线**
以研发代码为统一语言，在 IDE 中通过 AI 生成规范代码的研发直出型高效工作流,

代码复用率达100%生产级

特点

**轻体验逻辑简单 / 聚焦快速落地  / 代码直出**



适用场景

**0→1 全新项目，设计主导、多方案快速对比，全流程设计体验完整可控**

适用场景

**支持 0→1 / 1→N 迭代，产设研协作从跨角色流转到单角色闭环**



Figma Base 为设计主导型路线，核心适配 0→1 全新项目，具备视觉高度可控、多方案快速对比、全流程设计体验完整的优势，是打磨极致用户体验的核心抓手；Code Base 为代码主导型路线，既支持接入 Design Token 实现 0→1 快速出码，也可通过克隆代码仓库，完美适配 1→N 存量迭代项目，代码兼容性与工程适配性更强，是研发侧高效落地的优选方案。两条路线各有侧重、优势互补，可根据项目对设计可控性、迭代类型、操作体验的需求灵活选择，全面覆盖全场景设计研发需求。目前两条路线均已完成多业务案例落地实践，在交付效率与交付质量上均实现了跨越式提升。

# 三、Figma Base 工作流全链路
Figma Base 是设计主导型全链路智能工作流。它以 Design Token 为核心底座，在 Figma Make 设计工具中打通「需求输入→高保真原型生成→体验精准调优→生产级代码一键导出」的完整闭环，实现从设计到开发的一站式高效产出，完美适配对体验精度要求高、需极致打磨的 0→1 全新项目。其核心思路与全链路流程如下：

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=09fd758c5c6c4b80a2edf622ad240ba0&docGuid=NNPYiqU6fFxUsH "")


* **搭建阶段：构建 Design Token 统一设计底座**

以 Design Token 为核心的设计底座是Figma Base 整个工作流的根基与约束核心，对色彩、字体、间距、组件等视觉属性做语义化抽象并与代码变量一一映射，形成标准化可复用规范体系，为 AI 生成提供统一约束，实现设计研发资产共用、全局可控、样式一致。



* **产品阶段：生成高保真 Demo，完成从 0 到 1 的快速验证**

AI 基于 Design Token 设计底座的约束，通过自然语言需求直接生成高还原可交互 Demo，无需手动绘制原型，快速验证需求，从源头保证规范统一，减少样式偏差与返工。



* **设计阶段：体验设计智能调优，精准校准设计还原度**

AI 自动完成代码清洗、结构优化与规范对齐，将生成的 Demo 代码适配团队的设计标准与工程规范；设计师仅需聚焦核心环节，高效校准交互逻辑与视觉还原度，完成体验细节的精细化打磨。



* **研发阶段：生产级代码无缝交付，打通设计到开发的全链路**

依托在设计底座中前置的代码规范 Rules 与 Comate CR 能力（涵盖代码规范、业务逻辑、风险防控），从源头保障代码质量；结合 Skills 智能优化，进一步优化代码结构、性能与可维护性。一键导出代码即可直接对接研发工程体系，大幅缩短产品交付周期，实现设计与开发的无缝衔接。



## 什么是以 **Design Token 为核心的**设计底座？
设计底座是将设计规范转化为可被 AI 直接消费的**代码资产（Design Token）**，搭配**使用指南（Guidelines）**用于约束 Figma Make 的生成结果，使其输出符合设计规范的样式和生产级代码

**设计资产代码化（Design Token）：**

将颜色、字号、圆角、组件等视觉样式抽象为具备设计语义的代码映射，实现设计与代码共用一套语言。一处修改即可全局生效，大幅提升迭代效率

🤔 **多端适配（H5、Web、iOS、安卓）场景下，设计底座是否需要多次修改？**

✅ **无需多次修改。**设计师仅需维护一套 Figma 设计底座，Figma Make 生成代码后，多端适配难题由** Comate AI IDE团队研发的 Comate F2C相关技术**提供核心支撑。可通过 Figma Make 转代码插件，将生成的代码一键转换为 H5、Web、iOS 原生各自适用的代码结构，实现多端高效复用。后续也邀请各业务线参与跨框架场景的效果验证，进一步释放多端提效潜力。

✅ **可实现多角色高效协同，**彻底消除跨角色沟通内耗。两条路线均构建了完善的协同机制：Figma Base 路线按项目沉淀 **Figma Make 智能模板**，产、设、研共用同一套模板协作，所有变更实时同步、全局可见；Code Base 路线按业务维护专属代码分支，各角色克隆仓库后，仅需拉取最新代码，即可同步最新 Demo 与工程文件，大幅提升协作效率。
