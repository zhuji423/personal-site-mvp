#  主题1：语音TTS客观化评测探索与实践——马晨 
## 一、背景&目标
### **1.1 传统人工听音评测**
* 评测需求多，吞吐低：PM评竞品，RD评迭代效果，QA测效果
* 对听音人员的专业基础素质的要求：对音频需要从以下几个维度进行评估

|检查项|检查内容|
|-|-|
|音频质量|音频是否为静音；音频声音是否有杂音（背景音，嘈杂声音），音频声音是否有尖锐的声音等|
|合成内容|多音字读法是否正确，情感标签发音是否正确|
|音色、语调、语速|同一个发音人调整音色，语调，语速参数，输出音频是否正确|
|情感、流畅度、相似度|开心，平静，伤心等语气是否符合语境，说话方式是否自然流畅、是否与真人具备较高的相似度|

### **1.2 最新TTS自动评测**
* 探索使用自动化评测方式代替传统人工听音的评测方式提升TTS的测试效率，实现0到1的突破。针对TTS合成的前、后端分别做自动化评测建设，对前端问题进行提前拦截，避免向后传播。同时结合业务特殊性做定制化适配。

## 二、解决方案
在语音合成技术中，主要分为语言分析部分和声学系统部分，也称为前端部分和后端部分。

* 语言分析部分主要是根据输入的文字信息进行分析，生成对应的语言学规格书，想好该怎么读；
* 声学系统部分主要是根据语音分析部分提供的语音学规格书，生成对应的音频，实现发声的功能。

### 2.1 前端评测能力构建
#### 2.1.1 评测项
* **TN：中文转换错误、英文转化错误**
* 符号 → 忽略或转义（"￥99" → "九十九元"）
* 英文缩写 → 单位读法（"cm" → "厘米"）
* **注音：多音字、儿化音（未读/错读）**
* 多音字 → 语义感知（"银行行长讲话了" → "银行 *háng* 长讲话了"）
* 儿化音 → 口语自然度（"去哪儿" → "去哪 *nǎr*"）
* **韵律（停顿）：符号停顿作用是否生效，词边界、词内停顿是否合理（1->3：短停顿->长停顿）**
* 农民1只要1向1村里1申请了1宅基地3，并且1手里面1有钱3，那么3想1啥时候见2就1啥时候见3，而且1在1建房1标准上3也1没有1太大的1要求。

#### 2.1.2 评测方案
* 前端引擎可测性改造，实现前端TN转写结果、多音字注音、韵律停顿信息的输出
* 对比标注结果使用WER工具计算TN以及多音字的准确率
* 通过检查停顿标志是否出现在词间实现韵律结果初筛

### 2.2 后端评测能力构建
#### **2.2.1 评测项**
[流程图]
**主观层评测项与传统评测方法**

* **流畅性评估**：评估生成语音是否具备平滑的节奏，避免出现不自然的停顿或语速变化。
* **情感度评估**：
    * 情感准确性评分：评估生成语音是否成功传达了指定的情感类型。
    * 情感丰富性评分：评估系统是否能有效地表现复杂或微妙的情感变化。

* **相似度评估**：
    * 音色还原度：声音音色（音调、音色质感等）是否像原声
    * 风格还原度：说话时表达方式、口音、语气、语调、停顿习惯等是否像原声


常见传统人工评测方法主要包括以下2种：

* **两两对比评测**（PC：Pared ComParison）：要测试的系统两两比较，也就是常用的ABX
* **主观印象打分**（MOS：Mean Opinion Scale）：事先给定打分规则，对每一个分数给出明确的定义，给出有限个数的得分，听音人根据自己对输出系统的主观印象打分

|**情感表达**|**OpenSMILE**|一个广泛使用的音频特征提取工具，适用于情感分析和情感识别。|提供多种音频特征提取方法，适用于情感表达和识别任务。|提取音频的情感特征，分析语音中的情感表现。|

## 三、一些思考
### 3.1 评测过程一点经验
**评估方案设计**：端到端评测视角是必须考虑的评测视角，从线上用户视角出发才能获取到用户关注的场景和体验。这种获取的评估结果对产品而言可获取持续优化/打磨的方向。

**评测效率 & 准确率**：评测的效率 & 准确度决定了AI应用的迭代速度 & 质量。评测准确度取决于评测数据集的质量，需要根据任务具体要求去设计。

**客观评测工具**：客观评测工具建设是非常重要，不仅可以提升评估效率，也可以帮助模型快速发现优化方向。

### 3.2 语音模型发展趋势对评测的思考
当前多数SOTA模型已经实现多模态深度融合能力，后续可能会实现语音、文本、图片甚至视频的端到端模型，**实现多模态上下文混合评测**可能是一种趋势。

当前TTS生成音频不论是在语调、节奏和语气等方面越发拟人化表达，目前大多数都主观评估实现，但如何**将情感表达拟人度实现准确的客观评测**是必须要解决的难题。
