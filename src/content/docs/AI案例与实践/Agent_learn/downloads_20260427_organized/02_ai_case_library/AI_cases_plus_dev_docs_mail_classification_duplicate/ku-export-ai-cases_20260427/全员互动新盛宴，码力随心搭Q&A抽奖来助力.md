## 全员大会（Q&A/抽奖）系统
**该项目旨在为2025年****SEP&TMO全员****会H2提供Q&A/抽奖系统解决方案，参会****规模高达1000+人**

交付周期缩短22（30->8）人天，节约业务人力5人天，系统已作为标准化模版上线，上线两周内已复用2次

##### **方案提供方**
码力随心搭

##### **服务用户**
SEP&TMO全员

##### **业务场景**
2025年H2的SEP&TMO全员会中，运营组提出需要覆盖1000+人的Q&A和抽奖系统，其中Q&A系统支持全员会会前问题收集、问题点赞，会中TOP3问题展示与回复，会后问题回复（管理员的权限）、答案展示、回复通知以如流工作卡的形式推送给提问人。而抽奖系统支持全员会现场6轮抽奖，且所有人不可以重复中奖，支持会后中奖名单导出。

##### **解决方案**
Q&A系统

包括「提问页面」、「问题广场（可点赞、展示问题与回答）」、「管理后台」等功能，为Leader配置管理员权限，可对所有问题进行回复，回复通知以如流工作卡的形式推送给提问人，提问人点击可跳转至所提问题和答案界面。

抽奖系统

包括「礼品遮挡页」、「多轮抽奖」、「抽奖过程交互」「管理后台」等功能，配置不可重复中奖规则。
