前沿论文速递：WebRPA助力BIT AI技术社区内容升级

#### 🧑‍🏫 案例作者：[@郭静](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：知识加工、办公
#### 🔧 使用工具：AI Spider WebRPA
#### 📒 案例概要：BIT团队新增arXiv抓取渠道，结合Web RPA自动抓取并解读前沿大模型论文，实现选题、解读、发布全流程自动化，助力AI社区内容升级，年节省运营人力60人天，获业务方认可。
**背景：**为扩大前沿技术论文的服务范围，并确保其分发的及时性，BIT团队新增了arXiv官方抓取渠道，以弥补原有UGC渠道覆盖力不足的问题

**解决方案：**基于Web RPA能力，定期甄选最前沿的大模型论文，并以专家视角进行解读，帮助用户高效掌握核心观点、快速追踪技术前沿，实现论文选题、解读、发布全流程自动化；同时，补全AI社区内容供给能力，节省运营人力 60人天/年。获业务方总监 Luna 金花感谢。

部门：技术中台群组/技术管理部
