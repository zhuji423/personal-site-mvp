**完整产品Demo搭建：**分步骤多轮输入，每一轮输入以 **“1个初始Prompt+多个子Prompt” **的形式搭建一个页面或功能，效果更可控，最终通过多轮输入组合成一个完整产品

# 实战技巧分享
**Prompt 工具化：**

结合已有视觉样式库，通过 Prompt 明确指定设计语言；逐步建立团队 AI Prompt 模板

**整理设计文件：**

从设计稿转原型时，先整理设计文件的结构、命名和自动布局设置、清理无用图层，可使输出结果更好

**探索式原型设计：**

用 Figma Make 快速构建多个方案，可以进行快速 AB 测试与视觉表达比较



**可编辑性是关键：**

生成结果需手动微调，避免“一次生成就完事”，确保可控制性。

**团队协作融合：**

产品、设计、开发可同步体验交互效果，跨角色协作更自然。



**鼓励大家先用起来——多探索、多尝试，AI 的价值在动手实践中才能真正释放！**

# 常见问题及解决方案
|**问题**|**可能原因**|**解决方案**|
|-|-|-|
|**断点改动不生效**|改错了尺寸 / 样式被覆盖|在对应断点下修改并确认保存|
|**布局错乱**|Auto Layout 规则冲突|检查父容器布局模式|
|**字体不一致**|未统一 Styles 或缺字体文件|建立全局字体样式库|
|**发布后加载慢**|图片过大 / 动画过多|压缩资源，减少复杂交互|

**域名相关**

可绑定公司的域名，Professional Plan 专业版只能绑定 10 个/账号，Organization 组织版和 Enterprise Plan 企业版无限制，采用 cname 解析方式，还自带 SSL 证书
