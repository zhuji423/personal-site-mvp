# **扫地僧**
#### 是一位专注于「业务代码清理」的数字员工。
#### 他可以清理遗留的老代码、老配置、老词表、老测试用例等，
#### 支持 CR 自动生成、测试全流程托管，减少研发人力投入。
# 1 背景
业务快速迭代过程中，遗留了非常多的废弃代码。这些废弃代码**拖慢编译速度**、**占用线上资源**、**增加业务理解难度**。为了不让编译拖慢研发、测试速度，维护线上稳定性，使业务良性发展，商业历年都会开展代码清理活动，专门投人力删除废弃代码。

专门投人力清理代码，挤占了部分研发时间，大家积极性一直不高。早期，也曾探索过自动代码清理，但复杂、多变的代码逻辑，让规则不断膨胀，难以覆盖所有场景，缺少放之四海皆准的、可落地的自动清理方案。随着 GenAI 时代的到来，让我们看到了自动清理的曙光。大模型强大的代码理解能力，少样本学习能力，让代码清理从「人清」跨越到「机器清」，促进了扫地僧的诞生。

# 3 产品
依托如流机器人、工作卡、侧边栏等开放能力，我们推出了扫地僧（ai_saodiseng@baidu.com）数字员工。解析用户清理请求，创建需求卡片，自动生成清理 CR，追踪、推进测试和评审流程，统计清理效果数据，更好地为研发服务。当前扫地僧可以清理以下代码：

* 开关、插件、dag 结点
* 孤儿变量、函数、类型
* xbuiltin 词表
* xbox 词表
* CTS 功能测试 case、lib、配置和词表
* 线上配置和词表

# 4 效果
9 月生成 935 个 CR，合入 408 个，一次通过率 **68.93%**。月吞吐是真人的 **30 倍**，代码变更行数是真人的 **5 倍**。

相关经验推广到「besas 拆分词表 proto」和「词表智能 proto 识别」项目。
