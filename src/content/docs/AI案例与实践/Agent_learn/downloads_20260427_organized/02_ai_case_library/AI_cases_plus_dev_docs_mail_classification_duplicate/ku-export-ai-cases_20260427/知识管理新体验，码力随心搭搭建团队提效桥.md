## MEG-知识管理系统
**该项目旨在知识沉淀场景提供通用解决方案，本次覆盖****MEG区域直销部****高达1000+****业务人员**

该系统由业务同学借助码力实现快速搭建，用于提升客发与运营团队的沟通效率，业务成本节约**396人天/年**，研发成本节约**4.5人日**(8->3.5)；系统已于 12月17日全量上线。

##### **方案提供方**
码力随心搭

##### **服务用户**
 MEG区域直销部

##### **业务场景**
MEG区域直销部，营销服务联络中心负责中小客户的开发和维护，当前是以电话营销为主要的客开方式客户体量大，为了提高效率，使用数字员工进行客户外呼和意向挖掘。而数字员工模型的沟通能力依赖知识的供给，但是大量的实战经验、客户洞察和成功话术知识沉淀在一线业务，需要建立知识供给机制，辅助模型训练。因此期望为知识沉淀提供通用解决方案。

##### **解决方案**
* 知识沉淀系统与如流侧边栏绑定，方便一线业务人员快速提交知识。
* 实现“提交-整理-审核-采纳-点亮”全流程闭环，并且审核同学通过后业务同学能收到消息。
* 全员可以看到知识广场、排行榜，方便激励业务同学沉淀知识。

##### **前后对比**
**优化前**

一线业务人员将知识零散沉淀到如流群。收集人员在知识库中集中汇总，并且筛除低质量知识，导致人工成本比较高

[流程图]
**优化后**

一线业务人员直接在如流群中打开系统，提交知识，管理员审核采纳，并且针对高质量知识进行点亮，在知识广场中显示。
