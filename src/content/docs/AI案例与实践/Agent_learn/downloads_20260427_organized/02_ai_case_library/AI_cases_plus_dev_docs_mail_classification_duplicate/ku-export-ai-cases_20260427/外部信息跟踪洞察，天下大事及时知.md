外部信息跟踪洞察，天下大事及时知

#### 🧑‍🏫 案例作者：[@郭静](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：办公、通用
#### 🔧 使用工具：数字员工
#### 📒 案例概要：针对人工整理信息效率低且深度不足的痛点，利用 AI 智能体 实现了全平台信息的自动化采集与深度分析。
**外部信息跟踪与洞察工作流：**针对人工整理信息效率低且深度不足的痛点，利用 AI 智能体 实现了全平台信息的自动化采集与深度分析。

        * **信息采集基座**：已接入微信公众号、小红书、推特等主流平台，支持指定网址、博主及主题的定向跟踪与抓取。
        * **智能处理引擎**：基于智能体技术，可对上万条信息进行自动理解、筛选与生成，目前已落地MEG地图、ACG市场、HR COE和PR等部门**热点追踪、竞品监测、趋势洞察、选题策划**等多类场景。

    * **案例：**
        * **ACG市场－行业动态监测数字员工（** [日报看板](https://medii-carol.github.io/news/newskanban.html#s=&q=)**）：ACG市场**团队日常需高频完成新闻追踪与日报整理，原流程依赖专人从多个渠道手动搜集、编辑，平均耗时**3–4小时/天**。通过数字员工方案，实现了对上百家行业媒体与网站的自动抓取，并智能完成信息去重、分类与摘要处理。实现全流程智能化与自动化；所有日报均以结构化形式存档，为后续的专题汇编、趋势分析与知识复用提供了基础
        * **HR COE****－****AI*组织*People行业资讯****：**针对组织发展、人才培养等相关领域的公众号内容进行自动抓取与总结，提供AI *组织 *People行业资讯的聚合分析服务。计划从下周一开始，以周报形式推送至Nina（罗郁）及其下属团队。
