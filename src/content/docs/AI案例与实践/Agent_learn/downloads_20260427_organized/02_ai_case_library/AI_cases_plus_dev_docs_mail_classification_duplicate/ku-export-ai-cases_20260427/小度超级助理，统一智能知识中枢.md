## 小度超级助理
该项目通过数字员工，打通跨部门、跨业务、跨模块的信息壁垒，预计可为业务节省人力120人月，显著提升组织协同效率与知识流转效果。

小度同学的全能工作搭子：知识 + 数据双智能中枢一体化，一步直达，高效智能办公。

##### **方案提供方**
数字员工

##### **服务用户**
小度全体员工

##### **业务场景**
销售团队在日常工作中需频繁处理知识检索、信息查询与销售操作执行等，当前支持手段零散、流程割裂，导致操作效率低、学习成本高、支持人力投入大。

* **知识分散，难以获取**

业务流程、产品信息、政策细则等多业务知识散落于多个平台、多个团队、文档与IM记录中，缺乏统一查询渠道，导致销售在关键节点难以及时获取准确信息。

* **操作入口受限，流程复杂**

核心销售订单查询操作需在PC端多个系统完成，流程入口深、操作繁琐，且移动端无法支持，销售在外无法高效处理，效率与体验受限。

* **数据获取成本高**

小度数据团队沉淀了海量的数据资产，散落在多个平台的海量报表中，查数找数看数困难；用户没有开发能力获取数据难；已有SQL脚本无法复用，开发效率低。

##### **解决方案**
* **智能知识中枢**

全面覆盖小度**销售、财务、电教、硬件**四大业务方向下的 **40+ ****子领域**，累计沉淀知识内容 3**000+ ****篇**，涵盖大量表格、图片（如设备参数、操作说明书等）等非结构化知识载体。当前整体问答准确率达 **93.67%**，有效支撑一线业务高频、复杂问题的快速解答。

打通多系统数据壁垒，实现 “输入一个关键词（如订单号、手机号），关联查询全链路信息”，减少跨平台操作成本，一键获取订单&仓储等信息，业务快速定位数据效率提升**70%。**

* **智能数据中枢**

基于「**CBI 智能问数能力**」，接入平台销量、订单明细等 **6 大类核心业务数据库**，覆盖数据记录 **3480 万+**** 条**，支持通过自然语言对 **54 类****核心指标口径**进行实时查询，显著降低数据获取与分析门槛，让数据真正“用得起来”。
