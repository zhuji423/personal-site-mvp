## query设计思路
为了让模型准确生成你想要的应用，请在 Query 中同时包含以下几个关键信息点。

1. **页面创建**

-新建一个页面，命名为 “简单小测 · 直达你所热爱”

-问卷采用 5个页面 / 分页展示 的形式，每页只显示一道题。

2. **问题与选项配置**

-共5个问题，问题为单选

-每一页包含：问题文本、A/B/C/D（部分为A~E）选项

3. **页面跳转逻辑**

-点击选项，跳转至下一题

-“返回上一题”按钮，返回至上一题，展示第一题的页面“返回上一题”按钮隐藏

-提交，最后一题点击提交

## query示例
```
请为我搭建一个名为 “简单小测 · 直达你所热爱” 的问卷页面，功能需满足以下要求：
1. 页面创建
- 问卷采用5页结构，每一页仅展示一题。
- 页面标题固定为：“简单小测 · 直达你所热爱”。

2.问题与选项配置
- 请依次设置以下 5 道题，每道题为单选：
- 题目示例：
- 第1题：今年大会你最期待的内容是？
- A.百度大模型与AI应用最新进展
- B.AI应用展区的真实体验与互动
- C.AI公开课系统学习实战方法论与案例
- D.覆盖AI最热议题的分会内容详解   
- 第2题：您对哪个AI领域最感兴趣？
- A. 基础大模型开发，如训练、推理等
- B .领域专有模型微调、精调等
- C .智能云基础设施
- D.AI应用开发工具与平台
- E.热门AI应用: 如数字人 智能体 AI搜索 具身智能  无人驾驶等     
- 第3题：您认为AI 在工作中适合扮演什么角色？
- A. 高效执行者（精准完成指定任务）
- B. 灵感激发者（提供创意方向）
- C. 专业协作者（在专业领域提供深度建议）
- D. 全能生产者（从零到一独立开发应用）  
- 第4题：您最希望AI为您处理/提供哪类内容？
- A.结构化内容（如报告、代码、数据）
- B.创意性内容（如文案、故事、诗歌）
- C.多媒体内容（如图片、视频、音乐）
- D.信息性内容（如摘要、翻译、问答）
-E.商业性内容（如报告、计划书、应用）
-第5题：您日常使用AI的主要场景是？
-A.技术研究开发
-B.生活娱乐陪伴
-C.商业能力拓展
-D.工作技能提效
-E.个人兴趣爱好

3. 页面跳转逻辑
- 每题页面底部需包含：
- “返回上一题”按钮（第1题隐藏）
- 点击选项
- 点击选项：保存当前题答案并进入下一页
- 第5题将“下一题”替换为“提交”按钮，点击后保存全部答案，进入下一流程
```

## case4：自定义参观路线
![](/personal-site-mvp/img/doc-placeholder.svg "")
## query设计思路
填写 Query 时，请确保同时覆盖以下维度，这样模型才能按照你的真实场景生成对应应用。

1. 打卡站点状态

-“已打卡”、“打卡”、“等待解锁”

2. 路线推进逻辑

-用户点击“打卡”后，该站点变为“已打卡”，并自动解锁下一站点为“打卡”

-所有站点完成后，出现最后一个“领奖处”，状态为“已解锁”

3. 进度显示规则

-显示总打卡站点数量、完成打卡自动更新进度数字、完成所有打卡点领奖解锁

## query示例
```
请为我在“个性化打卡地图”页面配置打卡路线逻辑，要求如下：

1. 打卡站点状态
- 每个打卡点需支持 3 种状态，并按顺序逐一解锁：
- 已打卡：已完成打卡，
- 打卡：当前可打卡站点，
- 等待解锁：后续站点未解锁

2. 路线推进逻辑
- 第一个站点默认状态为“打卡”，其余为“等待解锁”
- 用户点击“打卡”后，该站点变为“已打卡”，并自动解锁下一站点为“打卡”
- 所有站点完成后，出现最后一个“领奖处”，状态为“已解锁”

3. 进度显示规则
- 顶部显示“已打卡 X / 总站点数”
- 每次打卡成功后，自动更新进度数字
- 若全部完成，显示“已打卡 7/7 个站点”并解锁领奖
```
# 如何按时间自动切换文案
前言：当你在搭建活动系统时，需要在不同时间节点向用户呈现不同按钮文案（例如开场前显示“敬请期待”，到点自动切换为“立即入场”），甚至是其他模块的展示文案，这个案例都能为你提供可复用的实现思路。

## case5：到指定时间，自动切换按钮展示文案
![](/personal-site-mvp/img/doc-placeholder.svg "")
![](/personal-site-mvp/img/doc-placeholder.svg "")
## query设计思路
编写 Query 时，请将以下内容同步写入，这有助于模型做出更精准的推理与生成。

1. 设置按钮的初始文案内容，右侧按钮为"预约直播"。
2. 设置预约直播按钮到时间变换文案：

-在11月13日12:00之前，文案为"预约直播"

-在11月13日12:00后，文案为"观看直播"

## query示例
```
请按照以下要求完成页面按钮设计及功能设置：

1. 按钮文案
- 设置首页区域按钮文字内容：
- 右侧按钮："预约直播"

2. 动态功能实现
- 时间触发条件：当系统时间达到11月13日12:00时
- 动态变更内容：将右侧按钮文字从"观看直播"自动变更为"观看回放"
- 变更方式：无需用户操作的前端自动更新

请提供完整的HTML/CSS/JS代码实现方案，包含：
- 按钮的DOM结构
- 样式定义（包含渐变边框实现代码）
- 时间判断逻辑
- 动态文字变更函数
```
