# 🧩 高频率场景提效 tips
### **新人视角：拥有 24 小时在线的“数字 Mentor”**
* **场景：** 刚入职的小 A 面对满屏的百度黑话（如：MEG、度宇宙）和复杂的行政政策（如：青松计划、育儿假）一头雾水，想问 Mentor 又怕耽误对方时间。



* **提效实操：**
    * **【搞定公司福利政策】**：例如“请介绍一下青松计划”、“育儿假怎么申请？”、“百度内推的奖励机制是什么？”、“简单币如何获取？”、“2026 新春礼盒包含什么？” 
    * **【查询企业知识/行政】**：例如“PaddlePaddle深度学习平台官网是什么？”、“工卡丢失如何补办？” 、“公司体检可以带家属吗？怎么加项？”
    * **【秒懂企业内专词（黑话）】**：例如“希加加是谁？”、“什么是度宇宙？”、“百度总监会是什么”、“MEG 是什么？”、“SO&BPIT 是什么？”
    * **【寻找业务接口人】****：**“内搜的业务负责人是谁？” 、“随心搭的负责人是谁？”、“超级助理的负责人是谁？” 




* **结果：** 无需翻阅海量**知识库文档**，一句话直达答案，快速度过入职迷茫期 。

### 职场老兵视角：打通信息孤岛的“提效黑科技”
* **场景：**资深百度人每天穿梭于数十个项目和如流群聊中，信息不是太少，而是太碎片化。当需要复盘三年前的老项目、查阅复杂的报销策略、或者在 5 分钟内看完全球行业报告时，传统的翻找方式效率极低。



* **提效实操：**
    * **【多维精准找文档】**：“找一下张三去年在如流xx群聊里发给我的技术文档”  、“找一下 XXX 编辑的关于 XX 的文档” 、“找一下我上周阅读过的文档”
    * **【长文档智能阅读】**：（**上传文件后或者粘贴知识库链接**🔗提问）例如“帮我总结一下这篇文档第三章的核心结论” 、“帮我解释一下这个架构图里的逻辑” 
    * **【职场沟通润色】**：（上传文本后提问）“帮我把下面这段话的语气调整得更严谨专业” 、“润色，将下面这段话语气调整为更轻松”




* **结果：** 秒级唤回文件，告别在如流聊天记录里反复横跳的痛苦 。

# 🛠️ 超级助理 AI 搜索进阶 SOP
在发起搜索前，先判断你的需求属于以下哪个维度，以选择最精准的提问方式：

* **企业知识类**：涉及福利政策、黑话缩写、行政财务流程。
* **文档检索类**：涉及项目方案、技术文档、会议投屏。
* **任务/接口人类**：涉及 iCafe 进度、业务负责人 。

### 
* **PC 端**：如流搜索框右侧图标或内搜 AI 模式 。
* **移动端**：如流底 Bar 中间或右侧图标 。

拒绝宽泛的关键词，采用“**核心动词 + 关键信息 + 补充限定**”的公式。

* **找文档**：`找/搜索` + `[主题/文件名]` + `[XXX编辑/分享的]` 。
    * *示例：找张三上周在如流xx群聊发给我的文档。*

* **问知识**：`请介绍/如何/什么是` + `[业务名词/流程名]` 。
    * *示例：请介绍一下青松计划。*

* **查系统**：`查询` + `[iCafe/应用名]` + `[状态描述]` 。
    * *示例：查我负责的未完成的 iCafe 卡片。*


搜索不是终点，利用 AI 能力进行信息深加工：

1. **秒读摘要**：对于长文档，直接追问“帮我总结核心结论” 。
2. **专业润色**：将草拟的回复交给助理，指令为“风格改为严谨专业” 。
