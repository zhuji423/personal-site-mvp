## HR-年节礼品信息收集系统
该项目支持公司内全员完成26年年节礼品信息收集，包括礼品申领、催办通知、库存管理、发货物流号通知等，整体复用25年节礼品申领应用，复用率95%。

该系统通过低代码平台研发成本节约44人日（50->6)，提效88%；系统已于 10月30日一期上线，交付周期缩短21人天。

##### **方案提供方**
低代码

##### **服务用户**
百度全体员工

##### **业务场景**
支持HR业务完成26年年节礼品信息收集，包括礼品申领、催办通知、库存管理、发货物流号通知等。

**方式转变：**传统年节礼品信息收集，HR需跟各个部门负责人联系，通过Excel等形式收集信息，人力投入大，效率低下。

##### **解决方案**
复用年节礼品信息收集系统标准化模板，微调后实现交付使用，复用率95%。

**优化前**
