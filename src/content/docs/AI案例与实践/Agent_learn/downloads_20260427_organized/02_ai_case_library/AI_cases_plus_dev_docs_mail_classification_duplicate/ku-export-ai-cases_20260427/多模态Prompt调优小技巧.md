# 🎯 第一部分：核心理念（Know-how）
## ✅ 本质是什么？
> **Prompt 是你与 AI 沟通的语言，它既是“指令”，也是“画面”或“声音”的剧本。**
## ✅ 核心 Know-how（三句话）：
1. **输出质量 = 输入指令的清晰度 × 想象力密度**
2. **AI 不会“推理意图”，你不说清楚，它就胡猜**
3. **每一种模态都有“可控变量”，掌握变量 = 掌控结果**

## ✅ 万能提问法：
> 每次写 Prompt 之前，先自问五个问题：
* 我想生成什么内容？（类型）
* 想传达什么感觉？（情绪）
* 主体是谁？在哪里？在干嘛？（构图）
* 呈现的风格是什么？（风格）
* 有哪些细节必须被看到或听到？（细节）

# 🧠 第二部分：三大模态 Prompt 技巧 + 中文示例
## 一、📷 图像生成 Prompt（Stable Diffusion / DALL·E / Midjourney）
### ✅ 核心理念：
> 图像生成的 Prompt 就是**摄影构图说明 + 美术风格建议 + 情绪氛围描述**。
### ✅ Prompt 核心结构：
**主体 + 动作/状态 + 场景 + 风格 + 光影细节 + 分辨率**

### 📌 中文示例：
```
一位白发老人在山顶晨雾中静坐打坐，身披深灰色长袍，四周环绕松柏，柔和阳光穿透雾气，国风水墨画风格，高清，细节丰富
```
### 🪄 实用关键词模板：
* 风格：油画风、水彩画、吉卜力风、3D渲染
* 光影：柔和光线、逆光、高对比、散射光
* 细节：超清画质、超高细节、特写镜头、大景深



## 二、🎧 音频生成 Prompt（音乐 / 语音 / 声效）
### ✅ 核心理念：
> 音频 Prompt 是**“声音氛围描述 + 节奏结构 + 声音元素”**的组合，类似为 AI 作曲或配音写一个简洁的脚本。
### ✅ Prompt 核心结构：
**类型 + 情绪 + 节奏 + 风格 + 声音元素**

### 📌 中文示例：
```
一段轻柔的钢琴独奏，带有温暖的感情色彩，节奏缓慢，适合夜晚冥想，加入背景雨声和微弱风铃声
```
### 🪄 实用关键词模板：
* 类型：lofi、轻音乐、电子、古典、氛围音乐、BGM
* 情绪：平静、忧郁、兴奋、梦幻、温暖
* 元素：鼓点、合成器、鸟鸣、风声、人声采样、低音



## 三、🎬 视频生成 Prompt（如 可灵、即梦、Sora、Runway、Pika）
### ✅ 核心理念：
> 视频 Prompt 是**导演语言 + 镜头调度 + 画面风格**的脚本描述。
### ✅ Prompt 核心结构：
**主角 + 动作 + 环境 + 摄影风格 + 镜头语言 + 时间设定 + 特效要求**

### 📌 中文示例：
```
一位穿着未来战甲的女子在废墟城市中奔跑，黄昏时分，慢动作镜头，镜头跟随，光线从破碎大楼间穿透，赛博朋克风格，电影质感，高清
```
### 🪄 实用关键词模板：
* 摄影语言：慢动作、航拍、跟拍、远景、第一人称
* 风格：科幻、写实、动画、油画、黑白电影
* 特效：爆炸、雨雾、镜头抖动、光晕、虚焦

# 🧩 第三部分：模态共通的 Prompt 高阶策略
## ✅ 1. 层级式构建法
用多个短句分层表达，而非一长句。

> **错误写法：**
> 一个男人站在桥上忧郁，光线很好，情绪挺感人。


> **优秀写法：**
> 一个男人站在一座老旧的桥上，低头沉思。
> 秋日傍晚，阳光微弱，洒在他发上。
> 画面色调偏暖，情绪哀而不伤，仿佛在回忆往事。
---

## ✅ 2. 拓展 Prompt 的四个方向（加词方法）：
* **加人物设定**：性格、身份、装束（如：冷酷的赏金猎人、温柔的村姑）
* **加时间线**：白天、夜晚、黎明、未来、古代
* **加风格调性**：浪漫主义、写实主义、恐怖片风格
* **加感官描述**：声音、光线、温度、色彩

---

## ✅ 3. 参考黄金 Prompt 模板：
```
[主体] is [动作], in/on/under [场景], with/in [光影或情绪氛围], in [艺术/摄影风格] style, [分辨率或镜头技术], [额外细节]
```
```
一位[身份+描述]，正在[做什么]，场景位于[环境]，伴随[光线/情绪]，整体为[风格]，画面为[画质/镜头技术]，并包含[其他细节]
```
---

## ✅ 如何速成
1. **建立高质量 Prompt 笔记库**：收集 + 模仿 +改写
2. **每种模态都写10条 Prompt 作业**：风格各异，尝试极限
3. **把 Prompt 结构化为组件**：写成模版 → 每次只改部分
4. **对比实验法**：一条 Prompt 改一个词，看结果变化 → 提升感知力
