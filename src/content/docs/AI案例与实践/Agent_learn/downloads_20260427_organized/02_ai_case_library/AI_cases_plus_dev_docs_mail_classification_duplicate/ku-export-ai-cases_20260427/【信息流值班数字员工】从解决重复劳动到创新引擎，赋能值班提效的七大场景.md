你是「信息流智能值班机器人」，核心职责是根据用户输入的关键字/关键信息，精准、高效检索指定知识库内的文档资源，为用户快速定位所需信息，替代人工检索的繁琐流程，保障知识获取的及时性与准确性。

1、键字解析能力：能精准识别用户输入的核心关键字（含专业术语、业务名词、文档相关特征词等），可自动过滤无效冗余信息（如语气词、重复表述）

# 输出格式
输出相关的文档链接地址和文档摘要信息

1、不具备文档内容修改的能力，仅专注于 “检索 + 结果呈现 + 检索优化建议”；

![](/personal-site-mvp/img/doc-placeholder.svg "")

# 01  @mcp.tool
**FastMCP 框架的核心装饰器**，用于将普通 Python 函数注册为 MCP（Model Context Protocol）协议支持的 “工具”（Tool）



@mcp.tool(

    name="calc_cpc",# 自定义工具名称（默认用函数名）

    description="计算广告 CPC（单次点击成本），单位：元",# 自定义参数描述（优先于函数文档字符串）

    parameters={"spend":"广告总花费（单位：元）","clicks":"广告总点击量"},

    tags=["广告指标","成本计算"],# 工具分类标签（方便LLM筛选）

    auth_required=False, # 是否需要身份验证（默认False）

    examples=[{"inputs":{"spend":1000.0,"clicks":50},"output":20.0},{"inputs":{"spend":800.0,"clicks":1},"output":800.0}]  

)

# 02  @mcp.resource
`mcp.resource` 是 FastMCP 框架中与 `mcp.tool` 并列的核心装饰器，用于将 **只读数据源** 封装为 MCP 协议支持的 “资源”（Resource）



@mcp.resource(

    name="ad_account_budget",

    path="/ads/account/budget",# 自定义路由路径，未配置则用name作为

    description="查询广告账户的可用预算（敏感数据）",

    tags=["敏感资源","账户数据"],

    auth_required=True# 开启身份验证)

# 03  @mcp.prompt
`mcp.prompt` 是 FastMCP 框架中专门用于 **封装可重用 LLM 提示模板（Prompt Template）** 的核心装饰器。它允许开发者将自然语言提示（Prompt）定义为结构化、参数化的模板，并将其注册为 MCP 协议的一部分。





@mcp.prompt

def product_promotion_creative(

    product_name: str,

    key_features: list[str],

    target_audience: str,

    tone: str = "专业且热情"

) -> str:

   return f"""

    你是一位经验丰富的社交媒体内容创作者。

    请为以下产品创作一篇吸引人的推广文案：



    产品名称：{product_name}

    核心功能：

    {chr(10).join([f"- {feature}" for feature in key_features])}

    目标受众：{target_audience}

    文案语气：{tone}

    """
