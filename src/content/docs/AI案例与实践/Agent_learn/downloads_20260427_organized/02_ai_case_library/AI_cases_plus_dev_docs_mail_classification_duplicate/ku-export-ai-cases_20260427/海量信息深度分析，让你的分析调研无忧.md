海量信息深度分析，让你的分析调研无忧

#### 🧑‍🏫 案例作者：[@郭静](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：通用、办公
#### 🔧 使用工具：数字员工
#### 📒 案例概要：这是一个信息深度分析智能体，当前，厂内存在大量调研分析任务，面对上万条海量且复杂的信息进行用户调研、需求调研和舆情分析等。
## **信息深度分析智能体**
当前，厂内存在大量调研分析任务，面对**上万条**海量且复杂的信息进行**用户调研、需求调研和舆情分析等。**

##### **方案提供方**
数字员工

##### **服务用户**
全员

##### **业务场景**
通过数字员工深度思考Agent，结合任务特点调度指定Skill，通过自主分析数据特征➡️智能进行信息过滤清洗➡️自主训练专项模型进行数据标注➡️并设计对应的聚类、分析等算法，并可自主迭代优化；此外，还支持生成网页、图表等呈现形式。这一过程大幅提升了数据处理的效果、稳定性和执行速度。

##### **解决方案**
* **PR-舆情分析：**基于百度相关事件及行业热点动态，需要快速、精准地分析**上万条，上百万字**媒体报道和相关用户评论。在**事件脉络梳理**和**媒体观点分析**方面，我们的解决方案显著优于之前的供应商，提升了处理效果和速度。此外，智能体还能够提供**用户评论的深入洞察**，解决了之前无法处理的问题，帮助团队迅速制定有效的公关方案。。
* **HR-简单小考主观题分析****：**每期需对超过**3万条、累计超350万字**的主观题反馈数据进行深入分析。目前，该分析流程主要依赖人工操作，周期长达**3-4天**，存在处理速度较慢和主观影响结果准确性的问题。通过数字员工的信息深度分析Agent，支持自动化处理标签分类和数据深度分析的能力，实现分析的高效性和结果的客观性，并且支持不同组织层级的专项分析和横向对比。
