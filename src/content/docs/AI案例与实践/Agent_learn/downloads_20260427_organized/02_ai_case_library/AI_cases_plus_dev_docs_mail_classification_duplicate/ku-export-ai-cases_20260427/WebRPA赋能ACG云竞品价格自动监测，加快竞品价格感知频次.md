## ACG云竞品价格自动监测
**为****ACG云竞品****价格监测提供解决方案，实现对****华为云、火山云、百度云、腾讯云、阿里云等各产品价格试试监测，提升ACG云产品价格竞争力**

已复用覆盖7条产品线、20个竞品的44条任务流，日均更新4.6万条价格数据，加快竞品价格感知频次季度→日

通过 RPA 实现复杂网页信息监测，日均更新4.6万条价格数据以提升价格竞争力，同时达成63%的研发提效，且支持MEG/ACG/SLG等多业务场景。

##### **方案提供方**
AI Spider WebRPA

##### **服务用户**
ACG运营与产品管理部

##### **业务场景**
ACG云竞品价格通过人工（产品运营）方式从各个竞品页面获取价格信息，存在人力消耗大、效率低、结果产出周期长，无法及时感知竞品价格变动等问题。

##### **解决方案**
基于WebRPA的复杂网页操作能力，实现云竞品价格的天级自动查询，解决竞品价格人工监测效率低的问题（手工整理数据→自动获取），赋能加速价格决策、支撑提升公有云价格竞争力；已复用覆盖7条产品线、20个竞品，日均更新4.6万条价格数据，加快竞品价格感知频次季度→日
