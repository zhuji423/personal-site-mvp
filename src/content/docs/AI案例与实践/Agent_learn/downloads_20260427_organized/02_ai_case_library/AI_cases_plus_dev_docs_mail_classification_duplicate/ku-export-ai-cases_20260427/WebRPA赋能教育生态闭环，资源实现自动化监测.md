WebRPA赋能教育生态闭环，资源实现自动化监测

#### 🧑‍🏫 案例作者：[@郭静](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：信息洞察、知识加工、数据分析、工作流自动化
#### 🔧 使用工具：AI Spider WebRPA
#### 📒 案例概要：WebRPA自动化监测希沃白板K12课程体系与资源，年化节省人力1117.2人天，监测可可英语内容节省83人天。助力百度教育优化产品、丰富素材库，构建学生-家长-教师生态闭环，赋能业务线内容智能分发。
### **MEG百度教育K12课程自动化监测（希沃白板）**
**MEG百度教育竞品K12课程体系自动化监测（希沃白板）--12.29上线**

* 基于WebRPA自动化能力，实现对外部成熟教育平台（希沃白板）K12课程体系的自动化监测，助力百度教育优化完善新旧产品体系与架构；同时，联动在行项目的课程及试卷资源自动化监测，共同支撑业务端丰富自有教育资源素材储备，构建学生-家长-教师完整生态闭环，赋能百度教育全业务线内容智能分发与价值释放。
* 收益：课程体系自动化监测（希沃白板）：年化节省业务人力27.2人天（13.6人天*2次/年）；共计26171个叶子节点，每分钟人工可处理4个叶子节点（点击，下展，录入，切换），纯人工需要6542分钟，约合工时109h，13.6人天



**MEG百度教育K12课程资源自动化监测（希沃白板）（移动生态事业群组/*/搜索产品部/*/教育B端业务组）--2.11上线**

* 基于WebRPA自动化能力，实现对外部成熟教育平台（希沃白板）K12课程资源的自动化监测，预计年化创造1090人天的新增生产力（104684个ppt*5分钟），助力业务构建教师群体使用的一站式教师专用素材库，构建学生-家长-教师完整生态闭环，赋能百度教育全业务线内容智能分发与价值释放
* 收益：课程资源自动化监测（希沃白板）：年化节省业务人力1090人天，26171叶子节点（平均每个子节点4个PPT）,每个PPT人工截图保存约需5min

**MEG百度教育专项练习（可可英语）内容自动化监测（移动生态事业群组/*/搜索产品部/*/教育B端业务组）--2.14上线**

* 基于WebRPA自动化能力，实现对外部成熟教育平台可可英语分级读物、有声名著等内容的文本及音频文件自动化监测，预计年化创造83人天人天的新增生产力，助力业务丰富英语学习资源，提升用户留存及时长等指标；
* 收益：共计节省业务人力83人天，全部内容共计2万章节*2min（查询，点击，下钻，复制，下载，录入，切换等）
* RD人力投入：6.5人天，包括：任务流搭建5人天，解决下载文件带特殊符号导致下载失败等问题；业务联调1.5人天
