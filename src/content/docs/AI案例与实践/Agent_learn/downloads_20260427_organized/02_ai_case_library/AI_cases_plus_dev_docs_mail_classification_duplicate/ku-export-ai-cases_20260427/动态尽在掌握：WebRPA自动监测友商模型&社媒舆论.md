动态尽在掌握：WebRPA自动监测友商模型&社媒舆论

#### 🧑‍🏫 案例作者：[@郭静](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：信息洞察、工作流自动化
#### 🔧 使用工具：AI Spider WebRPA
#### 📒 案例概要：WebRPA自动化监测系统上线，实现竞品模型社媒舆论（X/Reddit/小红书）自动追踪及友商人才招聘动态监测。通过拟人自动化操作替代人工收集，年化节省人力57人天，提升信息获取效率，为业务决策提供实时数据支持。
**竞品模型社媒舆论追踪自动化监测（3条任务流）****--****1.14已正式上线**

* **背景**：基于WebRPA拟人自动化操作能力，针对目标网站，实现所需字段的自动爬取和录入数据表，改变原有需要人工手动收集录入的流程，实现新发布模型社媒舆论信息的快速自动获取，为后续趋势分析、调研报告等输出提供原材料，刷新并提升高价值结论产出频次、产出效率。
* **收益**：基于WebRPA的拟人自动化操作能力，实现竞品模型社媒（X/Reddit/小红书）舆论追踪自动监测，分析模型实测效果与市场影响；助力业务信息收集由“人工收集→自动监测”工作范式改变，为业务决策与战略研判提供实时数据支持，年化节省人力27人天（1.5人天*18次/年），

**友商人才策略洞察****（5条任务流）****--****1.12已正式上线**

**需求背景**：目前业务需要持续关注友商（字节/openAI/Anthropic/腾讯/阿里等）相关岗位的招聘动态，用于：竞品团队动向分析、人才策略与岗位趋势研判、内部战略规划输入

解决方案：基于WebRPA的拟人自动化操作能力，实现自动监测头部厂商（字节/阿里/腾讯/OpenAI等）人才动态，辅助挖掘竞对在模型/Agent/产品/战略等方向的高价值信息，年化节省人力30人天（2.5人天*12次/年）
