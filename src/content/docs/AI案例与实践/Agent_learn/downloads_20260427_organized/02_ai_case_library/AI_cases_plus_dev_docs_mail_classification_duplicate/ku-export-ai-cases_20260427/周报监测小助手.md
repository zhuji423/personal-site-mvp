周报监测小助手

#### 🧑‍🏫 案例作者：[@毕晶晶](https://ku.baidu-int.com?t=mention&mt=contact&id=422c2e80-f2cb-11f0-80f0-91056ee5134c)
#### 🎬 案例分类：通用
#### 🔧 使用工具：AI Spider WebRPA、知识库随心搭
#### 📒 案例概要：通过WebRPA和知识库随心搭搭建「周报监测小助手」，以项目维度，从周报中获取不同角色周报内容并自动总结进展，作为了解内部业务的核心渠道，将分散的周报内容总结为结构化的项目信息，替代原有低效的电话、消息确认模式
# 👉 基本信息
项目名称

**周报监测小助手**

所属团队/BU

**安全与企业效率平台/运营管理二组/安全战略**

方案提供方

**随心搭+WebRPA**

# 📌 **目标及价值**
---

**目标：「以项目维度」，从周报中获取不同角色周报内容并自动总结进展，作为了解内部业务的核心渠道**

* WebRPA：负责按筛选条件获取周报数据
* 知识库随心搭：负责内容的呈现及总结



**价值**

* **周报信息整合：**分散的周报内容总结为结构化的项目信息，用户可自行定义输出格式
* **项目进展交叉验证：**对BU重点项目及工作多负责人周报的自动交叉验证、多视角补充与智能总结，替代原有低效的电话、消息确认模式

# 📌 **适配业务场景**
---

* **战略/业务分析：**自上而下，关注项目整体进度、产研及商业化情况，通过内部进展挖掘外部竞品分析视角
* **项目管理：**自下而上，关注项目中子项目的进展、风险及执行情况
* **业务角色（产研/销售等）：**拓宽业务视角，将不同角色工作与项目关联起来，从全局视角了解进展

# 👉 方案内容及试用指南
* **项目定义：**自行定义，设置项目关键词、项目目标
* **时间范围：**当周、近1周-4周，支持多选
* **目标对象/角色：**支持添加「有权限」查看周报的用户、设置分组
* **处理指令：**支持自定义输出指令，如内容呈现、格式要求、人员范围要求等，常用参考模版如下
