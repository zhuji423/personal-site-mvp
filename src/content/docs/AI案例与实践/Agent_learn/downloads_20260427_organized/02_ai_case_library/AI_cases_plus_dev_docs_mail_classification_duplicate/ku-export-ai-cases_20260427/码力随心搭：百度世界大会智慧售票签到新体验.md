码力随心搭：百度世界大会智慧售票签到新体验

## 大市场-2025百度世界大会售票签到系统
**该项目****旨在为百度世界大会提供客邀、对外售票、签到、数据分析等全流程功能需求**

本次大会方案通过标准化能力复用，复用率达90%，**交付周期缩短53.5人天（70.5→17）****；**支持业务实现**大会规模8000+**内外部参会人员现场签到顺利完成，其中购票人员200+。

##### **方案提供方**
低代码

##### **服务用户**
内外部嘉宾

##### **业务场景**
* 百度世界大会作为公司年度最高规格的对外盛会，其会务系统的稳定性与流畅性直接关乎百度对外的企业专业形象。
* 当前会务流程在嘉宾邀请、票务管理与现场签到等环节仍依赖多系统与线下人工协同，存在数据不一致、效率低、统筹难度大等问题，影响整体运营效率与参会者体验。

##### **解决方案**
* **嘉宾邀请&对外售票**：构建一体化嘉宾邀请与对外售票系统，实现线上邀约、票务发放及管理的全流程支持。
* **座位管理&现场签到**：支持大会现场座位分配定制化配置及扫码签到。
* **现场技术保障机制**：组建现场支持团队，制定应急预案，11月13日大会期间派驻3人提供全程技术保障，确保系统稳定、问题实时响应，关键环节零风险交付。
