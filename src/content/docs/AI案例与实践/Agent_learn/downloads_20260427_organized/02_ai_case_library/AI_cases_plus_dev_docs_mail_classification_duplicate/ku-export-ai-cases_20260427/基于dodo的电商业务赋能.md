#### 🎬 案例分类：数据分析
#### 🔧 使用工具：dodo
#### 📒 案例概要：dodo智能助手通过电商数据集与分析框架，快速生成分析报告，解决业务分析周期长、复用难问题，提升工作效率。
### 一、引言
**背景：**在AGI时代，AI应用能力已成为一种核心竞争力。面对层出不穷的AI工具，我们最关注的始终是如何让技术真正为工作提效，让我们不仅不落于人后，更能走在前面。

**适用人群：① **直接对经营情况负责，需要方案赋能提升需求响应速度的同学；② 直接对业务负责，需要数据赋能掌握商家/用户最新变动情况的同学

**解决痛点：**分析周期长、业务难复用、共识范围小

#### **关键特点**
* **入口便捷**：支持在如流、网页使用，不需要复杂的环境配置，随时可召唤
