# 大模型应用于机器学习调研
大模型与机器学习的关系大模型，尤其是大语言模型，更像是机器学习的一个补充，而不是替代品。它们的出现弥补了传统机器学习方法在某些任务上的不足，尤其是当特征工程变得困难或者数据集不足时。

自动特征提取：大模型具有自动学习特征的能力，因此在处理结构化数据或文本数据等复杂情况下非常有用。传统机器学习通常需要手动提取特征，而这可能是一项繁琐的工作。泛化能力：大模型通常在大规模数据上训练，因此它们可以具有很强的泛化能力，能够适应各种领域的任务。而传统机器学习针对不同任务都需要一定的数据集来让模型进行训练1）何时选择大模型：

无训练数据集：大模型经过了大量无监督预训练任务能够自动发现数据中的模式和结构，而机器学习需要依赖于数据集的构建。复杂数据特征提取困难：当数据具有复杂的结构或为文本数据，传统特征提取方法难以适应时，大模型可以自动学习数据的表示。2）何时选择机器学习：

数值型特征：当数据具有明确定义的数值特征或标签时，传统机器学习方法更合适。可解释性要求：如果任务要求模型的决策需要解释和验证，传统机器学习模型通常更容易解释，例如决策树或线性回归。小规模数据：对于小规模数据集，传统机器学习方法通常更具优势。计算资源限制：传统机器学习方法通常需要较少的计算资源。在实际应用中，通常需要综合考虑问题的性质、可用数据、计算资源和模型的可解释性来确定是选择大模型还是传统机器学习方法。
