# curl_upload.py 使用文档

## 概述

`curl_upload.py` 是一个批量上传函数到测试环境的 Python 脚本。它定义了多个常用函数（时间、随机、数学、加密等），通过 HTTP 请求将这些函数上传到测试环境的 API。

## 运行方式

```bash
python3 curl_upload.py
```

运行后会自动上传所有定义的函数到测试环境，并生成以下文件：
- `scriptsId.txt` - 保存上传成功的脚本 ID
- `delete_scripts.py` - 批量删除上传脚本的工具

## 内置函数列表

### 1. 时间相关函数

#### 1.1 time - 获取指定格式的时间

**功能说明**
根据指定的日期格式和时间偏移量，返回格式化的时间字符串。支持年、月、日、时、分、秒等多种时间单位的偏移计算。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| format_str | str | 是 | 日期格式，如 yyyy-MM-dd HH:mm:ss | yyyy-MM-dd HH:mm:ss |
| shifting | str | 否 | 时间偏移量，如 -1d（昨天），+1y（明年） | -1d |

**使用示例**
```python
# 获取当前时间
time_func('yyyy-MM-dd HH:mm:ss')
# 输出: 2026-01-12 15:30:45

# 获取昨天同一时刻
time_func('yyyy-MM-dd HH:mm:ss', '-1d')
# 输出: 2026-01-11 15:30:45

# 获取今天日期
time_func('yyyyMMdd')
# 输出: 20260112

# 获取一年前
time_func('yyyy-MM-dd', '-1y')
# 输出: 2025-01-12
```

#### 1.2 timestamp - 获取13位时间戳

**功能说明**
获取当前时间的13位时间戳（毫秒级），支持时间偏移量计算。常用于接口测试中需要毫秒级时间戳的场景。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| shifting | str | 否 | 时间偏移量，如 -1d（昨天此刻） | -1d |

**使用示例**
```python
# 获取当前时间戳
timestamp_func()
# 输出: 1736667045123

# 获取昨天同一时刻的时间戳
timestamp_func('-1d')
# 输出: 1736580645123

# 获取一小时后的时间戳
timestamp_func('+1H')
# 输出: 1736670645123
```

#### 1.3 timestamp10 - 获取10位时间戳

**功能说明**
获取当前时间的10位时间戳（秒级），支持时间偏移量计算。这是 Unix 标准时间戳格式。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| shifting | str | 否 | 时间偏移量，如 -1d（昨天此刻） | -1d |

**使用示例**
```python

# 输出: 1736667045

# 获取昨天同一时刻的时间戳

# 输出: 1736580645

# 获取一分钟前的时间戳

# 输出: 1736666985
```

#### 1.4 getWeekDate - 获取星期对应的日期

**功能说明**
根据指定的星期几和周期偏移量，计算对应的日期。例如可以计算3周前的周一是哪一天。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| week | int | 是 | 星期几，取值1-7（1=周一，7=周日） | 1 |
| shifting | int | 是 | 周期偏移量，负数往前，正数往后 | 0 |
| format_str | str | 是 | 日期格式，如 yyyy-MM-dd | yyyy-MM-dd |

**使用示例**
```python
# 获取3周前的周一
get_week_date_func(1, -3, 'yyyy-MM-dd')
# 输出: 2025-12-22

# 获取2周后的周三
get_week_date_func(3, 2, 'yyyy-MM-dd')
# 输出: 2026-01-28

# 获取本周五
get_week_date_func(5, 0, 'yyyy-MM-dd')
# 输出: 2026-01-17

# 获取下周日
get_week_date_func(7, 1, 'yyyyMMdd')
# 输出: 20260119
```

### 2. 随机函数

#### 2.1 randomInt - 生成随机整数

**功能说明**
在指定范围内生成随机整数。如果不指定范围，默认生成 0 到 9999999 之间的随机数。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| min_val | int | 否 | 取值下限 | 0 |
| max_val | int | 否 | 取值上限 | 100 |

**使用示例**
```python
# -100到100的随机整数
random_int_func(-100, 100)
# 输出: 42

# 0到100的随机整数
random_int_func(0, 100)
# 输出: 87

# 默认范围的随机整数
random_int_func()
# 输出: 5234123
```

#### 2.2 randomString - 生成随机字符串

**功能说明**
生成指定长度的随机字符串。可以自定义字符范围，如果不指定则默认使用英文字母和数字。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| length | int | 是 | 字符串长度 | 10 |
| characters | str | 否 | 允许出现的字符 | abc |

**使用示例**
```python
# 长度为10，只包含abc的随机字符串
random_string_func(10, 'abc')
# 输出: cabbacabca

# 长度为8，默认字符范围的随机字符串
random_string_func(8)
# 输出: a3B7kL9m

# 长度为6，只包含数字的随机字符串
random_string_func(6, '0123456789')
# 输出: 847291
```

### 3. 取模函数

#### 3.1 mod - 取模运算

**功能说明**
执行取模运算，并支持结果左侧补零到指定长度。常用于 ID 生成、哈希分片等场景。

**入参说明**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| dividend | int | 是 | 被除数 | 34 |
| divider | int | 是 | 除数 | 32 |
| length | int | 否 | 总长度，不足时左侧补0 | 4 |

**使用示例**
```python
# 34 % 32
mod_func(34, 32)
# 输出: 2

# 34 % 32，补全到4位
mod_func(34, 32, 4)
# 输出: 0002

# 100 % 7
mod_func(100, 7)
# 输出: 2

# 100 % 7，补全到6位
mod_func(100, 7, 6)
# 输出: 000002
```

python3 delete_scripts.py

## 时间偏移量格式说明

时间偏移量支持以下格式：

| 单位 | 说明 | 示例 |
|------|------|------|
| y | 年 | +1y（明年），-1y（去年） |
| M | 月 | +1M（下月），-1M（上月） |
| d | 天 | +1d（明天），-1d（昨天） |
| H | 时 | +1H（一小时后），-1H（一小时前） |
| m | 分 | +1m（一分钟后），-1m（一分钟前） |
| s | 秒 | +1s（一秒后），-1s（一秒前） |

## 日期格式说明

日期格式使用 Java 风格，会自动转换为 Python 格式：

| Java 格式 | 说明 | 示例 |
|-----------|------|------|
| yyyy | 四位年份 | 2026 |
| MM | 两位月份 | 01 |
| dd | 两位日期 | 12 |
| HH | 24小时制小时 | 15 |
| hh | 12小时制小时 | 03 |
| mm | 分钟 | 30 |
| ss | 秒 | 45 |

## 注意事项

1. 所有函数上传后会保存 scriptId 到 `scriptsId.txt` 文件
2. 删除脚本时会使用生成的 `delete_scripts.py` 文件
3. 时间函数的 shifting 参数为可选，不传则返回当前时间
4. 数学函数除法时除数不能为 0
5. sqrt 函数输入必须为非负数
