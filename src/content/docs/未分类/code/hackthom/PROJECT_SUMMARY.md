# AI播客生成系统 - 项目总结

## 项目概述

本项目是一个基于FastAPI和LangChain构建的多角色AI播客生成系统，能够模拟三个不同身份的角色进行关于AI对就业影响的深度对话讨论。

## 设计思路

### 1. 多角色系统设计

#### 角色定位
- **林知远（主持人）**: 中立引导者，负责控制节目节奏和引导讨论
- **陈博士（经济学家）**: 理性分析者，提供数据支撑和专业观点
- **小李（打工人）**: 情感表达者，代表普通人的真实担忧

#### 角色差异化
- **语言风格**: 主持人亲切专业、经济学家严谨客观、打工人口语化情绪化
- **知识背景**: 每个角色都有专属的知识库和参考数据
- **回应逻辑**: 根据角色特点设计不同的观点表达和情绪反应

### 2. 对话工作流设计

#### 对话管理
- **轮次控制**: 智能判断下一个发言者，避免某个角色过度活跃
- **节奏把控**: 根据目标时长动态调整讨论深度
- **冲突设计**: 有意制造观点碰撞，增强讨论张力

#### 讨论阶段
1. **现状分析阶段**: 各角色表达初始观点
2. **观点碰撞阶段**: 深入辩论和质疑
3. **解决方案阶段**: 转向建设性建议

### 3. 数据支撑体系

#### 研究数据模拟
- 世界经济论坛、麦肯锡、OECD等权威报告数据
- 历史技术革命的就业影响对比
- 具体行业的AI影响预测

#### 新闻事件模拟
- 最近的AI相关新闻事件
- 社交媒体讨论热点
- 职场论坛真实反馈

### 4. 技术架构

#### 后端框架
- **FastAPI**: 提供高性能REST API服务
- **DeepSeek API**: 核心大语言模型，提供强大的中文对话能力
- **自定义Agent系统**: 管理多角色对话流程

#### 模块化设计
```
hackthom/
├── agents/           # AI角色定义
├── data/            # 模拟数据和知识库
├── workflow/        # 对话工作流引擎
├── deepseek_llm.py  # DeepSeek API集成
└── main.py          # FastAPI应用入口
```

## 核心功能

### 1. 播客生成API

**主要接口**:
- `POST /generate-podcast`: 生成完整播客
- `GET /topics`: 获取预定义话题
- `GET /characters`: 获取角色信息
- `GET /demo`: 生成演示播客

### 2. 智能对话系统

**对话特性**:
- 基于上下文的动态回应
- 角色一致性保持
- 自然的话题转换
- 情绪化表达

### 3. 结构化输出

**播客结构**:
- 开场白（主持人介绍）
- 主要讨论（多轮对话）
- 总结收尾（观点汇总）

## 技术亮点

### 1. Agent工作流设计
- **智能角色切换**: 基于对话历史和上下文智能决定下一个发言者
- **情绪检测**: 根据内容和角色特点自动标注情绪状态
- **冲突管理**: 有意制造和解决观点冲突，增强讨论真实感

### 2. 知识库系统
- **分层知识**: 通用知识、角色专属知识、话题相关数据
- **动态数据选择**: 根据讨论话题自动匹配相关数据
- **真实感模拟**: 使用模拟但逼真的数据增强可信度

### 3. 可扩展架构
- **模块化设计**: 易于添加新角色或修改现有角色
- **配置化**: 通过环境变量调整模型参数
- **API优先**: 前后端分离，便于集成

陈博士: 从数据来看，AI客服确实在改变行业格局。根据最新研究，AI客服能够处理80%的标准询问，但人工客服在处理复杂情感问题上仍有不可替代的优势。

小李: 说得轻松，但我朋友就在某大厂的客服部门，他们最近裁员30%，全部换成AI。虽然说留下的人处理复杂问题，但岗位确实在减少啊，房贷车贷压力这么大...

林知远: 小李的担忧很真实。陈博士，您如何看待这种短期的就业冲击？

陈博士: 这确实是转型期的阵痛。历史上每次技术革命都有类似情况。关键是我们要看到，AI客服的普及也创造了新的岗位，比如AI训练师、客户体验设计师等。

小李: 但这些新岗位门槛会不会很高？像我们这种普通人能转过去吗？

## 部署和使用

### 环境配置
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置DeepSeek API密钥
cp .env.example .env
# 编辑.env文件，添加DEEPSEEK_API_KEY
# 获取密钥: https://platform.deepseek.com/api_keys

# 3. 测试DeepSeek集成
python test_deepseek.py

# 4. 启动服务
uvicorn main:app --reload
```

### API调用示例
```python
import requests

# 生成播客
response = requests.post("http://localhost:8000/generate-podcast", json={
    "topic": "AI自动化对客服行业的影响",
    "duration_minutes": 15,
    "use_predefined_topic": True
})

podcast = response.json()
print(podcast["transcript"])
```
