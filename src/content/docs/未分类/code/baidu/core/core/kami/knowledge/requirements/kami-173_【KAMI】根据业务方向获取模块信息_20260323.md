## 需求描述

kamixmgt 下新增接口，根据业务方向名称（如 "MEG-商业"）查询该方向下所有模块信息。

## 接口文档

- **POST** `/core/kami/v2/product/getModuleListByProductDirection`
- Headers: QAMate-ModuleId, QAMate-Token, QAMate-Username

请求：
```json
{ "productDirectionName": "MEG-商业" }
```
返回：
```json
{
  "code": 0, "msg": "SUCCESS",
  "data": [
    {
      "moduleId": 12345,
      "productDirectionName": "MEG-商业",
      "productName": "广告投放",
      "moduleName": "轻舸"
    }
  ]
}
```

## 数据模型

表关系：
`product_direction`(id, name) → `qamate_super_product`(id, name, direction_id) → `lazyone_product`(id, name, parent_id)

核心 SQL：
```sql
SELECT lp.id, pd.name, qsp.name, lp.name
FROM product_direction pd
JOIN qamate_super_product qsp ON qsp.direction_id = pd.id
JOIN lazyone_product lp ON lp.parent_id = qsp.id
WHERE pd.name = #{productDirectionName}
AND pd.is_del = 0
AND lp.is_delete = 0
```
