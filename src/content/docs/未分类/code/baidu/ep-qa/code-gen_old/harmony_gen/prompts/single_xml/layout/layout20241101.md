# 要求
## 采用`alignRules`方式实现对齐时，注意区分组件水平中点对齐参数`middle` vs 垂直中点对齐参数`center`，严格按照以下要求转换:
1. 水平中点对齐必须通过`middle`->`HorizontalAlign.XXX`进行设置，参考示例为：`.alignRules({{middle: {{anchor: '锚点容器ID', align: HorizontalAlign.XXX}}}})`
2. 对齐设置必须遵守格式：`.alignRules({{xxx: {{anchor: '锚点容器ID', align: HorizontalAlign.XXX（水平对齐）/VerticalAlign.XXX（垂直对齐）}}}})`
3. 垂直中点对齐必须通过`center`->`VerticalAlign.XXX`进行设置，参考示例为：`.alignRules({{center: {{anchor: '锚点容器ID', align: VerticalAlign.XXX}}}})`
## 通用边缘间距属性通过`.margin({{方向: 'xxvp'}})`来实现，特别注意左边距必须是设置`left`，右边距必须是设置`right`
## 示例中带`test`关键词的内容均仅供参考，请严格根据输入内容进行对应内容命名转换
## 示例中带`解释`关键词的注释内容仅供理解，在生成过程中请忽略此类注释，不要生成无关内容
## 参考示例生成对应布局转换注释，对于无法解析的布局、组件或属性，需在代码中生成对应`FIXME`注释，如：`/* FIXME: 无法映射的属性: 'xxx' */`
## 布局必须包含子组件，子组件需存放在布局`{{}}`内，布局的属性设置必须在其`{{}}`最后进行
## 图片组件转换时，需设置`.fitOriginalSize(true)`，保证图片能够适配布局
## 引用路径中带`.baidu`关键词的组件需要先导入然后生成对应的使用代码，其他组件一律转换成对应直接使用的默认组件即可，无法识别的属性设置生成对应FIXME注释
## 请按照要求尽可能完成所有组件布局位置关系的解析与转换，并使得转换后的鸿蒙组件与原始xml组件布局保持一致
