# 命名&格式规范：
## 输入接口路径有两种：（1）两层级->`前缀路径/包名/功能名`（2）三层级->`前缀路径/包名/子包名/功能名`，其中前缀路径为`baiduboxapp/ug-game`或``
## 所有`接口路径占位`有两种形式：（1）单层`包名`（2）双层`包名/子包名`，是根据需求输入接口路径来确定，当接口路径为两层级时为`包名`，当接口路径为三层级时为`包名/子包名`，示例如下：
1. 两层级接口路径`baiduboxapp/ug-game/包名/功能名`或`包名/功能名`，对应`接口路径占位`为单层`包名`
2. 三层级接口路径`baiduboxapp/ug-game/包名/子包名/功能名`或`包名/子包名/功能名`，对应`接口路径占位`为双层`包名/子包名`
## `基础功能名`优先需求指定，若未指定，则根据`功能名`解析，当`功能名`为驼峰命名时，`基础功能名`为第一个小写单词，如：功能名`testFunc`，则`基础功能名`为`test`
## `模块包占位`根据输入接口路径层级来确定，要求如下：
1. 两层级接口路径`baiduboxapp/ug-game/包名/功能名`或`包名/功能名`，对应`模块包占位`为`ddz`
2. 三层级接口路径`baiduboxapp/ug-game/pkg/包名/子包名/功能名`或`包名/子包名/功能名`，对应`模块包占位`为`包名`
## `游戏模块名`默认是`dto`，若需求中指定，则按指定内容进行命名
## 所有时间戳相关变量定义时，必须是int64类型，否则会解析错误
## 所有文件必须采用小写、下划线的方式进行命名
## 所有变量、函数、结构体均必须参照示例遵循对应的驼峰命名方式（db数据库变量&表名命名除外），特别注意缩写词如http、api、id、uid、cuid等在命名时必须大写，示例：以`uid`为例，驼峰命名`TestUID`
## 注意所有生成的结构体及其变量、常量必须生成一对一对应的注释，其中导出的函数、结构体必须采用`//方法名 ...`、`//结构体名 ...`的方式进行注释
