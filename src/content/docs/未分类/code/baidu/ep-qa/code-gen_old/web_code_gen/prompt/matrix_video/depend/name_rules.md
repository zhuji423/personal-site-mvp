# 命名&格式规范
## 输入接口路径有两种：（1）指定接口类型：`前缀路径/video/接口类型/包名/功能名`（2）不指定接口类型：`前缀路径/video/包名/功能名`，注意根据输入接口路径解析对应的`接口类型`、`包名`、`功能名`
## 所有时间戳相关变量定义时，必须是int64类型，否则会解析错误
## 所有文件必须采用小写、下划线的方式进行命名
## 所有变量、函数、结构体均必须参照示例遵循对应的驼峰命名方式（db数据库变量&表名命名除外），特别注意如http、api、id、uid、cuid等缩写词在结构体、方法体、变量命名时必须大写，示例：以`uid`为例，驼峰命名`TestUID`
## 注意所有生成的结构体及其变量、常量必须生成一对一对应的注释，其中导出的函数、结构体必须采用`//方法名 ...`、`//结构体名 ...`的方式进行注释
