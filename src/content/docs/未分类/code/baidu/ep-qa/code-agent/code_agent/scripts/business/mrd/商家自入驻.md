### 一、需求背景
**向内看：**提升入驻效率，目前本地商家采用托管模式，商家从入驻-开店均需由销售/运营同学强参与指导，整体人效较低，商家无法完成自主入驻-下单流程，影响商家使用体验

**向外看：**目前多家本地生活服务类平台已经实现了商家自主入驻，显著降低了运营成本。本地自建商家自入驻流程，提升平台的竞争力。
