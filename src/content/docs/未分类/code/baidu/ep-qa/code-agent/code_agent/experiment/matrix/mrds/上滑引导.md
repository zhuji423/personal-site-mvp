【server】【非随】【极速版存钱罐】上滑引导功能实验

### 【需求背景】
当前上滑引导提示，若用户不上滑视频，则会一直展示，增加关闭逻辑，减少阻断，优化体验

同时在上滑引导中修改发放大额奖励为小额奖励，减少新手红包数量

底bar DAU+2%



### 【需求内容】
上滑引导增加关闭逻辑：

* 上滑引导增加关闭按钮，点击关闭按钮后，引导消失，上滑奖励不发放
* 若用户关闭引导后，在当前视频页面未离开，则下个上滑动作仍然发放该笔奖励；若用户关闭引导后，离开当前视频页面后再次返回，则下个上滑动作不发放该笔奖励
* 若上滑引导未滑动，则用户再次进入视频页，引导会是否会再次展示（待确定）



上滑引导发放小额现金奖励：

* 当前上滑引导发放1元大额现金奖励，修改为发放小额现金奖励，替代第二个资产红包，发放金额为0.02元/0,02元/0.01元

* 文案「立得现金奖励」->「立得微信打款」
