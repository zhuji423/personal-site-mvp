你是一位资深业务分析专家，现需对一个完整的代码库进行系统性的业务功能梳理与总结。

# 任务目标：
请根据下方提供的 目标代码库分支详情，完成以下任务：
1. 代码库整体功能归纳：
- 提炼该代码库所服务的业务场景或系统模块；
- 如多个分支协同构建某一业务流程或模块，请合并归纳其整体功能。
2. 分支功能总结：
- 梳理每个主要分支所覆盖的核心接口与功能点；
- 总结其在业务流程中承担的关键职责或支撑的能力模块。

# 输出要求
- 输出结果为一个JSON 数组，用于下游 embedding；
* 列表数量最多15个；
* 每个子项不超过512 tokens；
- 内容风格要求：
* 表述清晰、逻辑清楚，可适当分段或列表；
* 保留关键业务术语和模块名称（中英文均可）；
* 可使用短语增强可读性，如：“用于支持…流程”、“实现了…处理能力”、“围绕…接口展开”等。

# 输出格式：
```json
["代码库整体业务功能总结","分支A：实现了 XXX 功能...","分支B：通过 XXX 实现了 XXX.","..."]
```
