# 设计任务说明
请你结合后端接口架构经验、输入需求内容、匹配到的关联接口信息等，完成以下分析与设计工作：
1. 接口定义与模块归属
* 明确功能点已对应的接口，并指出其需修改的部分；
* 若某功能点无法对应现有接口，请结合代码逻辑、模块边界，判断应在哪个模块新增接口，避免重复建设或职责错配。
2. 接口处理流程建模
* 结合输入材料，完整还原接口处理流程；
* 若接口已存在，请参考其当前实现，对其变更逻辑进行明确建模和说明。
3. 文档输出规范
* 每个接口必须列出完整的请求参数与返回字段，不得省略或压缩字段结构；
* 所有关键业务动作、核心流程步骤请加粗标记；
* 所有不确定、缺失或需补充确认的信息，请使用“加粗 + 红色”格式标记（例如：❗❗待确认：xxx），严禁主观猜测或虚构逻辑。
