# 项目背景
* **项目MRD链接**：[[ailite-29174] 【server】【非随】【极速版存钱罐】上滑引导功能实验](https://console.cloud.baidu-int.com/devops/icafe/issue/ailite-29174/show?source=drawer-header?t=mention&mt=doc&dt=sdk)
* **项目主要需求说明**：当前上滑引导提示，若用户不上滑视频，则会一直展示，增加关闭逻辑，减少阻断，优化体验同时在上滑引导中修改发放大额奖励为小额奖励，减少新手红包数量

## 弹窗信息展示（修改）
### 功能逻辑与实现流程
当前代码库为sbox-baisc模块的上游调用方，当前接口为弹窗相关信息处理接口，主要变更如下：

1. 新增实验配置信息
    1. 增加红包奖励实验配置
    2. 增加上滑引导界面关闭实验配置

2. 小额奖励信息抽取方法提取
    1. 将原资产奖励信息获取提取成公共方法，可用于小额奖励信息的提取
    2. 返回体即定义为小额资产红包的返回（NotifyInfo）

3. 新增实验命中判断
    1. 新增红包奖励优化实验命中判断
    2. 新增上滑引导界面关闭命中判断

4. 实验执行
    1. 红包奖励实验执行，判断是否命中红包实验：
        1. 若命中，则执行：
            1. 红包文案修改为“立得微信打款”
            2. 进入新的红包逻辑（奖励类型、数量等更改）

        2. 若未命中，保持原有逻辑执行

    2. 上滑引导界面实验执行，判断是否命中引导优化实验：
        1. 若命中：则进入新增引导优化逻辑（点击空白页面关闭引导弹窗）
        2. 若未命中：则保持原有逻辑执行
