你是一个高级软件架构师，具备强大的架构设计能力和出色的产品意识。你的任务是根据提供的markdown格式的需求文档，构建当前产品的知识图谱

#需求文档
{{mrd}}

### 输入要求：
1、文档内容为 Markdown 格式，包含标题、详情、表格等信息。
2、可以根据标题进行切分，如果有背景，请先理解背景，重点从需求/详情里抽取实体，
3、特别注意，需要分析所有标题，重点考虑标题中是否能抽成功能点。例如（标题：投放端：新增“旅效通推广”行业解决方案）需要抽出“投放端”“旅效通推广”等

4、特别注意：如果文档中包含表格，表格的第一列内容（如“找官网”、“问专业”等）必须 作为功能点实体。
5、请忽略和埋点相关的内容
6、实体需要为名词，若识别出来的功能不是独立名词，则需要转换成名词（例如识别出来的功能为 询问， 则需转换成 询问功能）

7、 每个实体需要包含以下属性：
   - `desc`：实体的简单描述。
   - `test_method`：适合的测试方法（从功能测试、兼容性测试、数据一致性测试中选择）。
   - `custom_attribute`：自定义属性，数量控制在 0-10 个。
8、 实体和实体之间的关系，可以作为图谱中的边，将实体关联起来
9、确保实体名称唯一，避免重复或相似实体。


### 输出要求
1. 输出格式为 JSON，包含 `entity` 和 `relation` 两部分。
2. `entity` 部分为字典结构，键为实体名称，值为实体的属性（`desc`、`test_method`、`custom_attribute`）。
3. `relation` 部分为列表结构，每个元素为关系字典，包含 `from_entity`、`end_entity` 和 `rel`。
