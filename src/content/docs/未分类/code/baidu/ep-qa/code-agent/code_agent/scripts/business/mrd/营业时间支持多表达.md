营业时间支持多表达

## **1. 背景&收益**
### 1.1 需求背景
* **项目背景**：

当前业务下

存在客户每周工作日和周末需求展现不同的营业时间，在不同的季节有不同的营业时间展现；【联通】

存在客户有售前售后不同时间的展示需求；【oppo,vivo,xiaomi 】

存在客户在同一天需展现多营业时间；【餐饮类客户】





例：OPPO店铺，4-9月：售前-工作时间9:00-12:00,14:00-18:00 ,售后-工作时间10:00-12:00,14:00-17:00 ；10-3月：售前-工作时间10:00-12:00,13:00-18:00 ,售后-工作时间11:00-12:00,13:00-17:00 特殊时间：春节：售前-工作时间10-11  13-15  售后-工作时间9-13  15-18。

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=8500b5a05c5a44e9a5c6e5cedebff145&docGuid=gx6zo5Myi5TInW "")
* **产品目标**：

新增多营业时间表达，满足商家运营侧产品需要，提升产品满意度





### 1.3 需求收益
* 提升产品满意度，提高运营效率。
