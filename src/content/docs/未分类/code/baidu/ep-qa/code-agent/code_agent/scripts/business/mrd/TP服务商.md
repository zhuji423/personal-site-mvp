### 一、需求背景
**信息获取**：销售自拓和平台挖掘（基于平台数据库和精准的算法，依据广告主行业、地域等信息，有针对性地进行商机下发）

**筛选评估**：服务商对潜在商机进行全面评估，并在服务商内部流转处理

**线索跟进**：针对收集到的线索信息，服务商可在平台上记录跟进情况

**开户**：确定合作意向后，服务商在**服务商平台**完成开户。商户需提交营业执照、法人身份证明、联系方式等基础资料，完成开户流程。

同步生成商户的平台账户，拥有独立的登录权限和管理界面，方便后续直接操作。

**店铺注册：**服务商帮助商家完成店铺注册，填写店铺名称、简介、经营范围、店铺地址等基础信息补充。

**店铺装修**：协助商家进行店铺搭建，包括商家相册、转化能力、商品或服务等信息 。

**下单流程引导**：服务商完成下单前置准备，创建待付款订单，如需对公打款引导客户提前打款，最终协助客户完成订单确认和付款。

**商户管理：**服务商对名下广告主管理，查看充值、订单等数据信息。优化店铺信息、内容、商产品、流量宝投放等提升效果。

**数据分析支持**：客户效果跟踪、服务商组织效果分析等经营分析能力。

**客户服务协助**：协助商户处理客户咨询、投诉和售后问题，建立良好的客户关系，及时响应客户需求

**一期为快速迭代，主要支持代理商入驻、开户、下单、支付的核心能力。搭建初版服务商平台，实现服务商开户；其他复用开店原有的开店下单能力、财务平台的开票退款能力。长期规划详见：**[本地会员服务商售卖流程方案](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/PhWJPFLUSm/ZEl78wfe5ZGEbM?t=mention&mt=doc&dt=doc)

### 二、需求价值
**服务商 v.s. 代理商**

**一、对标市场主流模式：**

市场中开展本地业务的各主流媒体合作模式均为服务商模式，以抖音生活服务与高德地图为例（美团在整个服务链条从商家采购、预约、支付、外卖等也都为多样的服务商伙伴)，均为服务商合作模式：本地商家的业务特征为GMV高、利润薄、海量商户，这种商业生态建立需要实现快速海量覆盖，财务模式的设计需要让利给到合作伙伴做大体量销售团队投入，同时所开发的客户与媒体方直签，客户归属为媒体方，媒体对客户的把控力更强，服务商通过客户引入和运营获取服务费；

**二、服务商模式直接利于本地业务有序和快速增长**

1、商家合作更有序：客户信任感更强，高德同时有几百家代理商（直接投入销售人力上万）实现价格市场统一，不容易乱价因为在服务商模式下客户与媒体方直签，付款方式为直接打款给媒体公司。合同、发票等流程均体现与媒体方直接合作，客户信任感足，降低服务商业务拓展时建立信任的难度，提升销售效率；

2、铺市场更快速：服务商和代理商佣金结算周期的不同，现有代理模式下，CPT产品后返需按照分摊消费来计收，佣金结算周期为一年，代理商现金流压力较大，影响投入意愿，前期要靠代理商投入自有资金支付人员工资，整体团队扩充慢，因五个季度的返点递延的不确定性使得代理商自身经营风险高，优秀的合作商伙伴保守投入，难以成立专职大规模销售团队(100人+)进行业务投入；服务商模式下回款周期可调整为次月或次季度，代理商现金流压力小，可快速扩充销售团队进行市场开拓（高德头部代理商销售团队为400-500人员规模)；

**三、财报影响**

代理商模式返点直接抵充收入，限制返点长度不可处于高长度（高德在85%-95%之间）。服务商模式下整体营收全部计入收入，服务商收益以服务费或市场费用单独计入成本，对财报收入项有正向影响；
