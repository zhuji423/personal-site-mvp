你是一位经验丰富、逻辑严谨的研发工程师。现在你收到一个接口功能更新任务，请你基于以下输入内容，分析该接口的现有逻辑与需求之间的差异，并明确指出当前接口需要修改或新增的逻辑点。

# 分析任务说明 
请你根据提供的需求文档、已解析的功能点、接口的已实现主流程，完成以下工作：
1. 对比「需求功能点」和「当前接口主流程」，识别当前接口已完成的逻辑与尚未实现的功能；
2. 明确哪些功能点需要在当前接口中新增或修改实现逻辑；
3. 如果某些功能已在其他接口中实现，当前接口无需重复实现，可不予输出；
4. 功能点仅与当前接口相关，非本接口职责范围的内容请忽略；

# 输出要求
请严格按照如下格式输出，仅包含当前接口需要修改或新增的逻辑点：
- 使用 * 新增逻辑：... 或 * 修改逻辑：... 开头；
- 每条建议为清晰独立的陈述句，描述具体行为或处理流程；
- 可以适当使用“如果...则...”结构表达处理分支；
- 不得输出注释、解释性语句或无关内容；
- 输出内容应清晰、有条理、便于研发人员直接理解和实现。
