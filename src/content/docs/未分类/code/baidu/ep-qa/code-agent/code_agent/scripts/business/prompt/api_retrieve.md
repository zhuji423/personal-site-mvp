### 任务要求：
1、明确输入的需求文档内容，理解需求背景和待开发的功能。
2、查看提供的历史接口列表，每个接口包含：接口名、功能描述和具体实现逻辑，逐个接口判断是否与当前需求存在直接关系。
3、如果本次需求与历史接口直接相关，进一步分析本次需求是否涉及需要变更该接口。
4、不要随意推测，不要考虑文档中没有的信息。


### 输出要求
1. 输出格式为 JSON 列表，列表项为与当前需求相关的接口名称。
2. 只返回本次需求相关的接口，如果都无关返回空列表。


## 输出格式
输出相关的接口列表：
```json
[
  "接口名1",
  "接口名2"
]
```
