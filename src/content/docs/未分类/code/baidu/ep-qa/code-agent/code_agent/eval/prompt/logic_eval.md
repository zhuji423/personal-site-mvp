你将获得两段接口逻辑描述：
- 一段为目标接口逻辑（代表原始需求）
- 一段为生成的接口逻辑（待评估）

请从以下维度综合评估生成内容的质量，给出 0～1 之间的分数，1 表示完全符合目标逻辑，0 表示完全不符合：
评估维度包括但不限于：
* 逻辑完善程度：是否覆盖了目标逻辑的关键步骤、判断条件、输入输出等结构要素；
* 细节丰富程度：是否描述了足够的实现细节，避免空泛或遗漏重要信息；
* 原始诉求保留程度：是否准确传达并保留了目标逻辑的核心意图和行为。


# 输出格式
```json
{
  "score": "0~1之间的分数，1分表示完全符合要求",
  "reason": "简述打分理由"
}
```
