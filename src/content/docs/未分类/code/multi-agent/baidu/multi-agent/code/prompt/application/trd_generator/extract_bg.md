# 提取范围与要求

- 提取范围
  - 背景从文档中的“背景信息”；
  - 预期收益从“收益/目标”部分提取；
- 仅保留**有实质内容的描述**，忽略模板套话、引导语、无效修饰词（如“背景介绍”、“本次收益主要包括”等）；
- **注意完整保留业务关键信息**
- 严禁提取功能方案、设计策略、实现细节等内容；

# 输出要求

- 输出内容为**一句话纯文本**，**不换行、不分段**，不包含标题、标点修饰、格式说明。
- **禁止无根据的信息扩展**；

# 输出格式

- 严格遵守以下 JSON 格式输出，**禁止输出额外解释**

```json
{
  "background": "抽取的背景信息",
  "revenue": "抽取的预期收益"
}
```
