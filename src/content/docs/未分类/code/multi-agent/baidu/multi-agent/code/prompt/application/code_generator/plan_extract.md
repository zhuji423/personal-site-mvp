## 任务描述

根据用户指定开发的“功能点”，从 `.lumos/设计文档.md` 或研发提供的 Markdown 设计文档中，
抽取与该功能点相关的所有设计信息。

## 用户输入
- 用户故事
    - 功能点关联的需求
    - 验收标准
- 待开发功能点
    - 功能点名称，功能点Tag
    - 功能描述
    - 模块设计

## 研发设计文档
- 设计文档文件位置 `.lumos/设计文档.md`
- 完整的设计文档一般包含以下几类内容：

1. 需求背景
2. 总体方案 （功能点以及对应的核心逻辑变更）
3. 接口设计
4. 存储设计 （如mysql、Redis、GCP）
5. 其他待开发的事项 （如脚本、配置等）
6. 其他扩展信息（测试、上线等）

## 输出格式

```markdown
# 功能点Tag - 功能点名称

## 1. 用户故事（一般从用户输入中提取，如果没有则跳过此项）

{{设计内容}}

## 2. 待开发功能点（从用户输入中提取）

{{功能点描述}}

{{验收标准}}

## 3. 代码设计（从研发设计文档中提取整合，具体包含哪些内容，根据实际情况填写）

* 接口：...
{{请求/响应参数变更情况}}
{{逻辑变更}}

* 脚本：...
{{逻辑变更}}

* 配置：...
{{配置变更}}

* 存储：...
{{数据结构}}


## 实现流程

1. 查看当前待开发需求的设计文档 `.lumos/设计文档.md`
2. 从用户输入中提取功能点Tag和名称关键字，并且提取当前代码库模块下的，设计文档中的和指定功能点相关的**开发设计**内容，用于指导后续自动化的代码生成。
3. 将用户输入中的的功能点相关信息和设计文档中的待开发内容整合到一起，并且按照格式将本次待开发功能点的内容输出到`.lumos/{{功能点 Tag}}.md`文件中。
