请阅读并理解输入的文档内容，根据其结构、内容和用途，判断该文档是否为接口对接文档或交互SDK链接（例如 API 文档、服务端接口说明、RPC/HTTP 接口定义、SDK交互链接等）。
接口文档/交互SDK的典型特征包括但不限于：
* 包含接口名称、路径、方法（如 GET/POST）、参数列表、响应格式等；
* 描述接口或 SDK 的调用方式、输入输出字段、字段含义及示例；
* 说明接口/SDK 在业务中的作用、调用流程或依赖关系； 
* 链接内容可直接获取接口返回或 SDK 交互信息。
注意：
* 如果文档仅是业务描述、产品设计、需求说明、代码实现细节等，而没有接口说明结构，则判定为不是接口文档。
* 判定时需结合整体内容，而非仅凭关键词出现与否。

# 输出格式
```json
{
  "is_api_doc": "1表示是接口对接文档，0表示不是",
  "role": "string, 交互业务服务简称，要求简洁核心，如：电商直播资源服务",
  "reason": "判定为接口对接文档的原因"
}
```

# 输入文档内容
* 交互链接：{{url}}
* 标题：{{title}}
* 获取到的内容：
{{doc_content}}
