# 任务目标
你将收到以下两部分输入：
1. 产品需求文档内容，内容可能包含图片及描述
2. 与产品需求文档中图片相关的候选ui实体，包括实体名称、实体描述、实体ID、可能的实体ui类型、关联的实体及关联类型

你的任务是：
请你理解产品需求文档中的图片内容和候选ui实体，为每个图片找到相对应的ui实体，并根据需求内容筛选出需要变更的ui实体

要求：
* 逐一判断，不遗漏：请对需求文档中的每个图片逐一评估，判断其是否与候选ui实体的功能相关，不得遗漏；
* 聚焦理解：仅理解图片中ui元素的功能，不扩展无关内容；
* 关联考虑：结合关联的ui实体，整体考虑匹配；
* 结果要求：分析结果按照相关性由高到低，最多取出5个实体，如果没有相关的实体可以为空。请直接输出最终结果，不需要单独排序输出

注意：请避免冗余扩展或引入与待开发功能点无关的推理。

# 输入示例
```json
{
  "description": "候选实体功能描述",
  "name": "候选实体名称",
  "entity_id": 0,
  "kind": "候选ui实体类型，unknown表示未知",
  "rel_entities": [
    {
      "description": "关联实体的功能描述",
      "name": "关联实体名称",
      "entity_id": 1,
      "kind": "候选ui实体类型，unknown表示未知",
      "rel_entities": [],
      "relation_type": "关联实体的关联类型"
    }
  ]
}
```

# 输出格式
## 字段说明
* name：实体名称，请从给定的候选实体中获取，请勿猜测
* entity_id：实体ID，类型为int，请从给定的候选实体中获取，请勿猜测
* score：关联得分，类型为int，表示实体的相关度，取值为1-10，值越大表示相关度越高
* reason：判定和得分原因。30 字左右
## 输出示例
```json
[
  {
    "name": "实体名称",
    "entity_id": 0,
    "score": 5, // int 数据，表示实体的相关度，取值为1-10，值越大表示相关度越高
    "reason": "判定和得分原因。30 字左右"
  }
]
```
