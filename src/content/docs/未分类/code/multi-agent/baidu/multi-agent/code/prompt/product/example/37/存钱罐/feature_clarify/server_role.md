# 示例（**输出结构仅作参考，重点是逻辑清晰、分组合理、信息完备**）
* **注意：如包含实验相关逻辑，优先按照实验维度对功能点进行划分，并确保同一实验组内的功能点保持一致归属和处理路径。**；
## 输入需求描述示例
```markdown
新手红包样式优化
1. 样式优化
* 原标题："新手红包" 改为 "新人红包"
* 原领取文案："立即打款" 改为 "立即微信到账"
2. 上滑红包奖励调整
* 若为激活用户，则根据用户层级调整上滑红包奖励金额，L1-L3第一个资产红包奖励金额为0.28元（原1元），L4层级保持为1元。

对照组：线上样式&奖励，sid=待定（20%） 
实验组1：样式优化，sid=待定（20%）
实验组2：奖励调整，sid=待定（20%）
```
## 输出示例（无需强制格式化，关键是逻辑链条理解和解析）
* 请求参数解析&校验
解析并校验客户端传入的用户标识信息（如 UID、CUID、设备类型、APP 版本等）、配置信息（如：AMIS 配置页面 ID，以及用户当前命中的实验 SID等）。

* 处理逻辑
- 实验1：新手红包样式优化
1. 根据AMIS页面ID获取样式优化实验配置（如：实验SID等）；
2. 通过用户SID和AMIS页面配置实验SID是否匹配，判断是否命中样式优化实验；
3. 根据实验命中状态确定新手红包标题和文案：
  3.1 若命中样式优化实验，则将新手红包标题替换为“新人红包”，领取文案替换为“立即微信到账”； 
  3.2 否则保持新手红包标题为“新手红包”、领取文案为“立即打款”；

- 实验2：上滑红包奖励金额调整
1. 根据AMIS页面ID获取奖励金额调整实验配置（如：实验SID等）；
2. 通过用户实验SID和页面配置实验SID是否匹配，判断是否命中奖励金额调整实验；
3. 当用户为激活用户时，则将用户当前层级、实验命中状态传入策略服务，根据返回策略内容获取奖励金额（命中新策略：L1-L3 为 0.28 元，L4 为 1 元，命中旧策略：所有用户默认奖励金额为 1 元）；

* 返回字段汇总
1. 是否命中样式优化实验（布尔值）；
2. 新手红包标题字段（字符串, “新手红包“ -> “新人红包”）；
3. 奖励领取文案（字符串，“立即打款” -> “立即微信到账”）。
4. 上滑红包金额调整实验命中状态（布尔值）；
5. 奖励金额领取详情信息（对象类型，用户奖励金额领取详情，非激活用户时为空）；
