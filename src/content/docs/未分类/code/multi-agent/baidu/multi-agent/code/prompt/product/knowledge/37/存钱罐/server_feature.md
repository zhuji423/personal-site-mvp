# 极速版存钱罐功能Server开发 - 业务背景知识
## 1. 代码库结构与职责
1.1 模块定位与交互关系
* `baidu/searchbox/sbox-basic`：**仅起到中转/透传作用的模块，不承接任何业务逻辑**，模块中的上游服务接口调用`baidu/jady/ug-duoduo-video`模块中的下游接口服务获取业务返回信息并透传给前端；
* `baidu/jady/ug-duoduo-video`：功能Server逻辑实现模块，模块中的下游服务接口给`baidu/searchbox/sbox-basic`模块中上游服务接口提供任务配置、业务逻辑、实验等返回信息；

1.2 **公共请求参数约定**
* 代码库中存在通用请求结构体，自动解析以下公共请求参数：
  * 用户相关参数（如：cuid、uid、version、appid等）；
  * 配置相关参数（如：实验 sid 、OSBranch、CUA等）；
* **解析需求时**：
  * 若需求涉及上述公共参数字段，即便接口请求参数中没有显式声明，也无需新增入参，因为这些字段已在公参解析中统一获取。
  * **仅当参数不在公共参数范围，或需求要求显式声明时，才新增**。

## 2. 交互对象
1. **客户端**：发起请求，传入用户信息、页面参数等，功能 Server 接收后进行业务处理并返回结构化响应数据；
2. **AMIS配置平台**：提供任务配置、实验配置（如实验 SID、默认文案、标题、副标题等）；
3. **外部服务调用**：功能Server可能需要调用的外部服务接口，**仅在业务逻辑涉及外部服务提供的功能时调用接口，不实现外部服务内部逻辑**；未涉及外部服务的业务逻辑仍需功能Server独立实现；调用外部服务时：
   * 功能Server需收集请求中与外部调用相关的必要信息（如用户信息、实验状态等）；
   * 功能Server处理外部接口相关逻辑，仅调用外部服务接口获取必要数据，用于补充或拼接响应。
   外部服务接口调用与约束，包括但不限于：
     * **奖励策略外部服务**
        * 所有涉及奖励策略分发逻辑（如根据用户信息、实验状态、层级 L1~L4 定制奖励金额、发放规则、金额变更记录等）**均由奖励策略 Server 独立实现**；
        * 功能Server仅负责调用奖励策略接口获取结果，并在响应中回传给前端； 
        * 响应字段一般无需新增或修改，除非需求涉及对奖励结果进行额外处理后再下发前端，此时才需新增或修改字段； 
        * 前端负责根据奖励策略结果做具体逻辑决策（如分支处理、展示策略、动画触发、挂件驻场/退场等），功能Server通常仅下发奖励分发结果，不下发前端独立决策字段（实验状态除外）。
     * **电商直播资源外部服务**
        * 涉及电商直播资源展示时，功能Server必须调用电商直播资源 Server 对应外部接口，获取对应电商直播资源详情展示信息，并拼接入响应；
        * 数据原样回传，除非需求明确要求额外处理。
     * **其他需求文档明确提到的外部服务接口**
        * 遵循与上述相同的调用原则与处理约束。
4. **外部页面交互**：和外部页面相互导流（如：任务系统、搜索结果页、游戏中心等），在需求理解时，仅关注其他系统导入存钱罐功能的逻辑和实验内容，**不关注外部页面或导入外部页面的逻辑、实验内容**。

## 3. 业务逻辑重点与边界
以下内容明确功能Server开发的职责和禁止越界内容，所有需求拆解时**不得将外部服务内部逻辑及前端独立负责的业务和字段处理分配给功能Server实现**。

### 3.1 实验相关逻辑（**全量上线时不涉及实验逻辑**）
* 当接口涉及实验控制能力时，需通过 AMIS 配置平台获取实验配置信息，并结合请求参数中的实验相关信息判断是否命中实验。实验命中状态将直接影响服务端的处理路径，例如分支策略、执行流程或返回结果，应作为核心判断条件纳入逻辑中。 
* **响应结果必须显式返回实验命中状态的字段**，以支持前端展示或逻辑分流。字段设计通常遵循以下约定：
  * 实验需求中仅区分单个实验组的场景：使用一个布尔类型字段（或 0/1 枚举）直接标识是否命中该实验；
  * 实验需求中明确区分多个实验组的场景：使用单个字符型枚举字段表示当前所处实验分组，枚举值覆盖所有可能分组（如：0-对照组简述,1-实验组1简述,...,n-实验组n简述）；
* 请结合具体需求场景合理决策（如先判断是否命中实验，命中则走特定策略，否则执行默认流程）。

### 3.2 前端独立负责逻辑&决策
以下内容为**前端完全独立控制**，不属于功能 Server 下发或决策范围，**在接口职责拆解和字段变更分析中必须排除，禁止新增任何和以下逻辑相关的字段**：
* 交互计数与节奏控制：仅涉及前端渲染次数、启动次数、滑动次数、点击次数、动画执行次数、节奏、挂件退场/驻场时机&停留时长等交互行为的控制字段； 
* 纯视觉与布局控制：纯 UI 动效、布局位置、展示顺序（如轮播顺序、渐显渐隐）、字体大小、颜色、透明度等视觉呈现控制；
* 本地计时与计数绑定：与前端自有定时器或本地计数器直接绑定的字段（如通知展示次数、滑动触发次、计时器转圈次数等）；
* 与服务端无关的展示控制参数：任何不会影响服务端决策结果、仅影响前端呈现效果的控制参数； 

> **例外（需由功能 Server 下发的字段）**：
> 1. 激活状态类字段：涉及“激活”相关的用户状态时（如是否激活），必须由功能Server上报至任务中台并返回给前端进行判断。
> 2. 文案配置类字段：如标题、副标题、提示文案、描述文本等，需由功能 Server 从配置平台提取并在响应中下发，承担配置透传与回传职责。
