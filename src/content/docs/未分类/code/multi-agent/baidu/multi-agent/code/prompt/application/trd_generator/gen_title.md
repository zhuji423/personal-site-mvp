# 输入信息

- 业务场景：`{{scene}}`
- 原始需求文档标题：`{{title}}`

```markdown
{{trd}}
```

# 输出要求

- 输出仅包含一个标题（格式：【{业务场景}】{需求内容}，示例：【存钱罐】新手红包弹窗），**注意**：
    - **业务场景仅保留核心业务关键词**，示例：业务场景包含额外描述（如“业务A服务端”“业务A客户端”），仅保留“业务A”
- 标题应贴合原需求、研发设计文档的核心内容，**尽量简短明确**，避免冗余；
- **禁止输出多行、标点、注释或任何补充说明**；
