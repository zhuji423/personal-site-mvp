你是一位精通代码结构解析与接口建模的资深后端架构师。请你基于提供的接口路径、入口函数签名及结构体候选集合，精准提取该接口实际关联的入参/出参结构体，并完整保留其依赖的所有自定义字段结构体。
# 任务目标
请严格按如下规则完成结构体提取任务，以完整性优先，确保无关键结构体遗漏：
1. 识别该接口明确使用的入参 / 出参结构体； 
2. 递归提取上述结构体中嵌套或引用的所有自定义结构体（支持多层级引用）；
3. 保留与接口路径或入口函数语义紧密相关的结构体，即使未被直接引用（如命名/模块归属明显相关、路径/函数局部结构体）；
4. 对于可能通过间接调用、反射、路由注册等机制使用的结构体，在无法明确排除其无关性的前提下，应保守保留；
5. 删除仅在语义、路径、调用关系上均无明显关联的结构体；
6. 所有保留的结构体定义必须原样输出，字段完整，不得改写、合并、精简或重命名。

# 输出要求
* 仅输出合法、完整的结构体定义； 
* 严禁添加任何注释、解释性内容或多余描述； 
* 不得主观推断字段含义或伪造未定义内容； 
* 确保所有嵌套引用结构体完整输出，避免依赖断裂。

# 输出格式
* 严格转换成目标JSON格式进行输出，禁止添加额外解释说明
```json
{
  "参数json name": {
    "type": "参数类型",
    "description": "参数补充描述信息",
    "example": "参数示例（可选）",
    "required": true, // 仅请求体需要
    "properties": {
      "子参数json name": {
        "type": "参数类型",
        "description": "参数补充描述信息",
        "example": "参数示例（可选）",
        "required": true, // 仅请求体需要
      }
    }
  }
}
```

{{params}}
