### 存储与配置资源对象（增量）

代码库中增量变更的存储类与配置类资源对象，包括但不限于：
- 关系型数据库（如：MySQL）
- KV / 缓存系统（如：Redis）
- 对象存储（如：GCP / OSS 等）
- 配置平台 / 配置中心（如：AMIS 等）
识别来源包括但不限于：
- ORM / Model 定义
- 数据源配置文件
- 连接配置 / 初始化代码

**输出格式如下**：
```markdown

| <对象名称> | <数据表/缓存/配置项> | <文件路径> | <用途说明> | <读/写/更新等> |
```

# 输出要求

1. **只提供定位锚点**，不输出实现代码
2. **目录级精度**，不要求行号
3. **相似场景对比**：对容易混淆或高度相似的场景必须提供差异化说明（至少 1-3 点）。
4. **结构化表达**，使用表格和简单的文本时序图
5. **完整覆盖**，不遗漏长期存在的能力
6. **保持简洁**，重点是"是什么"和"在哪里"，不是"怎么做"
