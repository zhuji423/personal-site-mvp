# 存钱罐功能 Server - 交互角色背景知识
功能 Server 是服务端的核心处理模块，提供各种业务功能服务接口，负责接收客户端请求、解析用户信息，**进行实验需求条件判断与流程控制**，按需调度获取 AMIS 平台配置和策略 Server 获取配置信息与个性化策略，最终聚合并输出结构化响应。

其核心职责包括：
* 任务配置获取
基于 AMIS 配置页面 ID 从平台获取任务配置、实验信息与元数据等。AMIS 仅提供静态配置内容，不承担命中判断逻辑。

* 实验逻辑处理
1. **若不存在实验需求或实验全量上线，则无需处理实验相关逻辑，跳过实验处理**。
2. 若存在实验需求，则需要：
* 在服务端进行命中逻辑判断：
  * 命中：修改相关配置字段（如实验文案、标题变更等）； 
  * 未命中：保留默认配置；
* 命中状态需在响应中显式返回，字段命名应符合需求原文。

* 外部接口调用
  * 需求涉及金额变更 → 调用奖励策略 Server：传入用户信息与命中状态，获取个性化奖励策略结果，并拼接至响应。
  * 需求涉及电商直播资源加载 → 调用电商直播资源 Server：获取展示所需的资源详情。
  * 其他需求**明确提到**的外部服务接口。
  * **需求不涉及以上内容 → 不进行外部接口调用**。

* 响应结构组装
汇总任务配置、实验判断结果与策略 Server 返回值，组装为结构化响应输出。返回内容包括命中状态、展示用字段（如标题、文案）、策略下发结果等，供前端渲染与使用。

# 交互系统职责边界
* **客户端**：负责发起请求（含用户标识、页面参数等），并根据服务端返回的结构化数据进行页面渲染与状态更新。页面内的动态交互行为（如点击跳转、弹窗打开、Tab 切换等）由前端独立处理，不属于服务端职责。
* **AMIS 配置平台**：提供任务相关的实验配置、任务元信息、默认文案等，供服务端按需拉取，不承担任何命中判断逻辑；
* **外部接口**
  * 奖励策略 Server：提供奖励金额变更场景下的个性化策略结果；
  * 电商直播资源 Server：提供展示所需电商直播资源详情；
  * 其他需求**明确提到**的外部服务接口。
