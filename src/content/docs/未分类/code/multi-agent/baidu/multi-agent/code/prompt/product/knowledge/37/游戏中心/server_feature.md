# 游戏中心功能Server开发 - 业务背景知识
## 1. 代码库结构与职责
1.1 开发代码库&接口职责
* 模块路径：`baidu/searchbox/ug-gamecenter`
* 接口前缀及对应职责：**游戏中心每个接口均存在独立负责的业务逻辑实现，不存在纯透传的接口**
    * `/baiduboxapp/ug-gamecenter`：面向用户的游戏中心业务逻辑实现接口；
    * `/inner`：内网接口，服务间内部通信与数据交互；
    * `/testing`：功能测试与数据干预接口；
    * `/mis`：AMIS平台配置获取接口；
  **在职责分配时，需理解接口的核心职责进行接口相关的准确逻辑映射和字段变更**

1.2 **公共请求参数约定**
* 代码库中存在通用请求结构体，自动解析以下公共请求参数：
  * 用户相关参数（如：cuid、uid、version、appid等）；
  * 配置相关参数（如：实验 sid 、OSBranch、CUA等）；
* **解析需求时**：
  * 若需求涉及上述公共参数字段，即便接口请求参数中没有显式声明，也无需新增入参，因为这些字段已在公参解析中统一获取。
  * **仅当参数不在公共参数范围，或需求要求显式声明时，才新增**。

## 2. 交互对象与职责边界
### 2.1 交互对象
1. **客户端**：发起请求，传入用户信息、页面参数等，功能 Server 接收后进行业务处理并返回结构化响应数据；
2. **AMIS配置平台**：提供游戏中心不同游戏的页面配置字段信息，通常通过接口读取Redis/DB等数据返回至配置平台进行展示和配置。
   * 职责定位：**页面展示配置**；
   * 注意：**游戏字段配置全集需以现有代码实现和参数定义为准**，以下内容仅作参考，帮助理解常见配置类型，包括但不限于：
      * 基础信息：游戏ID、游戏标识、游戏名称、跳转地址、认证类型、收益类型、在线状态、认证状态、动画开关等；
      * 展示信息：游戏标签、游戏icon、游戏图片、海报、图标、脚标等；
      * 大厅排序：游戏排序ID、展示位置、排序权重等；
      * 标签信息：标签名称、边框颜色、背景色、排序权重等；
   * 边界要求：仅负责**静态/半静态展示字段，不涉及实验逻辑或个性化策略**。
3. **GCP配置平台**：负责提供游戏中心任务及实验相关的参数配置，通过读取 GCP 平台的 JSON 构建响应结构体返回，包括但不限于：
   * 职责定位：**任务与实验配置**；
   * * 提供游戏中心任务、实验相关参数，通过 JSON 结构构建响应； 
   * 配置信息包括但不限于： 
     * 基础信息：任务/实验名称、唯一标识、分类、实验 SID 等； 
     * 个性化策略下发：根据用户信息返回奖励策略、抽奖策略等； 
   * 边界要求： 
     * 若无实验需求，不返回实验字段； 
     * 涉及实验时，需返回实验命中与策略分发结果； 
     * **仅负责实验/策略逻辑，不涉及页面展示配置**。
4. **外部服务调用**：需求中明确涉及的游戏相关逻辑外的外部服务，**仅在业务逻辑涉及外部服务提供的功能时调用接口，不实现外部服务内部逻辑**；未涉及外部服务的业务逻辑仍需功能Server独立实现；调用外部服务时：
   * 功能Server需收集请求中与外部调用相关的必要信息（如用户信息、实验状态等）；
   * 功能Server处理外部接口相关逻辑，仅调用外部服务接口获取必要数据，用于补充或拼接响应。
5. **外部页面交互**：和外部页面相互导流（如：任务系统、搜索结果页、存钱罐等），在需求理解时，仅关注其他系统导入存钱罐功能的逻辑和实验内容，**不关注外部页面或导入外部页面的逻辑、实验内容**。

### 2.2 职责边界说明

#### 2.2.1 前端边界
以下内容明确功能Server开发的职责和禁止越界内容，所有需求拆解时**不得将外部服务内部逻辑及前端独立负责的业务和字段处理分配给功能Server实现**。

**前端独立负责逻辑&决策**
以下内容为**前端完全独立控制**，不属于功能 Server 下发或决策范围，**在接口职责拆解和字段变更分析中必须排除，禁止新增任何和以下逻辑相关的字段**：
* 交互计数与节奏控制：仅涉及前端渲染次数、启动次数、滑动次数、点击次数、动画执行次数、节奏、挂件退场/驻场时机&停留时长等交互行为的控制字段； 
* 纯视觉与布局控制：纯 UI 动效、布局位置、展示顺序（如轮播顺序、渐显渐隐）、字体大小、颜色、透明度等视觉呈现控制；
* 本地计时与计数绑定：与前端自有定时器或本地计数器直接绑定的字段（如通知展示次数、滑动触发次、计时器转圈次数等）；
* 与服务端无关的展示控制参数：任何不会影响服务端决策结果、仅影响前端呈现效果的控制参数； 

> **例外（需由功能 Server 下发的字段）**：
> 1. 激活状态类字段：涉及“激活”相关的用户状态时（如是否激活），必须由功能Server上报至任务中台并返回给前端进行判断。
> 2. 文案配置类字段：如标题、副标题、提示文案、描述文本等，需由功能 Server 从配置平台提取并在响应中下发，承担配置透传与回传职责。

#### 2.2.2 配置平台使用边界
* 原则：仅在需求明确涉及相关内容时引入平台，**禁止不明确或错误引入**
* 规则： 
  * 页面展示相关 → 使用 AMIS 
  * 任务/实验/个性化策略相关 → 使用 GCP 
  * 页面展示与实验/策略同时涉及 → 两个平台都使用 
  * 不涉及展示或实验/策略 → 不引入任何平台
