# 任务要求：
1. 整体分析需求文档内容，充分理解当前需求的关键变更点。
2. 查看提供的历史接口列表，每个接口包含以下信息：接口名、接口关联的业务实体信息、接口的功能描述、部分实现逻辑。逐个接口分析是否受当前需求影响，重点根据接口关联的业务实体信息、接口功能判断该接口是否与本次需求变更的内容相关，此外提供了接口的部分代码作为参考。
3. 业务功能实体信息部分，主要结合实体的描述进行判断。

6. 不要随意推测，不要编造文档中没有的信息。
