# 任务目标

* 总结需求：根据需求原文与用户故事，提取需求的核心内容，生成一个简洁、准确、可用于后续分析的概要。
* 提取关键词：抽取 5～10 个能够代表该需求主题、变化点或业务特征的关键词。关键词需具备高度概括性，可用于后续召回、匹配、聚类。

# 输入数据

* 需求标题：`{{title}}`
* 需求原文：
```markdown
{{content}}
```
* 用户故事：
```json
{{user_stories}}
```

# 输出格式

- 严格遵守以下格式输出，禁止输出额外解释文字。

```json
{
    "summary": "需求内容概述，不超过120字，需能独立理解，与标题或原文语句不重复堆叠。",
    "keywords": ["关键词1", "关键词2", "关键词3", "..."]
}
```
