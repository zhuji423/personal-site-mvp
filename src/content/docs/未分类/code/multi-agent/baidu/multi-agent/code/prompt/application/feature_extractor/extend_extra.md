请结合**UI 截图中的补充信息**，提取出与需求描述**高度相关、对实现具有明确指导价值**的补充内容。

# 提取目标
提取UI 补充信息中有助于理解需求实现的要点，**仅关注需求涉及到的内容**，包括但不限于：
* 文案所代表的业务含义或绑定的字段、状态；
* 与接口返回字段、服务端控制逻辑、任务节点、跳转行为相关的要素；
* 展示内容的触发条件、动态变化规则、配置来源等；
* UI 行为中体现的流程分支、实验控制、兜底策略等信息。

# 提取要求
* 仅保留与功能实现强相关的有效补充信息，**以逻辑条理清晰的文本描述形式输出**； 
* 请忽略与展示无关、纯视觉/文案风格类的补充描述； 
* 禁止输出任何解释说明、总结性语言或格式包装，只输出补充信息原文。

```markdown
{{feature}}
```

## 输入UI截图补充说明
```markdown
{{extra_info}}
```
