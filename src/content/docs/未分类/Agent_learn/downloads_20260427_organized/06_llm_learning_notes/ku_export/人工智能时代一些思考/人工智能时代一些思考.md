# 人工智能时代一些思考
一、人工智能三大领域现代人工智能在通讯、感知与行动方面形成三个主要分支：

计算机视觉（CV）、自然语言处理（NLP）机器人二、计算机视觉（CV）2.1 常见任务1）图像分类（Image Classification）识别图像中物体的类别。

人脸识别、手写字识别、车牌号识别、缺陷检测

传统机器学习算法：特征描述算法（如sift，surf等）+SVM分类器，深度学习算法：VGG16，Resnet系列（推荐）

2）目标检测（Object Localization）识别图像中单个目标的边框以及标签。用途：无人驾驶车辆检测、人脸关键点检测、人骨骼关键点检测、文本检测

经典算法

传统机器学习算法：滑动窗口+分类算法

深度学习算法：faster-rcnn（推荐），yolo（推荐）

发展路径：https://zhuanlan.zhihu.com/p/240935815

3）目标跟踪（Visual Tracking）给出目标在视频中第一帧的初始状态（如位置、尺寸），自动估计目标物体在后续帧中的状态。用途：监控预警，数据集：OTB、VOT。

经典算法

生成类方法：在当前帧对目标区域建模，下一帧寻找与模型最相似的区域就是预测位置，比较著名的有卡尔曼滤波，粒子滤波，mean-shift等，推荐算法ASMS、DAT。

判别类方法：图像特征+机器学习， 当前帧以目标区域为正样本，背景区域为负样本，机器学习方法训练分类器，下一帧用训练好的分类器找最优区域，经典判别类方法推荐Struck和TLD。

深度学习类方法：目前不适合落地，VOT2015的冠军MDNet，VOT2016的冠军TCNN，速度方面比较突出的SiamFC、GOTURN。

相关滤波：最经典的高速相关滤波类跟踪算法CSK, KCF/DCF, CN。

发展路径：https://www.zhihu.com/question/26493945/answer/156025576

4）语义分割（Semantic Segmentation）标出图像中每个像素点所属的类别，属于同一类别的像素点用一个颜色标识。

传统机器学习算法：特征提取+Grap，深度学习算法：U-net，deeplab系列

5）实例分割（Instance Segmentation）不仅要标注出物体位置，还需要标注出物体的外形轮廓。

mask-rcnn

6）图像处理（Image Processin）超分辨重建、图像恢复（去雾）

7）图像理解（Image Understanding）图像问答和描述、图像与视频检索

8）生成对抗网络 GAN文字描述生成图像、风格迁移、超分辨率、图像补全

9）实时定位建图 SLAM自主定位、导航与即时地图构建

10）三维点云和3D重建图片生成3d 模型
