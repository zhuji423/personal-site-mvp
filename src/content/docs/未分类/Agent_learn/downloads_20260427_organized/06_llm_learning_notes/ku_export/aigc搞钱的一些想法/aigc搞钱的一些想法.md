# aigc搞钱的一些想法
1、aigc作画工具：midjourney（商用，niji），stable diffusion（开源）

需求：

普通人：需求量大、快速上手、定制化少，功能集中在app上；特定场景：变现有一定难度，对行业有一定了解

方向：

艺术照生成（上传几张照片生成艺术照）海报生成器（活动海报、降价销售海报、节假日海报，内容和信息指定）小天才画家（把小孩子的涂鸦转为3d）表情制作生成器（用于微信平台表情，gif版需要结合其他工具）Q版形象生成（上传动漫截图，产出Q版头像，是否版权问题？）绘本制作（可结合gpt自动生成故事走向快速选定或自己写故事走向生成画面，难点在于形象的前后一致性）ip设计（特定场景，需要平台支持）广告图生成（假人模特秒变大美女、大帅哥）小说封面生成（特定场景）菜单生成（特定场景）详情：

2、aigc文本工具：chatgpt4（💰），chatgml（开源，中文），llama（开源，英文效果更好）

需求：

ai文本首先想到各种辅助工具，提炼主题、进行润色、统计……nononono！这些都是为爱发电，门槛也不高，多想想体量大有钱的大公司在哪些可以降低人工成本方向：

银行：【催收客服系统】贷款收账啊，那么多烂帐，催收客服，有理有据自动扯皮强调法律持续沟通，好实现大收益！游戏行业：【举报客服系统】打游戏有人送，举报还不成功，举报想要的是罚吗，是想发泄情绪，实时有个自动客服有理有据好生安慰，（肯定有人被演举报不成功，点了人工反馈填半天，填完也没人理，越想越气退游的）；【npc自动台词生成】这个在做的就比较多了，让不重要的npc也有小惊喜基金？：【领域资讯政府倾向分析，提前预警行业宽基走向】这个还是算了，大A亏麻了旅游业：智能导航，耳机语音交互，主要功能：1）路径指引，在哪里往哪边走，哪里可以买吃的哪里有卫生间出口怎么走 2）经典&文物介绍，哪块排队人少
