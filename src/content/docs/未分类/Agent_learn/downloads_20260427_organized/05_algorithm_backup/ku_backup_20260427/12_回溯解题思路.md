回溯解题思路

## 框架
回溯法的本质是暴力穷举，解决回溯问题即是一个决策树的遍历过程。无论是哪种形式，本质都是穷举所有解，并且这些解呈树状结构，所以利用回溯算法框架，稍改代码即可求解。

```
result = []
def backtrack(选择列表, 路径):
    if 满足结束条件:
        result.add(路径)
        return

    for 选择 in 选择列表:
        # 做选择
        路径.add(选择)
        将该选择从选择列表移除
        backtrack(选择列表, 路径) # 核心 递归调用之前【做选择】，调用之后【撤销选择】
        # 撤销选择
        路径.remove(选择)
        将该选择再加入选择列表
```
## 一、排列/组合/子集
### 1.元素无重复不可复选
#### [中]全排列
[https://leetcode.cn/problems/permutations/solutions/1540935/by-huan-huan-20-hblf/](https://leetcode.cn/problems/permutations/solutions/1540935/by-huan-huan-20-hblf/)

```
class Solution(object):
    def permute(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        res = []
        use = [False] * (len(nums))
        def back(cur):
            if len(cur) == len(nums):
                res.append(cur[:])
                return 
            for i in range(len(nums)):
                if use[i]:
                    continue
                cur.append(nums[i])
                use[i] = True
                back(cur)
                cur.pop()
                use[i] = False
        back([])
        return res
        
```
nums中的元素是唯一的，每个元素只能被使用一次。组合问题为例，nums=[2,3,6,7]，和为7的组合只有[7]。

子集和组合问题实则是一样的，大小为 k 的组合就是大小为 k 的子集。

#### [中]子集
[https://leetcode.cn/problems/subsets/description/](https://leetcode.cn/problems/subsets/description/)

给你一个整数数组 nums ，数组中的元素互不相同。返回该数组所有可能的子集（幂集）。解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

其实在做全排列的过程中，本身就存在子集，只是我们并没有保存，如果在结束条件处略作修改，改为没有条件，每次节点的值本身就是子集，将其加入到结果中即可。但这样还存在重复，因为在全排列过程中可能会出现选择b作为开头但还可以选a，所以刚刚那样修改后结果会出现[a,b]，[b,a]，在集合中这二者是重复的。规避方式也很简单，每次从当前元素的下一个元素开始选。

为避免重复，从index开始遍历，无需use记录状态，但需要index记录位置

```
class Solution(object):
    def subsets(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        res = []
        def back(index, cur):
            res.append(cur[:])
            for i in range(index, len(nums)):
                cur.append(nums[i])
                back(i + 1, cur)
                cur.pop()

        back(0, [])
        return res
        
```
#### [中]组合
[https://leetcode.cn/problems/combinations/description/](https://leetcode.cn/problems/combinations/description/)

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。你可以按 任何顺序 返回答案。

这是标准的组合问题，但翻译一下就变成子集问题了：给你输入一个数组 nums = [1,2..,n] 和一个正整数 k，请你生成所有大小为 k 的子集。

还是以 nums = [1,2,3] 为例，刚才求所有子集，就是把所有节点的值都收集起来；现在只需要把第 2 层（根节点视为第 0 层）的节点收集起来，就是大小为 2 的所有组合：

在代码上，只是需要添加结束条件：

```
class Solution(object):
    def combine(self, n, k):
        """
        :type n: int
        :type k: int
        :rtype: List[List[int]]
        """
        res = []
        def back(index, cur):
            if len(cur) == k:
                res.append(cur[:])
                return
            for i in range(index, n):
                cur.append(i + 1)
                back(i + 1, cur)
                cur.pop()

        back(0, [])
        return res
        
```
**总结**：

* **全排列：**从0开始遍历，需要use记录状态
* **子集、组合：**从index开始遍历，无需use记录状态，但需要index记录位置



### 2.元素可重复不可复选
nums中的元素可以存在重复，每个元素只能被使用一次。组合问题为例，nums=[2,5,2,1,2]，和为7的组合有[2,2,2,1]和[5,2]两种。

#### [中]子集II
[https://leetcode.cn/problems/subsets-ii/description/](https://leetcode.cn/problems/subsets-ii/description/)

给你一个整数数组 nums ，其中可能包含重复元素，请你返回该数组所有可能的子集（幂集）。解集 不能 包含重复的子集。返回的解集中，子集可以按 任意顺序 排列。

以 nums = [1,2,2] 为例，为了区别两个 2 是不同元素，写作 nums = [1,2,2']。显然，两条值相同的相邻树枝会产生重复，如都有2：[1,2]，[1,2']，所以需要进行剪枝，如果一个节点有多条值相同的树枝相邻，则只遍历第一条，剩下的都剪掉，不要去遍历：遍历了[1,2]就不再遍历[1,2']。

在代码实现上，先对nums进行排序，在遍历时如果当前元素nums[i]与前一个元素相等nums[i] == nums[i-1]则跳过该元素

```
class Solution(object):
    def subsetsWithDup(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        res = []
        nums.sort()
        def back(index, cur):
            res.append(cur[:])
            for i in range(index, len(nums)):
                # 跳过与上一个重复的
                if index < i and nums[i] == nums[i - 1]:
                    continue
                cur.append(nums[i])
                back(i + 1, cur)
                cur.pop()

        back(0, [])
        return res
        
```
### 3.元素无重复可复选
nums中的元素是唯一的，每个元素可以被使用若干次。组合问题为例，nums=[2,3,6,7]，和为7的组合有[7]、[2,2,3]两种。

#### [中]组合总和
[https://leetcode.cn/problems/combination-sum/description/](https://leetcode.cn/problems/combination-sum/description/)

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。

这道题说是组合问题，实际上也是子集问题：

```
class Solution(object):
    def combinationSum(self, candidates, target):
        """
        :type candidates: List[int]
        :type target: int
        :rtype: List[List[int]]
        """
        res = []
        def back(index, cur, sum):
            if sum == target:
                res.append(cur[:])
                return
            # 避免无限重复 需要结束条件
            if sum > target:
                return
            
            for i in range(index, len(candidates)):
                cur.append(candidates[i])
                sum += candidates[i]
                # 从i开始 可以重复
                back(i, cur, sum)
                cur.pop()
                sum -= candidates[i]

        back(0, [], 0)
        return res
```

```
def dfs(grid: List[List[int]], i: int, j: int):
    rows, cols = len(grid), len(grid[0])
    # 超出索引边界
    if i < 0 or j < 0 or i >= rows or j >= cols:
        return
    
    # 如果这个格子不是岛屿，直接返回
    if (grid[i][j] != 1) {
        return;
    }

    # 进入当前节点 (i, j)
    grid[i][j] = 2;

    # 访问上、下、左、右四个相邻结点
    dfs(grid, i - 1, j);
    dfs(grid, i + 1, j);
    dfs(grid, i, j - 1);
    dfs(grid, i, j + 1);
```
岛屿问题，就是在所有值为 1 的陆地格子上做 DFS 遍历：

* 0 —— 海洋格子
* 1 —— 陆地格子（未遍历过）
* 2 —— 陆地格子（已遍历过）

#### [易]岛屿的周长
[https://leetcode.cn/problems/island-perimeter/description/](https://leetcode.cn/problems/island-perimeter/description/)

找到陆地后，周长 = 遇到海 + 超边界

```
class Solution(object):
    def islandPerimeter(self, grid):
        """
        :type grid: List[List[int]]
        :rtype: int
        """
        self.res  = 0
        rows, cols = len(grid), len(grid[0])

        def dfs(i, j):
            
            # 超边界 + 1
            if i < 0 or j < 0 or i >= rows or j >= cols:
                self.res += 1
                return
            
            # 非岛屿
            if grid[i][j] != 1:
                if grid[i][j] == 0:  # 海 + 1
                    self.res  += 1
                return
            
            grid[i][j] = 2

            dfs(i - 1, j)
            dfs(i + 1, j)
            dfs(i, j - 1)
            dfs(i, j + 1)

        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == 1:
                    # 只有一个岛
                    dfs(i , j)

        return self.res 
        
```

class Solution(object):

        :type grid: List[List[int]]

class Solution(object):
    def closedIsland(self, grid):
        """
        :type grid: List[List[int]]
        :rtype: int

        def dfs(i, j):

                return

                return

            dfs(i - 1, j)
            dfs(i + 1, j)
            dfs(i, j - 1)
            dfs(i, j + 1)

        for i in range(m):
            dfs(i, 0)
            dfs(i, n - 1)

            dfs(0, j)
            dfs(m - 1, j)

```
class Solution(object):
    def countSubIslands(self, grid1, grid2):
        """
        :type grid1: List[List[int]]
        :type grid2: List[List[int]]
        :rtype: int
        """
        # 在DFS过程中同时检查grid1的对应位置
        # 只有整个岛屿的所有格子都满足grid1对应为1，才计数
        self.is_ok = True
        res = 0
        m, n = len(grid2), len(grid2[0])

        def dfs(i, j):
            if i < 0 or j < 0 or i >= m or j >= n:
                return 
            
            if grid2[i][j] != 1:
                return 
            
            if grid1[i][j] != 1:
                self.is_ok = False
            grid2[i][j] = 2

            dfs(i - 1, j)
            dfs(i + 1, j)
            dfs(i, j - 1)
            dfs(i, j + 1)


        for i in range(m):
            for j in range(n):
                if grid2[i][j] == 1:
                    self.is_ok = True
                    dfs(i, j)
                    if self.is_ok:
                        res += 1
                    
        return res
        
```

#### [中]括号生成
[https://leetcode.cn/problems/generate-parentheses/description/](https://leetcode.cn/problems/generate-parentheses/description/)

```
class Solution(object):
    def generateParenthesis(self, n):
        """
        :type n: int
        :rtype: List[str]
        """
        # 只有在左括号数量小于n时可以添加左括号
        # 只有在右括号数量小于左括号时可以添加右括号        
        res = []
        def back(cur, l, r):
            if len(cur) == 2 * n:
                res.append(cur)
                return
            if l < n:
                back(cur + '(', l + 1, r)
            if r < l:
                back(cur + ')', l, r + 1)

        back('', 0, 0)
       
        return res
```
## 四、集合划分
#### [中]划分为k个相等的子集
[https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/description/](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/description/)

```
class Solution(object):
    def canPartitionKSubsets(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: bool
        """
        if sum(nums) % k !=0:
            return False

        target = sum(nums) // k
        nums.sort(reverse=True)
        used = [False] * len(nums)

        def back(index, add, count):
            if count == k - 1:
                return True

            if add == target:
                return back(0, 0, count + 1)
            
            for i in range(index, len(nums)):
                if not used[i] and (add + nums[i]) <= target:
                    used[i] = True
                    if back(i + 1, add + nums[i], count):
                        return True
                    used[i] = False

                    # 剪枝：如果这个数单独放都不行，那后面相同的数也没必要试
                    if add == 0:
                        break   
                    # 剪枝：跳过相同元素
                    while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                        i += 1

            return False    

        return back(0, 0, 0)
        
```

class Solution(object):
    def solveSudoku(self, board):
        """
        :type board: List[List[str]]
        :rtype: None Do not return anything, modify board in-place instead.
        """
        def is_ok(i, j, n):
            # 检查横竖
            for k in range(9):
                if board[i][k] == n:
                    return False    
                if board[k][j] == n:
                    return False  
            # 检查3*3
            start_i, start_j = 3 * (i // 3), 3 * (j // 3)
            for x in range(3):
                for y in range(3):
                    if board[start_i + x][start_j + y] == n:
                        return False  
            return True

        
        def back():
            for i in range(9):
                for j in range(9):
                    if board[i][j] == '.':
                        for n in range(1, 10):
                            if is_ok(i, j, str(n)):
                                board[i][j] = str(n)
                                if back():
                                    return True
                                board[i][j] = '.'
                        return False
            return True
                                  
        back()
        
```

class Solution(object):
    def solveNQueens(self, n):
        """
        :type n: int
        :rtype: List[List[str]]
        """
        board = [-1] * n  # board[i]表示第i行皇后所在的列
        res = []
        def gen():
            return ['.' * i + 'Q' + '.' * (n - i - 1) for i in board]
                
        def is_ok(i, j):
            for x in range(i):
                # 列
                if board[x] == j:
                    return False
                # 对角线
                if abs(x - i) == abs(board[x] - j):
                    return False
            return True

        def back(i):
            if i == n:
                res.append(gen())
                return
            for j in range(n):
                if is_ok(i, j):
                    board[i] = j
                    back(i + 1)
                    board[i] = -1

        back(0)
        return res
        
```
