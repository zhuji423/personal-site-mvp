# 语音识别算法
一、语音识别过程编码过程

将声音信号按照很短的时间间隔，切成小段，成为帧。对于每一帧，可以通过某种规则（例如MFCC特征）提取信号中的特征，将其变成一个多维向量。向量中的每个维度都是这帧信号的一个特征。

![](https://ku.baidu-int.com/wiki/attach/image/api/imageDownloadAddress?attachId=be1979050f9b4ade85130c39fdb926a0&docGuid=1A09zIvEALbJ8j)

解码过程

声学模型通过处理编码得到的向量，将相邻的帧组合起来变成音素，如中文拼音中的声母和韵母，再组合起来变成单个单词或汉字。语言模型用来调整声学模型所得到的不合逻辑的字词，使识别结果变得通顺。两者都需要大量数据用来训练。

![](https://ku.baidu-int.com/wiki/attach/image/api/imageDownloadAddress?attachId=a29ae6d1c1524a9aaa60e2a1f2eb7e61&docGuid=1A09zIvEALbJ8j)

许多研究将语音识别问题看做声学模型与语音模型两部分。后来，基于深度学习和大数据的端对端（End-to-End）方法发展起来，把声学模型和语言模型融为了一体。
