# 特征监控
一、背景分析1.1 机器学习监控重要性训练数据集代表模型的真实情况：这是收集尽可能多的数据对于性能良好、稳健的模型至关重要的原因之一。然而，该模型仅根据现实快照进行训练；世界在不断变化。这意味着模型学习的概念会随着时间的推移而变化，因此其性能会下降。

模型的性能下降往往是难以监控的，在机器学习领域，应该担心的不仅是代码，还有数据质量及其依赖关系，机器学习模型比传统软件具有更多的依赖组件、更多的潜在故障模式。通常，这些数据源完全不受我们控制，即使对数据及建模管道做到了完美的维护，环境的变化也会导致模型性能下降，甚至是发生巨变。在机器学习监控中，这个抽象问题需要得到重视，需要量化数据分布的变化情况，这与检查服务器负载是完全不同的任务。通常模型性能的下降是悄无声息的，往往通过标注标签感知到时已经滞后了一段时间，而这个过程中的模型都是正常工作的，在模型领域没有监控手段的情况下，这种无形的停机时间是令人担忧的。通过机器学习监控能尽早发现模型的潜在性能下降风险并尽早做出反应（更改特征处理逻辑&重新训练优化模型）。

ML 监控是一个全面的过程：

特征数据：机器学习监控系统监控训练和生产过程中使用的特征数据，以确保其质量、一致性和准确性，以及安全性和有效性。模型：在模型部署之后监控模型。监控系统寻找模型中的变化，并在发生变化时提醒数据科学家。环境：开发和部署模型的环境也有助于模型的整体性能。如果任一环境存在问题，都会影响性能。 ML 监控系统检查系统 CPU、内存、磁盘、I/O 利用率等指标。模型指标通过数字化已实现监控，模型部署与kirin支持环境监控，目前本文主要聚焦于对特征数据的监控。

1.2 机器学习模型性能下降的特征数据原因分析机器学习模型性能下降的常见原因：

线下模型与线上数据分离：构建模型的团队（数据科学家）和负责生产模型的团队（工程/机器学习工程师）之间存在分离。这种分离通常是由于编程语言专业知识的差异或仅仅是由于不同的组织结构而发生的。在这些情况下，工程师实施的生产模型与数据科学家的预期实施有很大不同是很常见的。因此，生产模型的逻辑无意中与预期逻辑不同。应用更新数据分布变更：当这些应用程序被更新/修改时，发送到模型的数据不再是模型所期望的。所有这一切都在数据科学团队不知道的情况下发生。虽然数据在数据完整性方面可能看起来不错，但模型的行为可能会由于这种随时间发生的分布变化而发生变化。特征处理方式变更：数据在最终到达 ML 模型之前要经过许多转换步骤。对数据处理管道的更改，无论是处理作业还是队列/数据库配置的更改，都可能破坏数据并破坏数据发送到的模型。训练完成后，模型期望将特定数据模式作为输入。由于特征转换或数据管道的早期阶段导致的模式更改可能会导致将格式错误的特征发送到模型。丢弃的字段：当处理作业失败时，通常会将重要字段留空。有时，可能会简单地省略或弃用其 API 中的某个字段，并未另行通知模型方。类型不匹配：由于第三方数据源的变化或内部数据管道的变化，模型可能会遇到意外的数据类型。当它期待一个 int 时，它可能会收到一个“Big int”；或期望 ASCII 时的 unicode 字符串。即本应为整数的字段可互换为整数和字符串（反之亦然！）。所有这些情况通常会导致不必要的处理错误和不正确的预测。默认值变更：在代码中都使用默认值：可以是0，也可以是-1；也许您选择的默认值是 NaN 或更好的东西。代码，尤其是模型，假设默认值不会改变。另一个团队在未通知数据科学团队的情况下更改其默认值是常见的问题来源，会导致模型的意外输入和意外行为。值超出范围：处理数据时，我们通常从分析数据开始。我们寻找唯一值，检查值范围和一般分布。超出模型预期范围的输入值可能会导致意外的预测。密切注意模型中特征数据变化并尽快检测到原因能够保证ML模型良好运行。

2.2 统计原理2.2.1 数据分布差异性检测（KS-检验）CDF 累积分布函数累积分布函数(Cumulative Distribution Function)，又叫分布函数，是概率密度函数的积分，能完整描述一个实随机变量X的概率分布。一般以大写CDF标记,，与概率密度函数probability density function（小写pdf）相对。

KS-检验D值计算对以下两组数据做KS-检验：

a = [1.26, 0.34, 0.70, 1.75, 50.57, 1.55, 0.08, 0.42, 0.50, 3.20, 0.15, 0.49, 0.95, 0.24, 1.37, 0.17, 6.98, 0.10, 0.94, 0.38]
b = [2.37, 2.16, 14.82, 1.73, 41.04, 0.23, 1.32, 2.91, 39.41, 0.11, 27.44, 4.51, 0.51, 4.50, 0.18, 14.68, 4.66, 1.30, 2.06, 1.19]

对a组数据从小到大进行排序：

sorted a=[0.08, 0.10, 0.15, 0.17, 0.24, 0.34, 0.38, 0.42, 0.49, 0.50, 0.70, 0.94, 0.95, 1.26, 1.37, 1.55, 1.75, 3.20, 6.98, 50.57]。

观察发现前10%的数据（2/20）小于0.15，前85%（17/20）的数据小于3。所以，对任何数x来说，其累积分段就是所有比x小的数在数据集中所占的比例。

对于数0.15，其累积分段为10%，对于数3，其累积分段为85%......求出a组数据中所有数的累积分段值后绘制累积分段左图所示：

可以看到大多数数据都分布在左侧（数据值比较小），这就是非正态分布的标志（注：正态分布两边小中间大）。为了更好的观测数据在x轴上的分布，可以对x轴的坐标进行非等分的划分。在数据都为正的时候有一个很好的方法就是对x轴进行log转换。

把b组数据按上述方法做同样处理，结果如下图-2，其中实线表示a组数据的累积分段，虚线表示b组数据的累积分段：

KS-检验使用的是两条累积分布曲线之间的最大垂直差作为D值（statistic D）来描述两组数据之间的差异。在此图中，D值出现在x=1附近，且D值为0.45（0.65-0.25）。

注：虽然累计分布曲线的性状会随着对数据做转换处理而改变（如log转换），但是D值的大小是不会变的。

2.2.2 特征重要性检测（肯德尔相关系数）肯德尔相关系数kendall秩相关系数（R）是指设有n个统计对象，每个对象有两个属性的系数。将所有统计对象按属性1取值排列，不失一般性，设此时属性2取值的排列是乱序的。设P为两个属性值排列大小关系一致的统计对象对数。

        Kendall(肯德尔)系数的定义：n个同类的统计对象按特定属性排序，其他属性通常是乱序的。同序对（concordant pairs）和异序对（discordant pairs）之差与总对数（n*(n-1)/2)的比值定义为Kendall(肯德尔)系数。

1）如果两个属性排名是相同的，系数为1 ，两个属性正相关。

2）如果两个属性排名完全相反，系数为-1 ，两个属性负相关。

3）如果排名是完全独立的，系数为0。

         斯皮尔曼等级相关系数对数据条件的要求没有皮尔逊相关系数严格，只要两个变量的观测值是成对的等级评定资料，或者是由连续变量观测资料转化得到的等级资料，不论两个变量的总体分布形态、样本容量的大小如何，都可以用斯皮尔曼等级相关系数来进行研究。
