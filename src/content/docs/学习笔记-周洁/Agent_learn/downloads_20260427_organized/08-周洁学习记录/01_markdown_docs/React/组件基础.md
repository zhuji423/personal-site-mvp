组件基础

### 函数组件 vs 类组件
在 React 中，组件可以分为两种主要类型：函数组件和类组件。随着 React Hooks 的引入，函数组件的功能得到了极大的增强，使得它在许多情况下成为首选。

#### 函数组件
**函数组件**是使用 JavaScript 函数定义的组件。它们通常更简洁，易于理解和测试。函数组件在 React 16.8 引入 Hooks 后变得更加强大，可以拥有状态和其他 React 特性。

```
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
```
#### 类组件
**类组件**是使用 ES6 类定义的组件。它们可以拥有状态、生命周期方法等。类组件在 React 16.8 之前是实现复杂组件的主要方式。

```
import React, { Component } from 'react';

class Counter extends Component {
  constructor(props) {
    super(props);
    this.state = {
      count: 0
    };
  }

  render() {
    return (
      <div>
        <p>You clicked {this.state.count} times</p>
        <button onClick={() => this.setState({ count: this.state.count + 1 })}>
          Click me
        </button>
      </div>
    );
  }
}
```
**对比：**

|特性|函数组件|类组件|
|-|-|-|
|定义方式|使用函数|使用 ES6 类|
|状态管理|使用 `useState`Hook|使用 `this.state`和 `this.setState`|
|生命周期方法|使用 `useEffect` Hook|使用 `componentDidMount`, `componentDidUpdate`, `componentWillUnmount` 等|
|代码简洁度|更简洁|相对冗长|
|测试|易于测试|需要更多的设置和模拟|
|Hooks 支持|支持|不支持（除非使用高阶组件或 Render Props）|

### 组件 props 和 state
在 React 中，`props` 和 `state` 是两个核心概念，它们用于管理和传递数据。

#### Props
**Props**（属性）是父组件传递给子组件的数据。子组件通过 `props` 接收这些数据，并根据这些数据进行渲染和逻辑处理。`props` 是只读的，子组件不能修改它们

```
function Welcome(props) {
  return <h1>Hello, {props.name}!</h1>;
}

function App() {
  return (
    <div>
      <Welcome name="Alice" />
      <Welcome name="Bob" />
    </div>
  );
}
```
#### State
**State**（状态）是组件内部管理的数据。组件可以通过 `setState` 方法更新 `state`，从而触发重新渲染。`state` 是可变的，组件可以根据需要修改它。

```
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
```
**对比：**

|特性|Props|State|
|-|-|-|
|数据来源|父组件传递|组件内部管理|
|数据可变性|只读|可变|
|使用场景|父组件向子组件传递数据|组件内部状态管理|
|触发重新渲染|父组件重新渲染时触发|`setState`触发|
|示例|`<Welcome name="Alice" />`|`const [count, setCount] = useState(0);`|

### 事件处理
在 React 中，事件处理是通过在 JSX 元素上绑定事件处理函数来实现的。React 的事件处理机制与原生 DOM 事件处理类似。

#### 基本事件处理
在 JSX 元素上绑定事件处理函数来处理事件。

```
function Button() {
  function handleClick() {
    alert('Button clicked!');
  }

  return (
    <button onClick={handleClick}>
      Click me
    </button>
  );
}
```
#### 传递参数
通过箭头函数或 `bind` 方法向事件处理函数传递参数。

##### **使用箭头函数**
```
function Button() {
  function handleClick(message) {
    alert(message);
  }

  return (
    <button onClick={() => handleClick('Button clicked!')}>
      Click me
    </button>
  );
}
```
##### **使用 **`bind`****
```
function Button() {
  function handleClick(message) {
    alert(message);
  }

  return (
    <button onClick={handleClick.bind(this, 'Button clicked!')}>
      Click me
    </button>
  );
}
```
#### 事件对象
在事件处理函数中，访问事件对象（`event`），它包含了事件的相关信息

```
function Input() {
  function handleChange(event) {
    console.log(event.target.value);
  }

  return (
    <input type="text" onChange={handleChange} />
  );
}
```
#### 阻止默认行为
通过调用 `event.preventDefault()` 来阻止事件的默认行为。

```
function Form() {
  function handleSubmit(event) {
    event.preventDefault();
    alert('Form submitted!');
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit">Submit</button>
    </form>
  );
}
```
#### 事件冒泡和捕获
React 支持事件冒泡和捕获机制，通过 `on[Event]Capture` 来绑定捕获阶段的事件处理函数。

```
function Parent() {
  function handleClick(event) {
    console.log('Parent clicked');
  }

  return (
    <div onClickCapture={handleClick}>
      <Child />
    </div>
  );
}

function Child() {
  function handleClick(event) {
    console.log('Child clicked');
  }

  return (
    <button onClick={handleClick}>
      Click me
    </button>
  );
}
```
### 组件生命周期
在 React 中，组件的生命周期是指组件从创建到销毁的整个过程。React 提供了多个生命周期方法，允许在组件的不同阶段执行特定的操作。

#### 挂载阶段（Mounting）
挂载阶段是指组件被插入到 DOM 中的过程。

* `constructor()`：用于初始化组件的状态和绑定事件处理函数。
* `static getDerivedStateFromProps()`：用于根据 `props` 的变化更新组件的 `state`。
* `render()`：返回组件的 UI 结构，是类组件中唯一必须实现的方法。
* `componentDidMount()`：在组件挂载到 DOM 后执行，适合进行数据获取、订阅事件、DOM 操作等。

```
class MyComponent extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
    console.log('Constructor');
  }

  static getDerivedStateFromProps(props, state) {
    console.log('getDerivedStateFromProps');
    return null;
  }

  componentDidMount() {
    console.log('componentDidMount');
    // 在这里可以进行一些初始化操作，如数据获取
  }

  render() {
    console.log('render');
    return <div>Count: {this.state.count}</div>;
  }
}
```
#### 更新阶段（Updating）
更新阶段是指组件的 `props` 或 `state` 发生变化，导致组件重新渲染的过程。

* `static getDerivedStateFromProps()`：根据 `props` 的变化更新组件的 `state`。
* `shouldComponentUpdate()`：决定组件是否需要重新渲染。
* `render()`：返回组件的 UI 结构，是类组件中唯一必须实现的方法。
* `getSnapshotBeforeUpdate()`：在组件更新之前获取 DOM 的快照。
* `componentDidUpdate()`：在组件更新后执行，适合进行 DOM 操作、网络请求等。

**示例：**

```
class MyComponent extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  static getDerivedStateFromProps(props, state) {
    console.log('getDerivedStateFromProps');
    return null;
  }

  shouldComponentUpdate(nextProps, nextState) {
    console.log('shouldComponentUpdate');
    return nextState.count !== this.state.count;
  }

  getSnapshotBeforeUpdate(prevProps, prevState) {
    console.log('getSnapshotBeforeUpdate');
    return null;
  }

  componentDidUpdate(prevProps, prevState, snapshot) {
    console.log('componentDidUpdate');
    // 在这里可以进行一些更新后的操作
  }

  handleClick = () => {
    this.setState({ count: this.state.count + 1 });
  };

  render() {
    console.log('render');
    return (
      <div>
        <p>Count: {this.state.count}</p>
        <button onClick={this.handleClick}>Increment</button>
      </div>
    );
  }
}
```
#### 卸载阶段（Unmounting）
卸载阶段是指组件从 DOM 中移除的过程。

* `componentWillUnmount()` 是 `Unmounting` 阶段唯一一个生命周期方法，用于在组件被销毁之前执行清理操作。
* `getSnapshotBeforeUpdate()` 虽然不是 `Unmounting` 阶段的方法，但在某些情况下（例如需要捕获 DOM 信息）可能会在组件卸载前被调用。

```
class MyComponent extends React.Component {
  componentDidMount() {
    console.log('componentDidMount');
    // 在这里可以进行一些初始化操作，如数据获取
  }

  componentWillUnmount() {
    console.log('componentWillUnmount');
    // 在这里可以进行一些清理操作，如取消定时器
  }

  render() {
    return <div>My Component</div>;
  }
}
```
#### 错误处理（Error Handling）
错误处理阶段是指组件在渲染过程中发生错误时触发的生命周期方法。

* `static getDerivedStateFromError(error)` 用于在捕获错误后更新组件的状态，从而显示备用 UI。
* `componentDidCatch(error, info)` 用于记录错误信息或执行其他副作用，例如将错误信息发送到错误跟踪服务。

```
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError(error) {
    console.log('getDerivedStateFromError');
    return { hasError: true };
  }

  componentDidCatch(error, info) {
    console.log('componentDidCatch', error, info);
    // 在这里可以进行一些错误处理操作，如记录日志
  }

  render() {
    if (this.state.hasError) {
      return <h1>Something went wrong.</h1>;
    }

    return this.props.children;
  }
}
```
