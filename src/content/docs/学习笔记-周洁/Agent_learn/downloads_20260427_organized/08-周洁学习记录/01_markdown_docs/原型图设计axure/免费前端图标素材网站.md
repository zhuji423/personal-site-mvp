免费前端图标素材网站

## Icons8
网站地址：[https://icons8.com](https://icons8.com)

一个国外著名包括图标，照片，插画和音效素材网站

## Iconduck
网站地址：[https://iconduck.com/](https://iconduck.com/)

Iconduck，界面上看着一般，但是也是一个不错的图标素材库，有提供超过一百万个图标，一切图标都是免费可以商用的。Iconduck 提供14种授权版本的分类，比如Apache License 2.0、CC0、MIT License、GNU General Public License v3.0等

## Toicon
网站地址：[https://www.toicon.com](https://www.toicon.com)

Toicon，是一个提供个性化的像素矢量图标。所有的图标素材都加入 CC 授权可免费商业用途。

## Iconfinder
网站地址：[https://www.iconfinder.com](https://www.iconfinder.com)

Iconfinder，这个平台提供提供超过四百多万个免费 icon 图标下载使用，但是需要注意，有部分是需要收费的。免费的大概有32万个多图标

## iconscout
网站地址：[https://iconscout.com](https://iconscout.com)

iconscout，我们可以看到这个平台有提供有超过 1200 多个贡献者的 200 万+免版税图标和图像资源免费下载。包括免费图标、免费插图、免费照片、品牌LOGO等。

## Flaticon
网站地址：[https://www.flaticon.com](https://www.flaticon.com)

Flaticon，一个依旧来自国外的提供海量免费图标素材库，提供 PNG、SVG、EPS、PSD 和 BASE 64 矢量图标格式

## iconstore
网站地址：[https://iconstore.co/](https://iconstore.co/)

iconstore，这个网站看着简单，但是图标确实还是比较多的，分类分的很细致。而且版权申明明确说到可以支持，支持个人和商用，可以修改，无需注明出处。

## Flat icon design
网站地址：[http://flat-icon-design.com](http://flat-icon-design.com)

Flat icon design，是一个日本的网站提供的资源，虽然资源比较少，但是图标都是免费可以商用的
