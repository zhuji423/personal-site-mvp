常见配置文件

配置文件是用于存储应用程序、软件或系统设置的文件。不同类型的应用程序和系统使用不同格式的配置文件。以下是一些常见的配置文件格式及其用途：

### 1. **INI 文件**
* **格式**: `key=value`
* **用途**: 用于存储简单的键值对配置，通常用于Windows应用程序。
* **示例**:

```
[Section]
key1=value1
key2=value2
```
### 2. **XML 文件**
* **格式**: 使用标签和属性来表示数据结构。
* **用途**: 用于存储复杂的数据结构，广泛用于Web服务和配置文件。
* **示例**:

```
<configuration>
    <appSettings>
        <add key="key1" value="value1" />
        <add key="key2" value="value2" />
    </appSettings>
</configuration>
```
### 3. **JSON 文件**
* **格式**: 使用键值对和数组来表示数据结构。
* **用途**: 用于存储结构化数据，广泛用于Web应用程序和API。
* **示例**:

```
{
    "key1": "value1",
    "key2": "value2",
    "array": [1, 2, 3]
}
```
### 4. **YAML 文件**
* **格式**: 使用缩进来表示数据结构，比JSON更简洁。
* **用途**: 用于存储配置文件，特别是在DevOps和CI/CD工具中。
* **示例**:

```
key1: value1
key2: value2
array:
  - 1
  - 2
  - 3
```
### 5. **TOML 文件**
* **格式**: 类似于INI文件，但更严格和易读。
* **用途**: 用于存储配置文件，特别是在Rust和Cargo项目中。
* **示例**:

```
key1 = "value1"
key2 = "value2"
[section]
key3 = "value3"
```
### 6. **Properties 文件**
* **格式**: `key=value`
* **用途**: 用于存储Java应用程序的配置，特别是在Spring框架中。
* **示例**:

```
key1=value1
key2=value2
```
### 7. **Environment Variables**
* **格式**: 系统环境变量。
* **用途**: 用于存储敏感信息或全局配置，特别是在容器化环境中。
* **示例**:

```
export KEY1=value1
export KEY2=value2
```
### 8. **Docker Compose 文件**
* **格式**: YAML格式。
* **用途**: 用于定义和运行多容器Docker应用程序。
* **示例**:

```
version: '3'
services:
  web:
    image: nginx
    ports:
      - "80:80"
```
### 9. **Kubernetes Manifest 文件**
* **格式**: YAML格式。
* **用途**: 用于定义Kubernetes资源，如Pod、Service、Deployment等。
* **示例**:

```
apiVersion: v1
kind: Pod
metadata:
  name: example-pod
spec:
  containers:
  - name: example-container
    image: nginx
```
### 10. **Shell 脚本**
* **格式**: 使用Shell命令和变量。
* **用途**: 用于自动化任务和配置环境。
* **示例**:

```
#!/bin/bash
export KEY1=value1
export KEY2=value2
```
### 11. **Configuration Files in Programming Languages**
* **格式**: 使用编程语言的语法。
* **用途**: 用于存储配置，特别是在动态语言中，如Python的`config.py`。
* **示例**:

```
# config.py
KEY1 = "value1"
KEY2 = "value2"
```
### 12. **Database Configuration Files**
* **格式**: 特定于数据库的格式，如MySQL的`my.cnf`。
* **用途**: 用于配置数据库服务器。
* **示例**:

```
[mysqld]
port=3306
datadir=/var/lib/mysql
```
### 13. **Web Server Configuration Files**
* **格式**: 特定于Web服务器的格式，如Apache的`httpd.conf`或Nginx的`nginx.conf`。
* **用途**: 用于配置Web服务器的行为。
* **示例**:

```
server {
    listen 80;
    server_name example.com;
    location / {
        root /var/www/html;
        index index.html;
    }
}
```
### 14. **Git Configuration Files**
* **格式**: INI格式。
* **用途**: 用于配置Git的行为，如用户信息、别名等。
* **示例**:

```
[user]
    name = John Doe
    email = john.doe@example.com
```
### 15. **SSH Configuration Files**
* **格式**: 特定于SSH的格式。
* **用途**: 用于配置SSH客户端和服务器。
* **示例**:

```
Host example
    HostName example.com
    User john
    IdentityFile ~/.ssh/id_rsa
```
