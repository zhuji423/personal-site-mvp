#### 1. 什么是Live2D模型？
Live2D是一种创新的动画技术，它可以将二维的静态图像转换为动态的、可交互的动画角色。与传统的3D建模不同，Live2D保持了2D绘画的美感，同时赋予其动态效果。通过Live2D技术，设计师和开发者可以创建具有丰富表情和动作的2D角色，这些角色可以在游戏、动画、虚拟主播等多个领域中使用。

Live2D技术的核心在于其独特的变形系统。通过对二维图像进行多层次的网格划分和变形点的设置，Live2D可以实现复杂的动作和表情变化，同时保持图像的清晰度和美感。这种技术不仅减少了动画制作的工作量，还使得动画角色更加生动和自然。

画师只需要绘制一张原画，然后将身体、五官、发型、服装等2D图片放到全3D的模型模板上。

![2D人物，以及分解完毕的各种细节部分](/personal-site-mvp/img/doc-placeholder.svg "2D人物，以及分解完毕的各种细节部分")
这样的成品将保留2D手绘的精细，同时在小范围旋转视角上也能做到毫无违和感。不过这一技术目前的缺点在于无法实现复杂图形、人物的大幅旋转。

#### 2. Live2D模型的应用场景
* **游戏开发**：在角色扮演游戏和视觉小说中，Live2D模型可以用于角色对话、互动场景和过场动画，提升游戏的沉浸感和互动性。例如，在《LoveLive! School Idol Festival》游戏中，角色的动态立绘就使用了Live2D技术，增加了玩家与角色之间的互动感。

![](/personal-site-mvp/img/doc-placeholder.svg "")
* **虚拟主播**：在直播平台上，虚拟主播可以通过Live2D技术进行实时互动和表情变化，增强观众的参与感和互动体验。虚拟主播如绊爱（Kizuna AI）通过Live2D技术，实现了与观众的实时互动，吸引了大量粉丝。
* **动画制作**：Live2D模型可以用于动画短片和广告制作，通过关键帧动画系统，创建复杂的角色动作和表情变化。例如，许多移动游戏的开场动画和过场动画都使用了Live2D技术，使动画更加生动和吸引人。

![食物语手游自制剧H5小程序](/personal-site-mvp/img/doc-placeholder.svg "食物语手游自制剧H5小程序")
* **移动应用**：在移动应用中，Live2D模型可以作为虚拟助理或互动角色，增加用户体验的趣味性和互动性。例如，一些手机应用中的虚拟宠物或助手角色，就使用了Live2D技术，使其能够与用户进行互动。

#### 3. Live2D Cubism介绍
Cubism是Live2D公司开发的一款专业软件，用于创建和编辑Live2D模型。Cubism提供了一个完整的工作流程，从素材导入、模型编辑到动画制作和导出，支持多种格式和平台，方便开发者在不同的应用场景中使用。Cubism的核心优势在于其强大的变形和动画系统，使得二维图像可以实现复杂的动态效果，同时保持高质量的视觉效果。

#### 4. Cubism的主要功能
* **模型编辑**：Cubism提供了多种绘图和编辑工具，用于创建和调整2D图像的各个部分。用户可以对图像进行分层处理，将角色的各个部分（如头部、身体、手臂、腿等）分开，以便后续的变形和动画制作。
* **网格生成**：Cubism可以自动或手动生成网格，用于定义图像的变形区域。网格的精细度直接影响变形效果的质量，因此用户可以根据需要调整网格的密度和形状，以获得最佳效果。
* **变形工具**：通过添加变形点和变形器，用户可以控制图像的动态效果。变形点用于定义图像的变形区域，变形器则用于创建复杂的变形效果。例如，可以为角色的面部添加多个变形点，以控制眼睛、嘴巴和表情的变化。
* **物理引擎**：Cubism内置了物理引擎，可以模拟真实世界的物理效果，如重力、风力等。用户可以为角色的头发、衣服等部分添加物理效果，使其在角色运动时产生自然的摆动和飘动效果。
* **关键帧动画**：Cubism提供了强大的关键帧动画系统，用户可以通过设置关键帧，为模型创建复杂的动画效果。关键帧之间的过渡由Cubism自动计算，生成平滑的动画效果。
* **实时预览**：Cubism提供了实时预览功能，用户可以在编辑过程中随时查看模型的动态效果，方便进行调整和优化。
* **插件支持**：Cubism支持与Unity、Unreal Engine等游戏引擎的集成，方便在不同的平台上使用。用户可以通过插件，将Live2D模型无缝集成到游戏或应用中，实现实时的动态效果。

#### 5. Cubism的使用步骤
##### 1. 准备素材
在开始使用Cubism之前，需要准备好角色的各个部件的分层图像。例如，一个角色的头部、身体、手臂、腿等部分应该分别绘制并保存为独立的图层。常用的图像格式包括PSD（Photoshop文件）和PNG。

##### 2. 导入素材
将分层图像导入Cubism Editor中。Cubism支持多种图像格式，如PSD和PNG。导入后，可以对图像进行初步的排列和调整，以确保各个部件的位置和比例正确。Cubism还支持导入已经带有图层结构的PSD文件，方便用户进行后续的编辑。

##### 3. 创建网格
为每个部件创建网格。网格用于定义图像的变形区域，可以使用Cubism的自动网格生成功能，或手动调整网格的形状和密度，以获得更精细的变形效果。网格的质量直接影响模型的变形效果，因此需要根据具体情况进行调整。

##### 4. 添加变形器
使用变形器工具为模型添加变形点和变形器。变形点用于控制图像的变形，变形器则用于创建复杂的变形效果。例如，可以为角色的面部添加多个变形点，以控制眼睛、嘴巴和表情的变化。通过精细调整变形点的位置和权重，可以实现自然的变形效果。

##### 5. 设置关键帧
通过关键帧系统，为模型设置不同状态下的动画效果。例如，可以设置角色在眨眼、张嘴、摇头等动作下的关键帧。关键帧之间的过渡由Cubism自动计算，生成平滑的动画效果。用户还可以为不同的动画效果设置不同的动画曲线，以实现更自然的过渡效果。

##### 6. 调整物理效果
使用Cubism的物理引擎工具，模拟角色的动作效果。可以为角色的头发、衣服等部分添加物理效果，如重力和风力，使其在角色运动时产生自然的摆动和飘动效果。物理引擎的参数可以进行调整，以实现不同的物理效果，例如增加或减少重力、风力的强度等。

##### 7. 导出模型
调整完成后，可以将模型导出为不同的格式，以便在不同的平台和引擎中使用。Cubism支持多种导出格式，包括MOC3（Cubism模型文件）、JSON（模型配置文件）等。用户可以根据需要选择合适的导出格式，以便在后续的开发中使用。

##### 8. 实时预览和优化
在实际应用中实时预览模型效果，进行必要的优化和调整。Cubism提供了实时预览功能，用户可以在编辑过程中随时查看模型的动态效果，方便进行优化和调整。通过不断调整和优化，可以确保模型在不同的应用场景中都能表现出最佳效果。

#### 6. Cubism Core for Web介绍及使用
[Live2D官方](https://www.live2d.com/zh-CHS/sdk/download/web/)提供了多个平台的SDK，包括iOS，Android，Flash，Unity，openGL等，在Web端中呈现，则有WebGL版SDK可以使用。

![Live2D官网](/personal-site-mvp/img/doc-placeholder.svg "Live2D官网")
Cubism Core for Web是Live2D公司提供的一套JavaScript库，用于在网页上渲染和控制Live2D模型。通过Cubism Core for Web，开发者可以将Live2D模型集成到Web应用中，实现实时的交互和动画效果。

##### 1. 准备工作
准备相应的库，这里部分用的是 npm 的安装方式

###### cubism-sdk 
       在官网下载 [https://www.live2d.com/zh-CHS/download/cubism-sdk/download-web/](https://www.live2d.com/zh-CHS/download/cubism-sdk/download-web/)

       在下面点击同意后选择下载 Cubism Core for Web ， 会得到一个js

###### live2d.min.js （没用上）
      官网没有，戳这个地址 [https://github.com/dylanNew/live2d/tree/master/webgl/Live2D/lib](https://github.com/dylanNew/live2d/tree/master/webgl/Live2D/lib)

      现在这个库已经在2019年停止更新，这个库是为了适应 Cubism 2.1 的模型

###### pixi.js ( > 5.2.0 )  注意版本 
```
    npm install pixi.js -s 
```
    驱动模型的 pixi 基础库，安装完之后记得 npm info pixi.js 检查版本

    假如安装的版本不是5.2.0之上，可以 npm uninstall pixi.js 卸载，再  npm install [pixi.js@6.0.2](mailto:pixi.js@6.0.2) -s 指定安装6.0.2版本

[Pixi](https://pixijs.huashengweilai.com/guide/start/1.introduction.html)是一个超快的2D渲染引擎。它会帮助你用JavaScript或者其他HTML5技术来显示媒体，创建动画或管理交互式图像，从而制作一个游戏或应用。它有一个合理的，整洁的API，并包括许多有用的功能，如支持纹理地图集和提供一个精简的系统，为动画精灵(交互式图像)。

###### pixi-live2d-display
```
    npm install pixi-live2d-display -s
```

##### 2. 初始化
       创建一个JS使用上面的库去驱动这些模型文件，index.js 可以放在与 model 文件夹同级 

       初始化Cubism Core、Pixi以及加Live2DModel：

```
import Live2DCubismCore from '@/utils/live2dcubismcore'
window.Live2DCubismCore = Live2DCubismCore

import * as PIXI from 'pixi.js'
window.PIXI = PIXI     // 全局

const { Live2DModel } = require('pixi-live2d-display/cubism4')
```
