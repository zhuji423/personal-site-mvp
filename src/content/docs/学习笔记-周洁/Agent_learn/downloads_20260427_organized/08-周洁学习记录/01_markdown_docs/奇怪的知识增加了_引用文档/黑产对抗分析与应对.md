黑产对抗分析与应对

本页面由边俊柯于2022/03/24迁移自wiki 云安全空间
本文想总结一下黑产的一些反侦查手段，了解这些手段来进行更好进行检测。

## 黑产形式与反侦查手段
### 1.用户IP屏蔽
         这是一个非常通用型的手段，并且可能是所有手段最后的落地点，目的是防止自己过多的暴露，这种小心翼翼的心态以安全的角度来看是值得肯定的。例如某个站点想做一些黑产活动，那么可以对访问此站点的用户进行过滤，如果是某些省份的则直接404，高级一点的会返回一些正常的请求回应。从业务的角度来讲，根据IP来进行受众人群的过滤也是必要的。例如，某医院网站只想接受当地的请求，因为外地的请求对自己也没用，而且还增加了暴露自己的风险，在这种情况下进行IP屏蔽是非常明智的选择。从平台的角度来讲，有些黑产的中心平台，会在控制面板中加入了IP的选项，作用跟上述的两种一致，同时给了客户一些选择。

         平台化是黑产的一个常态，例如，某医院使用了黑产提供的窃取隐私的服务。黑产提供服务不会是直接将代码卖给他，虽然前端的代码极易获得。最常见的方式是进行统一的管理，所有的客户站点都加载了某中心平台的脚本或者是请求。当请求时，可以对所有的来源IP进行统一的管理。这种情况下普通的用户出发屏蔽策略的可能性极小，但是碰到百度爬虫这种情况，由于多次爬取了医院客户的页面，触发了IP屏蔽策略，百度这种大平台获取到黑产代码的几率就会减小很多，相关的反黑产团队就更不容易发现他们。

### 2.目标屏蔽
          这个手段是我进一步的总结。在IP屏蔽的基础上演化而来。假如网站的目标是获取用户的隐私，根据其获取目标的ID（如果获取百度账号信息，那么百度账号就是ID）进行适度的缩减各种行为。假设用户已经访问此网站并且已经被抓取到了信息，那么相应的IP就会到屏蔽区。或者是在一定的时间内都不会进行响应。如果碰到了机器中没有需要的信息，例如这台机器压根就没有安装所需要隐私的客户端，那么就直接屏蔽掉IP。

 

### 3.尽量在服务端完成
        作恶的高端原则是，最低限度的暴露自己的接口。由于前端代码已于被发现，因此，除了必要的步骤外，一切由自己的服务器完成。例如，在一个窃取隐私的case中，黑产利用了某运营商的接口来获取手机号码。获取手机号码的步骤有多个，但是最重要的一步是进行核验，即，请求服务的IP要与号码的IP一致。因此这一步最重要的放在了前端进行完成，其余步骤都在服务端操作。如果采取了此类措施，可以大大降低被发现的风险。

## 发现黑产的手段
### 1.图挖掘中对于error请求的挖掘
       目前图挖掘的边的关系还处于只取JS的请求关系，后来加入了请求中有参数的这种。对于非正常的JS其实是非常需要关注的。既然不想被抓取到，那么就直接对这一类的JS进行挖掘。挖掘的思路很多，主要是以目的来推手段。假如想找一些权重特别高的JS，那么就使用统计的方法或者PageRank来进行计算。

      对于这种被屏蔽了的请求，两种思路，一种是直接使用 domain/path/xx.js进行全字符串统计。例如，以"39.106.18.209/qv.js"这种为例， 我们把所有的JS直接统计，可以看到这个case会有至少几百的引用量，而且这个JS大部分都处于error状态。那么这个JS就是非常有可疑的。第二种思路主要针对JS不是统一在一个服务器中的。黑产会将恶意JS直接卖给客户，客户会将JS放到自己的站点中，那么,第一种方法就会失效。这种情况下略复杂，可以去除掉参数，去除掉site，只保留 xx.js，然后再进行统计或者 PageRank.这种情况下，数据可能存在一定得偏差，因为像是select.js  push.js等常见的词汇可能会被统计到前列。这里有个好的办法，利用xx.js?args 来作为码。只有一类的JS参数才会一致，保留第一个参数的名称，会大大的降低碰撞的几率。

### 2.从PageRank中发现黑产
       使用PageRank发现黑产是目前我在使用的主要方法。使用这个方法的时候，需要了解黑产的一下几个特点

       1）黑产是规模化的。如果一个黑产的规模不够大，那么也不能成为我们的目标

       2）黑产在自身的社区中是克隆性的，也就是，每个站点使用它的方式类似。例如，某个黑产服务器上的JS作为主要手段，那么社区中的站点都会引用此站点的JS

       3）黑产是悄无声息的，低调的。绝大多数的作恶站点都不想暴露自己，如果暴露了自己，那也是业务的需要，为了拉拢更多的客户。那么，我们查询此JS的站点的时候，如果站点打不开或者查不到任何的信息，亦或是直接在官方写好了自己的作恶业务宣传，那么是黑产的可能性就越大。

       4）黑产是业务单一的。如果发现一个JS的站点是在宣传某种业务，那么作恶的可能性就比较小。除非本身这种业务就跟黑产关系密切。目前我们见到的绝大多数的黑产都是业务单一的。

       根据这四个特点，可以总结出使用PageRank来发现黑产的方法。首先使用PageRank发现高权重JS。然后根据自身已有的白名单过滤掉，剩下的需要自己人工过滤。在过滤中根据第三四条，可以快速的发现那些低调而又业务单一的黑产行为。还可以根据前面写的，黑产具有反侦查能力，如果JS很难被打开，那么是黑产的可能性就非常大。
