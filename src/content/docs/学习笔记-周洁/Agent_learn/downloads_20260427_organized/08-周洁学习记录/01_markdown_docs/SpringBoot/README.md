## 模块说明
* design-agent：任务执行引擎
* design-common：放一些公共的东西，譬如vo，entity，utils等
* design-dao：数据库交互持久层
* design-service：服务层
* design-web：web服务，所有和前段交互的入口
* putil：执行服务库，如py写的模型预测
