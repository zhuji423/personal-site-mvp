函数映射功能实现:动态函数调用

本页面由v_姚宇辰于2022/03/02迁移自wiki 周洁空间
目的：实现使用某函数名【func_01】的字符串格式('func_01')来调用该函数【func_01】执行功能

```
def func_01(a, b):
    return a + b


class Fun:
    def func_02(self, a, b):
        return a + b


if __name__ == "__main__":
    # 方法1：eval()
    # 通常用来执行一个字符串表达式，并返回表达式的值。在这里它将字符串转换成对应的函数。eval() 功能强大但是比较危险（eval is evil），不建议使用。
    print('eval(): %s' % eval('func_01')(1, 2))

    # 方法2： locals() 和 globals()
    # 是python的两个内置函数，通过它们可以一字典的方式访问局部和全局变量。
    print('locals(): %s' % locals()['func_01'](1, 2))
    print('globals(): %s' % globals()['func_01'](1, 2))

    # 方法3： methodcaller()
    fun = Fun()
    from operator import methodcaller
    print('methodcaller(): %s' % methodcaller('func_02', 1, 2)(fun))

    # 方法4： globals().get
    print('globals().get: %s' % globals().get('func_01')(1, 2))

    # 方法5： getattr()
    # getattr() 是 python 的内建函数，getattr(object,name) 就相当于 object.name，但是这里 name 可以为变量。
    print('getattr().get: %s' % getattr(fun, 'func_02')(1, 2))
```
