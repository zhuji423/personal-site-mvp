# First，是什么促成了我们的消费动机
---

消费促成一般会经过3层思考，

|基础层面|👉👉👉 **这个产品是否能够满足我特定的需求？**|
|-|-|
|**yes👇👇👇**||
|经济层面|👉👉👉 **这个产品能够满足我特定的需求，但是，我是否有足够的钱支撑我消费ta？**|
|**yes👇👇👇**||
|实惠层面|👉👉👉 **这个产品能够满足我特定的需求，我有足够的钱支撑我消费ta，但是，ta在我的消费决策中，性价比（实惠力度）是OK的吗？**|



**一般在我们做消费决策的时候，商家会通过套路🪤致使我们形成对这个产品的“认知偏见”，来影响我们的决策行为**

**认知偏见：**一个系统性的偏离轨迹，它相对于判断中的标准、合理性。这种偏离可能来自他人、特定场景。人们从自身的洞察中，创造出自己的“主观事实”

# 实惠层面
### NO.1  诱饵效应
用户在做出决策时，很少不做对比而直接购买，针对这一现象，商家为了用户更好更快的做出消费决策，往往会为目标产品提供一个**“诱饵🪝”**，以促使用户消费

|**99.9元喵喵双人餐====目标销售产品****猫窝、贴纸等赠品====“诱饵🪝”**|
|-|
|![](/personal-site-mvp/img/doc-placeholder.svg "")|



### NO.2  肾上腺素效应
用户对某产品有意图，但不一定会想购买，只有当用户的肾上腺素被激发时，短时间内，迫使用户做出购买决策，如：周杰伦演唱会门票 😒

### NO.3  宜家效应
用户在对待要求自己DIY的产品是，会对该产品价值的认知过高。通过增加用户的参与感，拉近用户与产品的距离，充分调动用户的能动性和参与意愿，从而加强消费、提升品牌好感

### NO.4  比例偏见：贵和便宜是相对的
很多场合，人们本来应该考虑数值本身的变化，但是人们更加倾向于考虑比例或者倍率的变化

|**放大优惠价值：高单价产品用优惠金额促销，低单价产品用百分比促销**|**放大优惠价值：低单价产品搭配高价值产品一起销售**|**转移参照对象（换购）：利用极少金额换购商品，而非提升整体价格后赠送商品**|

### NO.6  锚点效应
我们在做决策或价值预估时，通常会以某些特定信息作为基准参考，尤其是最显接触的信息。这些信息会像锚点一样制约我们决策或预估

### NO.8  稀缺效应
“饥饿营销”，我们会对越稀有的物品产生强烈的占有欲或购物行为，从而实现个体的差异化和个性化。而有限的供给会强化用户的竞争心理；引发损失厌恶，我们不想错过当前所谓稀少且珍贵的东西

eg：

* 控制产品数量，如：泡泡玛特的“隐藏款”
