中间件

### 什么是中间件
**解决什么问题：**实现业务代码与技术功能之间解耦合。

**基于分层的架构思想引入一个中间层，**专门来解决可用性、稳定性、高性能方面的技术类诉求，这个中间层就是中间件，中间件是游离于业务需求之外引入的一个个技术组件。
