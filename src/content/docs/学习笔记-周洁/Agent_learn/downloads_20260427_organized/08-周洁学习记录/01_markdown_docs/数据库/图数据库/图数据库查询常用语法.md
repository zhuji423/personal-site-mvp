本页面由v_姚宇辰于2022/03/02迁移自wiki 周洁空间
目前的python-joern的实现方式是通过HTTP请求发送Gremlin查询语言(Groovy实现)到Neo4j的Gremlin插件。

> 为什么不用Neo4j自带的Cypher, 因为Gremlin支持Groovy语法, 有更强的操作性, 也兼容其他图数据库
确认已经执行过“导入代码” ，“填充数据库”的操作。参考 [joern安装与使用 Mac](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=1620980581)
