心理学是一门研究人类心理现象及其影响的学科，心理学研究者们希望通过研究人类心理现象的发生、发展和活动规律，进而描述、解释、预测和影响行为。

# 七大心理学理论
### 01 锚定效应
锚定效应是指当人们需要对某个事件做定量估测时，会将某些特定数值作为起始值，起始值像锚一样制约着估测值。在做决策时，会不自觉地给予最初获得的信息过多的重视。通俗来讲，就是**人们做判断时，易受第一印象支配，以初始锚为参照点来进行决断。**



产品的营销定价策略，经常会使用锚定效应，例如电商中的原价和折后价的展示，较高的原价就是锚点，再呈现用户一个折后的低价，用户会认为自己占到了便宜，从而促进下单。

![](/personal-site-mvp/img/doc-placeholder.svg "")


商场中的奢侈品也是如此，用户在进入商场，首先看到的定价高昂的奢侈品，之后再逛其他的服饰鞋帽等，价格就显得亲民了很多，其他商品的销量就会有所提高。

### 02 **诱饵效应**
诱饵效应是指我们对两个不相上下的选项进行选择时，因为第三个选项（诱饵）的加入，会使某个旧选项显得更有吸引力，在本质上和锚点效应有异曲同工之处。

![](/personal-site-mvp/img/doc-placeholder.svg "")

美国《经济学人》杂志做过一个实验，该杂志原来的订阅选项里，有以下两个选项，读者的订阅选择为，选项1占比68%，选项2占比32%。

选项1：电子版：每年59美元
选项2：电子版+印刷版套餐：每年125美元

随后，《经济学人》杂志增加了一个选项，变为如下三个选项：
选项1：电子版：每年59美元
选项2：印刷版：每年125美元

选项3：电子版+印刷版套餐：每年125美元

结果显示，选项1的比例从68%减少至暴跌到16%，而**选项3的比例从32%增加至84%****。**

### 03 羊群效应
羊群效应，又称为从众效应，是指当个体受到群体的影响（引导或施加的压力）时，会怀疑并改变自己的观点、判断和行为，朝着与群体大多数人一致的方向变化。



就像在日常生活中，路边有两家饭店，一家在排队，一家几乎没有人，大家往往会选择去人多的那一家饭店。很多网红店利用这一效应，雇人排队，或是放慢出餐速度，都是希望利用人们的从众心理，吸引用户为之付费。

![](/personal-site-mvp/img/doc-placeholder.svg "")


羊群效应在工作中的应用，有以下方式。

**热搜、热榜、热门...**

**销量、浏览量、播放量、点赞量...**



羊群效应是非常行之有效的营销技巧，也是社会普遍存在的优选法则，在信息不对称和预期不确定的条件下，对用户而言从众是风险较低的一种方式。

### **04 损失规避心理**
损失规避心理，是指人们面临同样数量的收益和损失时，损失更令他们难以忍受，同量的损失带来的负面效应为同量收益的正面效应的2.5倍。通俗来讲，比起得到，人们更害怕失去，当你丢了100块钱的痛苦，远大于捡到100块钱的快乐。



损失规避心理，在运营活动，尤其是电商活动中应用较多。大促活动中，限时促销给人以紧迫感，商家发放的大量优惠券，现金红包等，用户害怕错过优惠，就会选择购买。

![](/personal-site-mvp/img/doc-placeholder.svg "")
### 05 7±2法则
美国心理学家在发表的论文《神奇数字7加减2:我们加工信息能力的某些限制》中阐述了以下观点：人的短时记忆广度大约为7±2个组块。通俗来讲，对于用户而言，短时间内，我只能记住5-9个信息。



7±2法则广泛应用于产品设计中，比如通常网页顶部/左侧导航栏的设计，模块一般在5-9个，可以减轻用户接收的信息负担，让用户聚焦关键信息。一旦，数量超过9的时候，就需要设置优先级。交互设计中，比如网页端顶部/左侧导航栏的设计、移动端底部导航的设计。根据7来控制界面的信息条目数量，可以减轻用户的信息负担，让用户聚焦最核心的信息。当信息条目超过9个的时候，优先展示优先级最高的信息项。

![](/personal-site-mvp/img/doc-placeholder.svg "")
### **06 沉没成本效应**
沉没成本效应指如果人们已为某种商品或劳务支付过成本，那么便会增加该商品或劳务的使用频率。举例来说，反正人都来了，钱都花了，电影不好看也要看完。



如拼多多的红包助力返现活动，先给你一个红包，页面提示积累多少元就可以体现，用户看到红包行动，“损失厌恶”产生了影响，你邀请好友助力，一开始助力金额很大，最后要提现的时候，发现金额越来越小，虽然有抵触心理，但考虑前面付出的时间成本与精力，就会咬咬牙继续邀请好友助力。

![](/personal-site-mvp/img/doc-placeholder.svg "")
### ** 07 蔡格尼克效应**
蔡格尼克效应，是指人们对于尚未处理完的事情，比已处理完成的事情印象更加深刻。人的完成欲与生俱来，我们的大脑强烈要求“做完这件事”。



在产品设计中，会员升级体系、流程化指引、任务进度展示、连续打卡激励体系等等都可以利用此效应。比如，你需要用户去做任务，任务有多个步骤，为减少用户使用成本，就可以将整体流程分为几个核心环节，用户可以清晰底看到哪个环节未完成，从而促使用户完成这部分内容。

# **写在后面**
上述的七个心理学常识是不是还没看过瘾？



小编再举几个例子：比如色彩心理学，在产品设计中色彩的选择对用户的情感和行为有显著影响。比如，购物类产品希望激发用户的购买欲，通常用橙色或红色；金融理财类产品为增强用户的信任感，通常用蓝色调；比如社会认同理论，通常应用于社交类产品中，通过展示用户的好友动态或喜好进行推荐，引导用户产生从众心理，增加用户对产品内容的认同感等等。



心理学理论知识浩如烟海，应用范围非常广泛，无论你是产品、研发、销售还是职能同学，都能从中找到宝贵的启示和指引。只要我们活学活用，找对角度，便能够将这些理论知识转化为实际工作中的有力武器。
