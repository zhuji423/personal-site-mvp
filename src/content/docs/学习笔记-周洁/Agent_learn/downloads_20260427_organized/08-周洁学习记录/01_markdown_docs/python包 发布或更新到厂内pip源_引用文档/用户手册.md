# 什么是百度官方pip源？
[百度官方pip源](http://pip.baidu.com)的使命是为百度所有python开发者提供最便捷、完善、开放、稳定的基础服务，让开发者们可以专注于创造和分享优秀的python项目。




平台主要包括四个部分：

* [pypi官方源镜像服务](http://pypi.baidu.com/)
    * 允许内网环境安装python开源社区所有的库
    * 使用全量同步技术，稳定、高速
    * 每天定时同步更新，及时获取最新版本(机器原因，目前已停止更新)

* [百度内部私有源服务](http://pip.baidu.com/)
    * 允许发布自己的python库让所有人共享
    * 自动对接pypi镜像服务，一个源可以同时获取内部项目和开源社区项目

* [pyenv镜像服务](http://pypi.baidu.com/static/pyenv/)
    * 允许内网环境一键安装pyenv和各版本的python或标准python开发环境

* python基础工具链
    * 与icode打通，创建代码库时自动生成符合规范的初始项目结构
    * 与编译云打通，提供标准python环境，预装编译相关的基础库，自动使用百度官方pip源
    * 与agile打通，一键发布python项目到私有源服务


# 如何使用百度官方pip源？
## 安装python库
### 安装pip命令
通常我们都应当使用pip命令来下载和安装python库，它会自动安装目标库及其所有直接和间接依赖库，非常便捷。

* 所有2.7.10以上版本的python在安装时均内置了pip命令，通常可直接使用，如果安装后没有pip命令，可尝试执行 

```
python -m ensurepip
```
* 如果机器上的python是使用jumbo安装的，且没有pip命令，可尝试执行

```
jumbo install python-pip  # 默认pip版本是7.0.1
pip install -U pip
```
推荐使用pyenv和官方镜像源安装和管理python，可以参考[python环境管理](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=483615335)和[如何正确安装python](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=483359004)的相关内容。

### 配置pip源
想要使用百度官方pip源，请将以下内容写入pip.conf文件中，普通用户路径为*~/.pip/pip.conf*（自己创建目录），root用户路径为*/etc/pip.conf*。

**pip.conf**

```
[global]
timeout = 60
index = https://pip.baidu-int.com/search/
index-url = https://pip.baidu-int.com/simple/
trusted-host = pip.baidu-int.com
[list]
format = columns
```
python曾经使用过easy_install来安装python库（现在某些特殊场景下仍然在使用），如果希望该命令也使用百度官方pip源，请将以下内容写入*~/.pydistutils.cfg*中。

**.pydistutils.cfg**

```
[easy_install]
index-url = https://pip.baidu-int.com/simple/
```
* 索引[root/baidu](http://pip.baidu.com/root/baidu)包含了所有第三方库和百度内部开源的公共库
* 如果希望仅使用外部开源的第三方库，则配置为索引[root/pypi](http://pip.baidu.com/root/pypi)（不推荐）

### 使用pip安装python库
可以使用*pip install*命令方便地安装和更新任何第三方库或内部开源公共库。

例如，想要安装常用的网络通讯库requests，只需要以下一句命令，就会自动安装好requests本身及其依赖的urllib3、idna、chardet、certifi等库。

**使用pip命令安装python库**

```
pip install requests
```
如果安装某些python库失败，可以根据[FAQ](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=483359004)查询解决方案，或者加入hi群1598407进行沟通。




pip命令除了install以外，还提供了uninstall、list、search等诸多子命令，可以很方便地管理本地python库。

更多pip命令相关的用法可以参考其帮助信息，或者google一下。

### 使用easy_install安装python库
可以使用easy_install命令直接安装python库。

但由于它只能安装不能卸载，也不提供list、search等方法，也无法识别现在主流的wheel安装包，尽量不要使用此命令。

一个常见的使用场景是用它来安装pip库，然后用pip命令来安装其他的python库。

**使用easy_install安装python库**

```
easy_install pip
```

## 上传python库
根据公司内部开源的发展趋势，鼓励大家将自己的代码发布到百度官方pip源上，让更多有类似需求的同学便捷地找到它、使用它、完善它，努力制造精品，避免重复造轮子。

上传python库主要包括打包和发布两个步骤，以下分别进行介绍。

保密模块注意不要上传，公司的产品库和官方pip源都是开放式的，任何人都可以获取到发布的包并从中获取源代码。

如果确实有发布的需求，建议在打包前先使用代码混淆工具进行处理，然后再打包发布。




### 打包
想要推送到pip源，要求项目必须在编译时打包成合法的python安装包并放入编译产出中。

* 必须使用setuptools进行打包，打包脚本通常命名为setup.py
* 推荐打包成wheel格式的安装包，它比原始的tgz压缩包携带了更多的项目描述信息
* 生成的安装包建议放置在output/dist目录下
* python项目推荐使用cmc_standard集群进行编译，默认提供了2.7.14和3.5.5版本的python及编译相关的常用基础库

使用cmc_standard集群时，指定python版本的方法请参考[这里](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=483359004)。

建议python项目遵守[python项目规范](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=469686381)，或者在icode创建新代码库时选择语言为python并勾选“使用既定的配置文件初始化代码库”。

这样的项目结构将自动满足以上所有要求，并指定python版本为2.7.14。




python项目的编译和C/C++项目不同，通常不要使用BCLOUD文件，而应当使用的ci.yml描述。

agile在创建默认流水线时会自动将编译阶段配置为使用ci.yml，用户通常无需手动修改。

如果发现编译时去查找BCLOUD导致编译失败，可以参考以下内容进行配置。

###### 配置编译阶段使用ci.yml
1. 进入项目对应的agile页面，点击右上角的“流水线配置”（如果是新项目，可能需要先创建默认流水线）


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_002.bin "")
2. 选择“编译”阶段，配置”编译“任务，将其中的”BCLOUD文件“修改为”描述构建场景“


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_003.bin "")
3. 在文件框中输入对应的profile名称，与ci.yml文件中某个profile的name对应
使用标准ci.yml的项目，通常在changes分支上配置为dev，不生成产出；在master和branch上配置为publish（或留空），生成产出。

通常changes分支和master分支都需要进行配置，如果涉及分支上的编译，则也需要相应地进行配置。

### 发布
大家可以通过agile非常方便地将自己的项目上传到百度官方pip源。




1. 进入项目对应的agile页面，点击右上角的“流水线配置”（如果是新项目，可能需要先创建流水线）


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_002.bin "")
2. 根据项目的发布模型，选择对应的pipeline，通常小型项目使用主干发布即可，大型项目可以考虑分支发布


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_005.bin "")
3. 点击“+”号，添加一个新阶段


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_006.bin "")
4. 选择“添加新任务”


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_007.bin "")
5. 在弹出的对话框中依次选择“发布/上线”->“其他发布”->“PipDeploy”


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_008.bin "")
6. 为该插件配置相关的参数，参数含义参考？号说明信息，通常直接使用默认值即可


![](../../../_remote_images/08-周洁学习记录/local_assets/EN9D1w9QpX-6Xs/image_009.bin "")
至此，就完成了全部的配置工作，当你的项目再触发agile的pipeline时，就可以直接推送到百度官方pip源了。

百度官方pip源的内网私有源索引root/baidu禁止覆盖和删除，如果一个项目的python包发布版本号和历史版本号重复，将导致发布失败。

请根据[版本号规范](https://wiki2ku.baidu-int.com/pubapi/urlmap?id=469686381)合理管理项目的版本。
