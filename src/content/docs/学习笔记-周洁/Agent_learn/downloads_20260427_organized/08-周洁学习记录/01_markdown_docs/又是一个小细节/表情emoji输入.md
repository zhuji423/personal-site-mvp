表情emoji输入

### **1. 表情的英文名称（拼写）**
参考 Unicode 标准的官方命名（英文）。例如：

* 😊 →`:smiling_face_with_smiling_eyes:`
* ❤️ →`:red_heart:`
* 🍎 →`:red_apple:`
* 🐶 →`:dog:`

**常用工具**：

* 在**Mac 自带的字符检视器**（通过快捷键`Control + Command + Space`打开）中，选中表情会显示其官方名称。
* 在线查询：[Emoji List](https://emojipedia.org/)（输入表情后会显示其英文名称）。

### **2. 在代码或聊天工具中使用**
部分平台（如 Slack、GitHub）支持用英文名称输入表情，例如输入`:heart:`会自动转换为 ❤️。

**常见表情拼写：**

|表情|英文名称（拼写）|
|-|-|
|😂|`:face_with_tears_of_joy:`|
|👍|`:thumbs_up:`|
|🎎|`:fire:`|
|🍕|`:pizza:`|
