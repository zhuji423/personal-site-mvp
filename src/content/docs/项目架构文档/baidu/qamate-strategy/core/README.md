## 环境配置

### 安装 python3.9

安装包地址：
- Mac（Inter）：https://www.python.org/ftp/python/3.9.11/python-3.9.11-macosx10.9.pkg
- Mac（M1）https://www.python.org/ftp/python/3.9.11/python-3.9.11-macos11.pkg

### 配置 python3.9 环境
运行命令：`python3.9 -m venv venv`
运行命令：`cd scripts && sh config && cd ..`
