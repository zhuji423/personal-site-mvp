# ITP新手Q&A

## 📚 文档概述
本文档面向ITP平台的新用户，解答平台基础功能、使用方法和常见疑问，帮助快速上手平台使用。

## 🔍 基础功能概览

### Case类型支持
- **单接口Case**：单个API接口测试
- **流程类Case**：多接口串联测试
- **支持步骤类型**：HTTP、RPC、SQL、Shell、Socket

### 执行粒度控制
- **单Case执行**：独立运行单个测试用例
- **Case集合执行**：批量运行一组用例
- **任意筛选执行**：自定义选择多个用例执行

## ⚙️ 执行控制特性

### 并行串行控制
- **执行模式**：支持并行和串行执行
- **并发度配置**：可自定义配置并发度
- **智能并发**：平台根据资源和稳定性自动调节

### 断言支持
- **正则表达式**：支持正则匹配响应内容
- **通配符支持**：灵活的内容匹配机制
- **多种断言类型**：KV断言、JSON Schema断言等

## 🏗️ 测试结构设计

### Setup和Teardown
- **文件夹粒度**：支持任意文件夹级别的setup和teardown
- **执行时机**：文件夹下case运行前后执行
- **适用场景**：环境准备、数据清理等

### 脚本支持
- **Shell脚本**：支持服务器脚本执行
- **脚本位置**：可选择维护在ITP或用户自有机器
- **扩展函数**：Python和JavaScript脚本用于自定义参数计算

## 💾 数据操作能力

### 数据库交互
- **配置方式**：提供数据库配置信息和SQL语句
- **支持类型**：MySQL、Redis、Elasticsearch等
- **无需脚本**：直接编写SQL语句即可

### Token计算
- **通用方案**：通过扩展函数发布token计算逻辑
- **自定义能力**：业务可发布专用的token计算函数
- **平台调用**：在case中直接引用扩展函数

## 🔄 流水线集成

### 触发执行
- **流水线插件**：提供专门的流水线集成插件
- **配置简单**：直接在流水线中配置相关任务
- **无缝集成**：与现有CI/CD流程完美集成

### 性能测试
- **功能定位**：当前版本专注于功能测试
- **性能测试**：暂不提供性能测试能力
- **未来规划**：关注平台更新公告

## 📤 数据管理功能

### 批量操作
- **Case生成**：基于流量和AI批量生成case
- **API查询**：通过开放API批量获取case信息
- **导出限制**：不支持批量导出，可通过API查询

### 数据统计分析
- **贡献统计**：提供API查询外包同学case贡献数量
- **度量支持**：支持项目级的数据统计分析

## 🔗 需求管理集成

### Icafe集成
- **关联方式**：可通过代码提交信息关联需求和case
- **自动化流程**：MEG已实现白盒分析自动关联
- **直接关联**：当前版本暂不支持直接的卡片关联

## 📝 Case管理功能

### 复制移动
- **复制支持**：支持单个case和case集合的复制
- **跨项目迁移**：支持case在不同项目间的迁移
- **权限控制**：需具备目标项目的相应权限

### 版本管理
- **版本控制**：提供完善的case版本管理功能
- **分支特性**：支持拉分支修改，验证后合入主干
- **回滚机制**：暂不支持内容回滚，但可通过版本管理替代

### 删除恢复
- **逻辑删除**：数据库采用逻辑删除机制
- **恢复支持**：误删case可通过ITP服务号恢复
- **无回收站**：平台当前未提供回收站功能

## 💡 最佳实践建议

### 新手入门
1. **先熟悉单接口case编写**
2. **逐步学习多接口流程case**
3. **掌握数据驱动和参数引用**
4. **了解扩展函数的使用**

### 进阶使用
1. **合理设计文件夹结构**
2. **利用setup/teardown管理测试环境**
3. **掌握并发执行的配置方法**
4. **学习流水线集成的最佳实践**
