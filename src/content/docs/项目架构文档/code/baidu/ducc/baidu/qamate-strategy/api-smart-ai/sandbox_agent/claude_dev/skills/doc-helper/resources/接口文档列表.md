# ITP接口文档列表

## 📚 文档概述
本文档整理了ITP平台的完整API接口体系，涵盖用例管理、测试执行、计划管理、统计分析等核心功能模块，为开发和集成提供详细的接口参考。

## 🏗️ 接口分类体系

### 1. Case批量操作接口
**功能描述**：批量管理测试用例，适用于大规模用例操作场景

| 接口名称 | HTTP方法 | URI | 功能描述 |
|---------|---------|-----|---------|
| 批量删除case | DELETE | /itp/node/delete/batch | 批量删除测试用例 |
| 批量启用case | PUT | /itp/node/enable/batch | 批量启用测试用例 |
| 批量停用case | PUT | /itp/node/disable/batch | 批量停用测试用例 |
| 批量重置生命周期 | PUT | /itp/node/api/revive/batch | 将用例状态重置为new |

### 2. Suite系列接口
**功能描述**：Suite级别测试集合的完整生命周期管理

| 接口名称 | HTTP方法 | URI | 功能描述 |
|---------|---------|-----|---------|
| 新增suite | POST | /itp/node/api/subgroup | 创建新的Suite测试集合 |
| 查询suite | GET | /itp/node/api/group?productId={productId} | 根据产品ID查询Suite |
| Suite级别校验 | POST/GET | 多个校验接口 | Suite级别的配置校验 |

### 3. Case操作接口（24个）
**功能描述**：测试用例的完整CRUD操作和高级功能

#### 基础操作
- **新增case/setup/teardown**：POST /itp/node/api/{type}
- **查询case**：GET /itp/node/api/case?groupId={groupId}
- **更新case**：POST /itp/node/api/case/{caseId}

#### 高级功能
- **数据驱动**: GET/PUT 数据驱动相关接口
- **批量操作**: POST 批量修改生命周期和等级
- **搜索查询**: POST 分页搜索和历史记录查询
- **统计分析**: GET 新增case数和运行情况统计

### 4. Operation操作接口
**功能描述**：测试步骤(Operation)的详细管理

| 接口名称 | HTTP方法 | URI | 功能描述 |
|---------|---------|-----|---------|
| 新增operation | POST | /itp/node/operation | 创建测试步骤 |
| 更新operation | PUT | /itp/node/operation/{nodeId} | 更新测试步骤 |
| 设置结果处理 | PUT | /itp/api/caseManage/operation/{operationId}/update | 配置结果处理方式 |
| 查询详细信息 | GET | /itp/node/api/getInfo | 获取步骤详情 |

### 5. Group操作接口
**功能描述**：测试集合分组的配置管理

- **新增测试集合**：POST /itp/node/api/group
- **更新全局配置**：PUT /itp/api/testgroup/{groupId}
- **统计信息查询**：GET 分组统计和分析接口

### 6. 版本管理接口（11个）
**功能描述**：测试用例版本控制和管理

#### 基础版本操作
- **版本查询**：GET /itp/api/testgroup/versionList?groupId={groupId}
- **批量合入**：POST /itp/node/api/batch/version/{versionId}
- **分支删除**：DELETE /itp/node/api/batch/version/{versionId}

#### 高级版本功能
- **分支管理**：PUT/GET 分支创建和拉取
- **批量获取**：GET 根据条件获取case信息
- **分支结构**：GET 分支树状结构查询

### 7. 计划执行接口系列
**功能描述**：测试计划执行和运行监控

#### 计划执行（18个接口）
- **计划运行**：POST /itp/testplan/api/{planId}/newrun
- **状态查询**：GET /itp/testplan/api/{planId}/{executionId}/status
- **结果轮询**：GET /itp/api/agile/getStatus

#### Case执行控制
- **同步执行**：GET /itp/node/api/runcase/{caseId}
- **异步执行**：GET /itp/node/api/case/runCaseAsync
- **结果获取**：GET /itp/node/api/case/getExeDetail

#### 统计分析
- **执行统计**：GET /itp/testplan/api/{planId}/getExeDetail
- **覆盖分析**：GET /itp/testplan/api/{planId}/getPlanApis
- **稳定性统计**：POST /itp/api/statistics/plan/exe/stable/detail

### 8. 其他功能接口

#### Plan管理
- **Plan查询**：GET /itp/testplan/api/{planId}/detail
- **挂载更改**：POST /itp/testplan/api/{planId}/infoChange
- **Case详情**：GET /itp/testplan/api/{planId}/node/case

#### URI筛选
- **触发接口**：POST /itp/testplan/api/uriScreen
- **状态查询**：GET /itp/testplan/api/uriScreen/getStatus

#### 模板操作
- **API模板**：POST/PUT /itp/api/apitemplate

#### JSON Schema验证
- **验证发起**：POST /itp/api/validate
- **结果查询**：GET /itp/api/validate/{exeId}

#### 产品线相关
- **产品查询**：GET /itp/api/caseManage/query/productId/{productId}
- **用例拉取**：POST /itp/product/api/pullProductCaseInfo

## 🔄 异步支持特性

### 大规模操作优化
- **异步执行**：支持大case集的异步执行
- **结果轮询**：提供状态轮询接口跟踪执行进度
- **并发控制**：智能并发度调节避免资源竞争

### 数据驱动能力
- **动态更新**：支持运行时更新数据驱动参数
- **前置处理**：setup中获取数据并更新到后续case
- **复杂场景**：支持动态数组和不规则数据

## 🔐 权限和安全

### 访问控制
- **产品线权限**：基于产品线的细粒度权限管理
- **API认证**：接口无需复杂的AK/SK认证
- **操作记录**：完整的用户操作审计日志

### 安全限制
- **Cookie接口**：禁止调用需要Cookie的内部接口
- **线上访问**：线上环境访问有专门的安全限制

## 📊 统计分析接口

### 多维数据统计
- **执行质量**：成功率、稳定性、执行时长统计
- **用例质量**：断言覆盖率、维护活跃度评分
- **资源使用**：并发度、执行器负载监控

### 报表生成
- **定制报表**：支持自定义统计维度和周期
- **实时监控**：提供近实时的执行状态监控
- **历史分析**：保留7天详细执行记录

## 💡 使用最佳实践

### 批量操作建议
1. **优先使用批量接口**提高操作效率
2. **合理控制单次操作数据量**
3. **使用异步接口处理大数据集**

1. **合理使用分支管理功能**
2. **定期合并稳定分支到主干**
3. **监控分支与主干的差异**

### 监控告警配置
