## 在有疾病的情况，经过几轮聊天，如果输入“我想免费问医生”
### （1）健康管家模型的返回，对话内容都是与疾病相关
### （2）输入“我想免费问医生”后一定会出下单相关的卡，聊天过程中出了下单卡也是符合预期
### （3）对于卡片的一些展现点的判断：
- （3-1）卡片中的病情信息是之前对话内容，提取姓名、性别、年龄信息，并总结主诉
- （3-2）如果历史对话有写就诊人，需要展示就诊人
- （3-3）非定向服务：默认出免费咨询及三甲医生，同时有下单按钮
- （3-4）服务详情
### （4）卡片中服务展示：
#### 免费服务
- i-标题：免费问医生
- ii-副标题：真实医生·极速响应
- iii-价格展示0.0
#### 三甲医生
- i-标题：三甲医生
- ii-副标题：公立三甲医生 平均1分钟响应
- iii-价格：展示用户需支付的价格（有券展示划线价+券后价）
- iv-按钮：去咨询
#### 定向医生
- i-医生信息：头像、姓名、职称、医院、标签（三甲/本地）、擅长、在线标签、曾经问过标签、最近看过标签、接诊量、平均响应、评分、价格
- ii-按钮：去咨询
- iii-每个医生展示推荐原因
