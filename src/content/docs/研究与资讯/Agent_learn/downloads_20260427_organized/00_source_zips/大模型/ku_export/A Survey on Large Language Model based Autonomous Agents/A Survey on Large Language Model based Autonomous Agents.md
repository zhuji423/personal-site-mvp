# A Survey on Large Language Model based Autonomous Agents
论文：《A Survey on Large Language Model based Autonomous Agents》摘要背景:

自主智能体一直是学术界和工业界的研究重点。传统的自主智能体研究通常局限于孤立环境中，训练代理的知识有限，与人类学习过程存在很大差异，难以实现类人的决策。大语言模型（LLM）通过学习大量网络知识，展现出接近人类智能的潜力，推动了基于LLM的自主智能体研究热潮。文章内容:

对基于LLM的自主智能体研究进行全面综述，从整体角度进行系统性回顾。第一部分: 讨论基于LLM的自主智能体的构建，提出一个统一的框架，囊括了大部分之前的工作。第二部分: 概述基于LLM的自主智能体在社会科学、自然科学和工程领域的各种应用。第三部分: 深入探讨用于评估基于LLM的自主智能体的常用策略。最后: 基于以往研究，提出该领域面临的挑战和未来的研究方向。1.Introduction![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=7ee531bc6b3f47baafe958d3a5447095&docGuid=so8SMay7pYDoHy)

文章中提出了一种统一的架构框架（见图2），涵盖了大多数现有研究成果。该框架包含四个模块：（1）角色描述模块，用于识别智能体的角色；（2）记忆模块，用于存储来自环境的感知信息并利用记忆信息来辅助未来的行为；（3）规划模块，用于帮助智能体分解复杂任务并制定执行计划；（4）行动模块，用于将智能体的决策转换为具体的行动。

2.1.1 角色描述模块Profiling Module 作为代理设计的基础，对代理的记忆、规划和行动过程有着重要影响。角色描述模块 的目的是识别代理的角色。

代理角色： 自主代理通常通过扮演特定角色来执行任务，例如程序员、老师和领域专家。角色信息： 这些角色信息通常会被写入提示中，以影响 LLM 的行为。角色信息包括基础信息（如年龄、性别、职业）和心理信息（反映代理的个性）以及社会信息（描述代理之间关系）。角色信息选择： 选择哪些信息来描述代理的角色取决于具体的应用场景。例如，如果应用的目标是研究人类认知过程，那么心理信息就变得至关重要。角色信息创建： 识别了角色信息类型后，接下来的问题是如何为代理创建具体的角色信息。现有的文献通常采用以下三种策略：
手工方法： 手工指定代理角色信息。例如，如果想要设计个性不同的代理，可以使用“你是一个外向的人”或“你是一个内向的人”来描述代理。手工方法在许多之前的工作中被用来描述代理角色。LLM 生成方法： 基于 LLM 自动生成代理角色信息。通常先指定角色信息生成规则，阐明目标群体中代理角色信息的组成和属性，然后可以选择指定一些种子角色信息作为少样本示例，最后利用 LLM 生成所有代理角色信息。数据集对齐方法： 从真实世界的数据集中获取代理角色信息。通常可以先将数据集中的真实人类信息整理成自然语言提示，然后利用它来描述代理角色。方法结合： 虽然大多数之前的工作独立地利用上述角色信息生成策略，但我们认为结合它们可能会带来额外的好处。例如，为了通过代理模拟预测社会发展，可以利用真实世界的数据集来描述一部分代理的角色信息，从而准确地反映当前的社会状况。随后，可以手工为其他代理分配真实世界中不存在但未来可能出现的角色，从而预测未来的社会发展。除了这个例子，还可以灵活地组合其他策略。
2.1.2 记忆模块记忆模块在代理架构设计中至关重要，帮助代理学习和适应环境，实现更复杂的任务。它存储从环境中感知的信息，并利用这些记忆来促进未来的行动，帮助代理积累经验、自我进化，并以更一致、合理和有效的方式行动。文章中从记忆结构、格式和操作三个方面对记忆模块进行了全面概述。 

记忆结构：统一记忆： 仅模拟人类的短期记忆，通常通过上下文学习实现，记忆信息直接写入提示。这种方法简单易行，能够增强代理感知近期或上下文敏感行为和观察的能力。但由于 LLMs 上下文窗口的限制，很难将所有记忆都放入提示中，这可能降低代理的性能。 混合记忆： 明确地模拟人类的短期和长期记忆，短期记忆暂时缓冲最近的感知，而长期记忆随着时间的推移巩固重要信息。这种结构能够增强代理进行长期推理和积累宝贵经验的能力，这对在复杂环境中完成任务至关重要。记忆格式：自然语言： 使用原始自然语言直接描述记忆信息，例如行为和观察。这种格式灵活易懂，保留了丰富的语义信息，可以为代理行为提供全面的信号。嵌入： 将记忆信息编码为嵌入向量，可以提高记忆检索和读取效率。数据库： 将记忆信息存储在数据库中，使代理能够有效地操作记忆。结构化列表： 将记忆信息组织成列表，以高效简洁的方式传达记忆的语义。记忆操作：记忆读取： 从记忆中提取有意义的信息以增强代理的行为，例如利用先前成功的行动来实现类似的目标。记忆读取的关键在于如何从历史行动中提取有价值的信息，通常使用最近度、相关性和重要性三个指标来提取信息。记忆写入： 将感知到的环境信息存储在记忆中，为未来检索信息提供基础。记忆写入过程中需要注意如何存储与现有记忆相似的信息（即记忆重复）以及如何删除信息以防止记忆溢出（即记忆溢出）。记忆反思： 对记忆进行回顾和分析，以获得更深入的理解和洞察。记忆反思模拟人类对自身认知、情感和行为过程进行见证和评估的能力，使代理能够独立总结和推断更抽象、更复杂和更高级的信息。2.1.3 规划模块规划模块的目的是让代理像人一样，将复杂任务分解成更简单的子任务，并逐个解决。 规划模块根据是否在规划过程中接收反馈信息，分为两种策略： 

无反馈规划： 代理在采取行动后，不会收到任何影响其未来行为的反馈。 单路径推理： 将最终目标分解成几个中间步骤，这些步骤以级联方式连接，每个步骤只导致一个后续步骤。LLMs 遵循这些步骤来实现最终目标。 多路径推理： 用于生成最终计划的推理步骤被组织成树状结构，每个中间步骤可能有多个后续步骤，模拟人类思考，在每个推理步骤中可能有不同的选择。 外部规划器： 尽管 LLMs 在零样本规划方面已经表现出强大的能力，但为特定领域问题有效地生成计划仍然极具挑战性。为了应对这一挑战，研究人员转向外部规划器，这些工具经过良好开发，并采用有效的搜索算法来快速识别正确甚至最优的计划。 有反馈规划： 在许多现实世界场景中，代理需要进行长范围规划来解决复杂任务，面对这些任务，上述无反馈规划模块可能效果较差，因为： 难以直接从一开始就生成完美无缺的计划，因为需要考虑各种复杂的先决条件，因此，仅仅遵循最初的计划往往会导致失败。 计划的执行可能受到不可预测的过渡动态的阻碍，导致最初的计划不可执行。当观察人类如何应对复杂任务时，我们发现个人可能会根据外部反馈迭代地制定和修改他们的计划。为了模拟这种人类能力，研究人员设计了许多规划模块，其中代理可以在采取行动后接收反馈，反馈可以来自环境、人类或模型。

环境反馈： 来自客观世界或虚拟环境的反馈，例如游戏中的任务完成信号或代理采取行动后做出的观察。ReAct： 提议使用思想-行动-观察三元组构建提示，思想部分旨在促进高级推理和规划，以指导代理行为，行动代表代理采取的特定行动，观察对应于行动的结果，通过外部反馈获得，例如搜索引擎结果，下一个思想受先前观察结果的影响，使生成的计划更适应环境。Voyager： 在规划时，整合了三种类型的环境反馈，包括程序执行的中间进度、执行错误和自我验证结果，这些信号可以帮助代理为下一个行动制定更好的计划。Ghost： 在推理和行动执行过程中也整合了反馈，这些反馈包括环境状态以及每个执行行动的成功和失败信息。SayPlan： 利用来自场景图模拟器的环境反馈来验证和细化其策略制定，该模拟器擅长识别代理行动后出现的結果和状态转换，帮助 SayPlan 迭代地重新校准其策略，直到确定可行的计划。DEPS： 认为仅仅提供有关任务完成的信息对于纠正规划错误往往不够，因此，他们建议向代理提供有关任务失败的详细原因，使他们能够更有效地修改计划。LLM-Planner： 引入了一种接地重新规划算法，该算法在任务完成过程中遇到对象不匹配和不可实现的计划时，动态更新由 LLMs 生成的计划。Inner Monologue： 在代理采取行动后向其提供三种类型的反馈：（1）任务是否成功完成，（2）被动场景描述和（3）主动场景描述，前两种来自环境，使代理行动更合理。

人类反馈： 除了从环境中获得反馈外，直接与人类互动也是一种非常直观的策略，可以增强代理的规划能力。人类反馈是主观信号，可以有效地使代理与人类价值观和偏好保持一致，也可以帮助缓解幻觉问题。Inner Monologue： 代理旨在在一个 3D 视觉环境中执行高级别自然语言指令，它能够主动向人类征求有关场景描述的反馈，然后将人类反馈纳入其提示中，从而进行更明智的规划和推理。模型反馈： 除了上述环境和人类反馈（外部信号）之外，研究人员还调查了利用代理自身内部反馈的可能性。这种类型的反馈通常是基于预训练模型生成的。SelfCheck： 允许代理检查和评估他们在不同阶段生成的推理步骤，然后通过比较結果来纠正任何错误。InterAct： 使用不同的语言模型（例如 ChatGPT 和 InstructGPT）作为辅助角色，例如检查器和排序器，帮助主语言模型避免错误和低效的行动。ChatCoT： 利用模型反馈来提高其推理过程的质量，模型反馈由一个评估模块生成，该模块监控代理推理步骤。Reflexion： 通过详细的口头反馈来增强代理的规划能力，在这个模型中，代理首先根据其记忆产生一个行动，然后，评估者以代理轨迹作为输入生成反馈，与以前研究中反馈作为标量值的相反，这个模型利用 LLMs 提供更详细的口头反馈，可以为代理计划提供更全面的支持。 2.1.4 执行模块执行模块负责将代理的决策转化为实际的操作，它是代理架构中最下游的部分，直接与环境交互。该模块受到角色、记忆和规划模块的影响。从四个方面介绍执行模块：

行动目标： 行动的预期结果是什么？代理可以执行各种目标的行动。这里列举几个有代表性的例子：
任务完成： 在这种情况下，代理的行动旨在完成特定的任务，这些行动通常有明确的目标，每个行动都为完成最终任务做贡献。这类目标的行动在现有文献中很常见。交流： 在这种情况下，行动是为了与其他代理或真实人类交流，以共享信息或协作。例如，ChatDev 中的代理可以相互交流，共同完成软件开发任务。在 Inner Monologue中，代理积极地与人类进行交流，并根据人类反馈调整其行动策略。环境探索： 在这个例子中，代理的目标是探索陌生的环境，以扩展其感知，并在探索和利用之间取得平衡。

行动生成： 如何生成行动？与普通 LLM 不同，LLM 的输入和输出直接相关，代理可以通过不同的策略和来源采取行动。下面介绍两种常用的行动生成策略。
通过记忆回忆进行行动： 在这种策略中，行动是通过根据当前任务从代理记忆中提取信息来生成的。任务和提取的记忆被用作提示来触发代理行动。通过计划跟踪进行行动： 在这种策略中，代理根据其预先生成的计划采取行动。行动空间： 有哪些可用的行动？行动空间是指代理可以执行的所有可能行动的集合。一般来说，我们可以粗略地将这些行动分为两类：
外部工具： 虽然 LLM 在完成大量任务方面已被证明是有效的，但它们可能不适用于需要全面专业知识的领域。此外，LLM 也可能遇到幻觉问题，它们很难自行解决。为了缓解上述问题，代理被赋予了调用外部工具来执行行动的能力。下面介绍几个在文献中被利用的有代表性的工具。
API： 利用外部 API 来补充和扩展行动空间是一个流行的范例。数据库和知识库： 集成外部数据库或知识库使代理能够获取特定领域的信息，以生成更真实的行动。外部模型： 以前的研究经常利用外部模型来扩展可能的行动范围。与 API 相比，外部模型通常处理更复杂的任务。每个外部模型可能对应多个 API。

内部知识： 除了利用外部工具之外，许多代理还依靠 LLM 的内部知识来指导他们的行动。现在我们介绍 LLM 的几个关键能力，这些能力可以支持代理合理有效地行动。
规划能力： LLM 可以被用作合适的规划器，将复杂的任务分解成更简单的任务。LLM 的这种能力甚至可以在不包含提示中的示例的情况下触发。对话能力： LLM 通常可以生成高质量的对话。这种能力使代理能够更像人类一样行动。在以前的工作中，许多代理根据 LLM 的强大对话能力采取行动。常识理解能力： LLM 的另一个重要能力是理解常识。这种能力使代理能够做出更合理的行动，并理解人类行为中的微妙之处。行动影响： 行动的影响是指行动对环境和智能体自身造成的影响。行动的影响会影响智能体的未来行动，因为它会改变智能体对环境的感知和理解。本文介绍了行动影响的几个关键方面：
环境变化： 行动会导致环境的变化。例如，在Minecraft中，智能体可以执行挖矿、建造等行动，这些行动会改变环境的物理状态。在对话中，智能体可以执行提问、回答等行动，这些行动会改变对话的语境。记忆更新： 行动会更新智能体的记忆。例如，智能体可以将成功的行动和失败的行动记录在记忆中，以便在将来参考。智能体还可以将从环境中获得的新信息存储在记忆中，以扩展其知识。智能体状态变化： 行动会改变智能体的状态。例如，智能体完成任务后，其状态会从“未完成”转变为“已完成”。智能体执行行动后，其状态也会发生变化，例如，智能体获得新的技能后，其能力会得到提升。 2.2 Agent capability acquisition两种增强智能体能力的策略，分别是需要微调LLM的策略和不需要微调LLM的策略。

需要微调LLM的策略：

利用人工标注数据集微调： 研究人员首先设计标注任务，然后招募工人来完成这些任务。例如，在CoH中，作者旨在使LLM与人类的价值观和偏好保持一致。与其他模型不同，该方法将人类反馈转化为自然语言形式的详细比较信息。LLM直接基于这些自然语言数据集进行微调。利用LLM生成数据集微调： 构建人工标注数据集需要招募人员，成本很高，尤其是在需要标注大量样本时。考虑到LLM可以在各种任务中实现类人的能力，一个自然的想法是使用LLM来完成标注任务。虽然由此方法生成的数据集可能不如人工标注数据集完美，但它更便宜，并且可以用来生成更多样本。利用真实世界数据集微调： 除了基于人工或LLM标注构建数据集之外，直接使用真实世界数据集来微调智能体也是一种常见的策略。例如，在MIND2WEB中，作者收集了大量的真实世界数据集，以增强智能体在Web领域的性能。提示工程： 由于LLM具有强大的语言理解能力，人们可以直接使用自然语言与LLM交互。这引入了一种增强智能体能力的新策略，即可以使用自然语言描述所需的性能，然后将其用作提示来影响LLM的动作。例如，在CoT中，为了赋予智能体进行复杂任务推理的能力，作者在提示中提供了中间推理步骤作为少样本示例。
