如流如何美化聊天框

## 方法：直接修改css
定位位置：`/Applications/如流.app/Contents/Resources/chat.css`

vscode直接打开编辑即可。



## 示例
### 给聊天框换个字体？
1. macOS搜索打开“字体侧.app”

![](/personal-site-mvp/img/doc-placeholder.svg "")
2. 找到你喜欢的字体。如果没有请上网搜索并安装

![](/personal-site-mvp/img/doc-placeholder.svg "")
3. 双击字体打开详情，复制字体名称

![](/personal-site-mvp/img/doc-placeholder.svg "")
4. 在`body`选择器的`font-family`首位添加字体名称：

![](/personal-site-mvp/img/doc-placeholder.svg "")
```
html,
body {
    display: block;
    width: 100%;
    height: auto;
    margin: 0;
    padding: 0;

    font-family: 'HannotateSC-W5', PingFangSC-Regular, arial, 'Microsoft Yahei', sans-serif;
    font-size: 13px;
    color: #fcfdfe;
    line-height: 1.5;
    user-select: none;
    -webkit-user-select: none;
}
```
5. 重启如流



### 怎么增加气泡的悬浮质感呢？
```
.msg-bubble {
    position: relative;

    margin: 2px 20px 8px 20px;
    padding: 8px 8px;

    word-wrap: normal;
    word-break: break-all;
    /*white-space: pre-wrap;*/

    color: #161717;
    box-shadow: 2px 2px 5px #e0e0e0;
    -webkit-border-radius: 4px;
    border-radius: 10px;
    background: #fff;
}
```
### 给气泡自定义颜色呢？
```
.msg-bubble.left {
    float: left;

    margin-right: 116px;
    margin-left: 9px;
    :border: 1px solid #ebeef1;

    :-webkit-border-top-left-radius: 0;
    :border-top-left-radius: 0;
    background: linear-gradient(135deg, #f4f4f7 50%, #e0efff 100%);
}
```


### 其他选择器：
整个聊天框的类：`#list`

聊天消息条的类：`.msg-bubble-Container`

左右消息气泡的类：`.msg-bubble.left``.msg-bubble.right`

聊天头像类：`.roundPortrait`

聊天名字标签类：`.displayName`

居中提示消息类：`.msg-bubble-local`

回复表情框：`.reply-emotion-bubble`
