开发机版

# 1、前置准备
## 1.1、安装ducc 
> /bin/bash -c "$(curl -fsSL [http://baidu-cc-client.bj.bcebos.com/baidu-cc/install.sh](http://baidu-cc-client.bj.bcebos.com/baidu-cc/install.sh))"
## 1.2、登录ducc
```
# 输入登录命令，终端会弹出一个二维码，如流扫码登录
ducc login
```
![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=ac841450978041d6af59bcce60103110&docGuid=Yj6Y_IsOpw96FE "")


## 1.3、启动ducc
```
# 换个厉害点的模型
ducc config model 'Claude Opus 4.6'

ducc
# 输入Query确认是否可用：看下当前系统的各项指标信息
```
![回车-同意](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=fc800c3782c049049e91b11eb0541248&docGuid=Yj6Y_IsOpw96FE "回车-同意")
![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=e9c1587c7cef42f2a77e405d2a73ee4c&docGuid=Yj6Y_IsOpw96FE "")


## 1.4、**环境变量提供相关依赖的TOKEN**
修改 ~/.bash_profile, 在底部新增以下内容

```
# TestOne: username是公司的邮箱前缀，token打开 https://testone.baidu-int.com/ 右上角获取
export TESTONE_USERNAME='<TESTONE_USERNAME>'
export TESTONE_TOKEN='<TESTONE_TOKEN>'

# Icafe: username是公司的邮箱前缀，password请让用户浏览器直接打开 https://console.cloud.baidu-int.com/api/icafe/users/virtual 获取
export ICAFE_USERNAME='<ICAFE_USERNAME>'
export ICAFE_PASSWORD='<ICAFE_PASSWORD>'

# infoflow: 登录机器人后台获取对应的appKey和appSecret https://qy.baidu-int.com/index.html
export INFOFLOW_APP_KEY='<INFOFLOW_APP_KEY>'
export INFOFLOW_APP_SECRET='<INFOFLOW_APP_SECRET>'
```




# 2、**启动Agent服务**
## 2.1、拉取代码到本地
[文件页：baidu/ep-qa/qep_delivery_open_source  *master](https://console.cloud.baidu-int.com/devops/icode/repos/baidu/ep-qa/qep_delivery_open_source/tree/master/ai-agent?t=mention&mt=doc&dt=sdk) 

* 把DUCC_BIN_PATH CC_PROJECTS_DIR 修改为自己机器的对应位置

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=5ca25501eb9441ca82a657c4d7c728b8&docGuid=seJKL0VgfbUj31 "")
## 2.2、环境初始化
```
cd baidu/ep-qa/qep_delivery_open_source/ai-agent
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt -U --index-url http://pip.baidu.com/root/baidu/+simple/ --trusted-host pip.baidu.com --no-cache-dir
```


## 2.4、**启动服务**
```
source ~/.bash_profile
source venv/bin/activate
python3 quick_start_with_ducc.py

```
![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=e4fa1a589cc6465ca513144aace56673&docGuid=rKjIOhc7cB82Rv "")


启动成功后，可以得到自己的接口地址： http://x.x.x.x:8888/aiAgent/execute
