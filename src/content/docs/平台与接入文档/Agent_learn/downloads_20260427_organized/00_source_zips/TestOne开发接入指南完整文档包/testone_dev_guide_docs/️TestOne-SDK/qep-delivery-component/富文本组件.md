富文本组件

# 新版
推荐使用 qep-delivery-component=0.8.1 及以上的版本

相关实现源码参考：

```
class RichTextComponent(BaseComponent):
    """
    通用组件：富文本
    """

    def __init__(self, component_operate_config: Optional[ComponentOperateConfig],
                 component_data: str = None):
        """
        初始化
        :param component_operate_config: 富文本组件公共操作，必填。如果为None，则使用默认值（默认展开，允许更新，无需标注）
        :param component_data: 富文本数据存储的链接
        """
        component_data = self.attribute_verify(component_data, 'component_data', str, "")
        # 兼容多种模式
        if is_valid_url(component_data):
            super().__init__(RICH_TEXT_ID, component_operate_config, {"url": component_data})
        else:
            if len(component_data) > 500:
                warnings.warn("富文本长度超过500字符的情况下，请上传到BOS后使用URL，而不是原始文本内容; "
                              "本组件将会在0.9.0及以后版本后抛出异常，不再允许超出500字符的场景，请及时升级",
                              DeprecationWarning, stacklevel=2)

            super().__init__(RICH_TEXT_ID, component_operate_config, {"htmlStr": component_data})
```

# FAQ
## 1 脚本未成功执行
可能的原因：

富文本字符串`richtext_str`要转换为 HTML 会经历一次转义，转义过程中可能出现语法错误。

如果脚本中存在正则表达式，所有`\`应该替换为`\\`来防止被错误转义。例如：
