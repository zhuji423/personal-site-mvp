分页查询知识库文档

# **1、添加权限（必须）**
添加权限->搜索 ai_qepku添加编辑权限。以下方式二选一，大家自行决定

* **整个知识库添加****成员权限**
* **按照知识本添加****查看或者更高权限**

# 2、接口信息
**功能**

> 创建文档
> 知识库原始API定义请参考 [知识库OpenAPI - 分页查询知识库文档](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/BCFGAMZaw_hj1w?t=mention&mt=doc&dt=doc)
> TestOne仅仅是把相关能力直接封装，方便大家加个权限就可以直接使用


**接口信息**

> 地址：https://testone.baidu-int.com/api/ku/getDocByPage
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string|-|application/json|
|username|string|用户名|xxxxx  TestOne平台右上角获取|
|token|string|Token |xxxxxx  TestOne平台右上角获取|



**请求参数**

|名称|类型|描述|是否必须|备注|样例|
|-|-|-|-|-|-|
|repositoryGuid|string|文档所属知识库ID|是|[知识库ID定义](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/Vlo_5YacJLlB_l?block_id=docyg-03134f81-0474-11f0-9e42-b7c76f10f5b8&type=card)|Bu7DDg4dpB|
|pageNum|int|分页页数|否|默认为1|1|
|pageSize|int|分页大小|否|默认为10|10|
|parentDocGuid|string|父文档ID|否|[文档ID定义](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/Vlo_5YacJLlB_l?block_id=docyg-03134f81-0474-11f0-9e42-b7c76f10f5b8&type=card)不为空时将限制查询范围在该父文档目录下（该父文档也需要在相同知识库中）|Cq7tg-r065jig5|
|docGuids|string[]|文档ID列表|否|[文档ID定义](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/Vlo_5YacJLlB_l?block_id=docyg-03134f81-0474-11f0-9e42-b7c76f10f5b8&type=card)不为空将限制查询范围在指定文档中（指定文档也需要在相同知识库中）|[BCFGAMZaw_hj1w]|
|showDocCreatorInfo|boolean|是否展示文档作者信息|否|默认为不展示true = 展示； false = 不展示|false|
|showDocPublisherInfo|boolean|是否展示文档最近更新者信息|否|默认为不展示true = 展示； false = 不展示|false|
|orderBy|string|排序字段|都不为空时有效|publishTime = 按发布时间排序|publishTime|
|orderDirection|string|排序方向||asc = 正序排序desc = 倒序排序|desc|



**返回**

|名称|类型|描述|备注|
|-|-|-|-|
|repositoryGuid|string|文档所属知识库ID|[知识库ID定义](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/Vlo_5YacJLlB_l?block_id=docyg-03134f81-0474-11f0-9e42-b7c76f10f5b8&type=card)|
|docGuid|string|文档ID|[文档ID定义](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/Vlo_5YacJLlB_l?block_id=docyg-03134f81-0474-11f0-9e42-b7c76f10f5b8&type=card)|
|name|string|文档标题||
|type|int|文档类型|1=普通文档2=知识本目录3=知识本文档4=普通表格6=PPT7=数据表8=数据表子节点|
|childCount|int|当前文档的子文档数量|当该值大于0时文档有子文档|
|created|long|文档创建时间戳|精确到毫秒|
|publishTime|long|文档发布时间戳|精确到毫秒|
|url|string|文档链接||
|creatorUserInfo|[UserMetaInfo](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/AhkQkHD47-/Vlo_5YacJLlB_l?block_id=docyg-fa2678c1-053b-11f0-9d3b-8f29f147125b&type=card)|文档作者用户简要信息|当请求参数 showDocCreatorInfo = true 时返回|
|publisherUserInfo|[UserMetaInfo](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/AhkQkHD47-/Vlo_5YacJLlB_l?block_id=docyg-fa2678c1-053b-11f0-9d3b-8f29f147125b&type=card)|文档最近更新者用户简要信息|当请求参数 showDocPublisherInfo = true 时返回|



示例代码

```
curl --location 'https://testone.baidu-int.com/api/ku/getDocByPage' \
--header 'username: YOUR_USERNAME' \
--header 'token: YOUR_TOKEN' \
--header 'Content-Type: application/json' \
--data '{
            "repositoryGuid": ""
        }'
```
```
# !/usr/bin/python3

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2025/7/1
@desc:   
"""

import json

import requests

# TODO 提供你自己的username  token
TESTONE_USERNAME = ''
TESTONE_TOKEN = ''


def query_doc(repositoryGuid:str):
    url = "https://testone.baidu-int.com/api/ku/getDocByPage"
    headers = {
        "username": TESTONE_USERNAME,
        "token": TESTONE_TOKEN,
        "Content-Type": "application/json"
    }

    body = {
        "repositoryGuid": repositoryGuid  # 知识库ID
    }

    response = requests.post(
        url=url, headers=headers,
        data=json.dumps(body, ensure_ascii=False).encode("utf-8"), ).json()
    print(response)


if __name__ == '__main__':
    query_doc("xxxxx")

```
