常见问题自查

# 1、日志显示code=302, msg=username或者token错误
由于未给对应的用户添加Agent开发调度的权限白名单，所以调用不通，联系[@顾友达](https://ku.baidu-int.com?t=mention&mt=contact&id=b0e6e690-fb28-11ee-8897-231df4a0d723)添加即可



# 2、日志里面显示  code=605  msg=Agent当前状态不允许回调忽略
两种原因可能导致

* 自行构造的请求参数，直接在麒麟平台调试，对应的Agent任务已经执行完成，所以不允许再次回调更新，忽略即可
* 在TestOne平台在线调试页面，Agent注册的时候，类型 同步/异步 选择和实际麒麟服务不一致



# 3、Agent执行成功无报错，但是前端显示执行失败
![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=3570a29b68314961ba705622426b4176&docGuid=ezBGjqngjN3s0e "")
原因：

Agent服务在麒麟平台注册的是异步，但是在TestOne平台注册的是同步，两边不一致。导致调度过程异常。

解决办法：

将Agent在TestOne和麒麟的同步异步方式改成一致
