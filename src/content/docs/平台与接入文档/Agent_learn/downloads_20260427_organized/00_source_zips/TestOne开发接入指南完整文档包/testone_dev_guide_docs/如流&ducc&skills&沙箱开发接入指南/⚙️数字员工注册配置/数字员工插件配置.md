## API信息设置
* Host:  https://testone.baidu-int.com
* Path: /aiqa/receiveInfoflowMsg
* 请求方式: POST

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=c2885781a27a4f88a8e98c29eaf19f83&docGuid=NeQdOC--WUltOf "")
## 输入参数配置
|参数名称|参数描述|参数位置|参数类型|固定值|是否必填|
|-|-|-|-|-|-|
|Accept|Accept|header|string|text/event-stream|是|
|aiworkerUsername|数字员工用户名(数字员工邮箱前缀)|header|string|你自己的数字员工的邮箱前缀|是|
|splitEnum|同一个群or同一个单聊任务分割枚举|header|string|DAILY：默认值，同一个群or同一个单聊，每天创建一个任务WEEKLY：同一个群or同一个单聊，每周创建一个任务MONTHLY：同一个群or同一个单聊，每个月创建一个任务KEEP：同一个群or同一个单聊，永远使用相同的任务，除非用户主动 使用  “/new 帮我干点啥" 创建一个新任务|否|
|allowMultiTask|同一个群or同一个单聊，是否允许多个任务同时进行|header|string|false: 默认值，不允许，如果有进行中的任务用户可以通过 “/new 帮我干点啥" 的方式创建一个新任务并行执行用户可以通过 /stop  停 等方式主动停止进行中的任务true：允许（如果有进行中的任务，自动新建任务）|否|
|query|用户问题|body|string|-|是|
|userId|用户Id(邮箱前缀)|body|string|-|是|

![](https://rte.weiyun.baidu.com/wiki/attach/image/api/imageDownloadAddress?attachId=5b8c824bdff14a309aa5608b932b9c66&docGuid=NeQdOC--WUltOf "")
