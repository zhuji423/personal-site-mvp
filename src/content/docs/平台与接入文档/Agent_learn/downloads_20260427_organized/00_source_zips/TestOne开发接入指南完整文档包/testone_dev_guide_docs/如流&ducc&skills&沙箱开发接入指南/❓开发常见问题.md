# 活还没干完，如流就断了？
目前如流的流式消息最长只支持5分钟，超出就会自动关闭

* 但是不影响自己的任务继续执行，只是如流的实时推送断了
* 打开TestOne平台，或者侧边栏依旧能继续看到流式输出。
* 建议开发者可以在任务执行超过5分钟的场景下，主动将结果推送给用户，推送方法如下
    * self.send_md_msg_to_user
    * self.send_md_msg_to_group

# 怎么实现的流式，似乎没看到SSE相关的逻辑
* **Agent侧-非SSE**：Agent任务通常耗时非常久，而且平台后台存在非常大规模的任务在并行执行，如果采用SSE进行流式推送对于平台的资源和稳定性要求较高，故任务数据采用普通HTTP接口进行推送。数据源源不断的推送到平台后端的缓存队列
* **用户侧-SSE**：用户侧(Web&如流)，同时在线操作的用户量级可控，且和后台任务都不在一个数量级，对于资源的占用比较低。因此用户侧是基于标准的SSE进行数据的实时推送
