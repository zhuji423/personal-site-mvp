# **1、添加权限**
* **给 ai_qepku@baidu.com虚拟账号添加可读权限即可**
* **建议按照知识本或者目录的方式给此账号授权，方便后续的使用**

**Header**

|-|-|-|
|username|string|用户名|
|token|string|Token |



**参数**

|字段|类型|必填|含义|示例|

|docGuid|string|是|文档的ID|NzwrklmOjkeBeQ|

# 3、知识库内容JSON转HTML/MARKDOWN
**接口信息**

> 地址：http://testone-test.bcc-szzj.baidu.com:8080/kuJsonParse
> 方法：POST
> 注意：由于后续知识库可能会直接提供MD/HTML 或者提供统一的转化服务，目前我们的场景单一，且流量很低，故临时搭建一个线下服务
****

Header：

> Content-Type：application/json


**请求参数**

|参数名|类型|说明|是否必填|
|-|-|-|-|
|type|string|输出类型，可选值为`html`或 `markdown`|是|
|json|object[]|从知识库获取的文档 json 文件|是|

```
{
  "type": "markdown",
  "json": [
        {
            "type": "paragraph",
            "children": [
                {
                    "text": "这个是morpho的json数据"
                }
            ]
        },
        {
            "type": "paragraph",
            "children": [
                {
                    "text": "是知识库文档本质"
                }
            ]
        },
        {
            "type": "heading",
            "blockId": "docyg-4dd8a990-0305-11f0-920e-87ec44cd5687",
            "children": [
                {
                    "text": "大标题"
                }
            ],
            "level": 1
        },
        {
            "type": "heading",
            "blockId": "docyg-4a0421f0-0305-11f0-920e-87ec44cd5687",
            "children": [
                {
                    "text": "小标题"
                }
            ],
            "level": 6
        }
    ]
}

```
 

**返回结果**

|参数名|类型|说明|
|-|-|-|
|`code`|number|响应状态码，`0`表示成功，`400` 表示错误|
|`message`|string|响应状态信息，成功时为`success`，错误时提供错误描述|
|`data`|string | null|解析后的HTML或Markdown文本内容|

```
{
    "code": 0,
    "message": "success",
    "data": "<p style=\"font-size:16px;line-height:1.625;min-height:26px;margin:1px 0;padding:3px 0;text-align:left;padding-left:0px;white-space:pre-wrap\">这个是morpho的json数据</p><p style=\"font-size:16px;line-height:1.625;min-height:26px;margin:1px 0;padding:3px 0;text-align:left;padding-left:0px;white-space:pre-wrap\">是知识库文档本质</p><h1 style=\"text-align:left;color:rgb(28, 29, 31);padding-left:0px;font-weight:bold;line-height:1.5;white-space:pre-wrap;font-size:26px;margin-top:19px;margin-bottom:9px\">大标题</h1><h6 style=\"text-align:left;color:rgb(28, 29, 31);padding-left:0px;font-weight:bold;line-height:1.5;white-space:pre-wrap;font-size:16px;margin-top:14px;margin-bottom:6px\">小标题</h6>"
}
```
