# 2、接口信息
**功能**

> 创建文档
> 知识库原始API定义请参考 [知识库OpenAPI - 编辑文档正文](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/hEJvX639J4Kbqx?t=mention&mt=doc&dt=doc)
> TestOne仅仅是把相关能力直接封装，方便大家加个权限就可以直接使用


**接口信息**

> 地址：https://testone.baidu-int.com/api/ku/updateKuDoc
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string|-|application/json|
|username|string|用户名|xxxxx  TestOne平台右上角获取|
|token|string|Token |xxxxxx  TestOne平台右上角获取|



## **参数**
|名称|类型|描述|是否必须|备注|样例|
|-|-|-|-|-|-|
|docGuid|string|文档ID|是||hEJvX639J4Kbqx|
|editorUsername|string|编辑者用户名称|是|传入用户UUAP|zhangsan|
|operations|DocEditOperation[]|文档编辑操作列表|是|列表中的操作将依次执行||
|publish|boolean|是否在编辑后同步发布|否|默认为falsetrue = 编辑后立即发布false = 编辑后不发布，仅在编辑态发生了编辑变动|false|

DocEditOperation

|名称|类型|描述|是否必须|备注|样例|
|-|-|-|-|-|-|
|mode|string|操作模式|是|sibling = 同层级节点插入update = 更新目标节点的属性delete = 删除目标节点|inner|
|blockId|string|目标节点ID|取决于mode|文档正文内目标节点IDmode = sibling 时可不传，默认在正文最后一个节点进行追加json其他mode场景则必传|docyg-ed66e223-b2b4-4483-ba24-e98eaf68c94e|
|json|object[]|编辑器json元素列表|是|具体参考编辑器json协议，可用[sdk工具](https://kumega.now.baidu.com/#ApiTools-json)参考||
|position|int|位置信息|否|mode = sibling时，值为偏移量，举例：-1为节点上方，1为节点下方|1|
|properties|object|编辑器json元素信息|否|具体参考编辑器json协议，可用[sdk工具](https://kumega.now.baidu.com/#ApiTools-json)参考当是 update 模式时，若需要更新节点属性，才需要传|{"color": "#000000"}|



**参数示例 RequestExample**

### **sibling模式-追加到文档底部-参数示例**
```
{
    "docGuid": "FiLHDahuHLECVI",
    "editorUsername": "zhangsan",
    "operations": [
        {
            "mode": "sibling",
            "json": [
                {
                    "type": "paragraph",
                    "children": [
                        {
                            "text": "sibling模式不指定BlockId时，默认追加到文档底部的文本"
                        }
                    ]
                }
            ]
        }
    ],
    "publish": true
}
```

```
# !/usr/bin/python3

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2025/7/1
@desc:   
"""

import json

import requests

# TODO 提供你自己的username  token
TESTONE_USERNAME = ''
TESTONE_TOKEN = ''


def update_doc():
    url = "https://testone.baidu-int.com/api/ku/updateKuDoc"
    headers = {
        "username": TESTONE_USERNAME,
        "token": TESTONE_TOKEN,
        "Content-Type": "application/json"
    }

    body = {
            "docGuid": "", // 你自己的文档ID
            "operations": [
                {
                    "mode": "sibling",
                    "json": [
                        {
                            "type": "paragraph",
                            "children": [
                                {
                                    "text": "sibling模式不指定BlockId时，默认追加到文档底部的文本"
                                }
                            ]
                        }
                    ]
                }
            ],
            "publish": true
        }

    response = requests.post(
        url=url, headers=headers,
        data=json.dumps(body, ensure_ascii=False).encode("utf-8"), ).json()
    print(response)


if __name__ == '__main__':
    update_doc()

```
