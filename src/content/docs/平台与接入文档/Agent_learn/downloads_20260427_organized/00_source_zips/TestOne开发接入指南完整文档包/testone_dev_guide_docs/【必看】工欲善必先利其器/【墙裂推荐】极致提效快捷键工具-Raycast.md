# 1、个人最常用的功能
个人最高频的2个场景

* 粘贴板
* 超链



## **粘贴板历史内容检索**
经常需要复用之前已经复制的内容，每次需要的时候直接几个快捷键就可以一步到位

> option+space  -> his(history简写)  -> xxx(直接根据一些关键词就可以把历史粘贴板的内容筛选出来了)
> * option+space: 调出输入框
> * his  ：快捷筛选出 Clipboard History 
> * xxx  ：关键字搜索粘贴板的内容
> 
>

## 链接快速打开
日常工作需要可能收藏了几十上百个各种链接，需要的时候关键字快速检索并直接浏览器打开（就不用浏览器收藏夹慢慢找了）

> option+space  -> his(history简写)  -> xxx(直接根据一些关键词就可以把历史粘贴板的内容筛选出来了)
> * option+space: 调出输入框 
> * xxx  ：关键字搜索收藏的链接并打开
>
