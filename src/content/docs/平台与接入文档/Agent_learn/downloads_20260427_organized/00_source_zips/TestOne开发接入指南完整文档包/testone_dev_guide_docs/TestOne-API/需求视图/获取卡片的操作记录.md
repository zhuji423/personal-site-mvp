获取卡片的操作记录

**接口地址：**

https://testone.baidu-int.com/api/testCard/getOperateRecordByIcafeId?icafeId={ICAFE_ID}

**请求类型：**

GET

**Header:**

username: 个人邮箱前缀

token: 个人在TestOne平台Token (获取方式：[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken) )

**请求参数：**

|字段|类型|是否必须|含义|示例|
|-|-|-|-|-|
|icafeId|string|是|icafe卡片ID|youtrack-898|



**示例代码：**

```
import requests

def demo(icafe_id):
    url = "https://testone.baidu-int.com/api/testCard/getOperateRecordByIcafeId?icafeId={}".format(icafe_id)
    headers = {
        "username": TESTONE_USERNAME,
        "token": TESTONE_TOKEN
    }

    response = requests.get(url=url,headers=headers).json()
    print(response)

```
