# 1、背景
大家之前建设了很多能力，但是推动落地特别的艰难。

毕竟要让大家养成习惯、例行的去用一个或者多个新的其他平台，这个太难太难了，除非遇到阻塞性流程必须用，否则但凡能不用都不会主动去用的。

基于如流群侧边栏，不需要大家养成新的习惯主动去找到那么多平台去用。大家天天都在群里沟通，顺手点开就能看见，开发者把各种平台的数据聚合好，主动的推给群里的用户。

从原来让用户养成习惯主动去各平台寻找信息，变成了开发者把用户需要信息准备好主动放到群里面
