根据业务线获取映射平台信息

**接口信息**

> 地址：https://testone.baidu-int.com/api/department/getDeptMapConfsByDept?deptId=xxx&subDirection=xxx&platformId=x
> 方法：GET


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|guyouda|
|token|string|Token |xxxxxx|



**参数**

|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|deptId|int|是|业务线ID|222|
|subDirection|string|是|业务子方向|搜索|
|platformId|int|否|映射的平台ID，QAMate填1，QTest填2|1|



**返回**

            "deptName": "百度APP",
