更新或删除任务排期

# 一、删除任务排期
**功能**

> 删除任务排期


**接口信息**

> 地址：https://testone.baidu-int.com/api/calendar/updateCalenderList
> 方法：POST


**Header**

|字段|类型|含义|获取方式|
|-|-|-|-|
|username|string|用户名|浏览器打开[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken)链接获取|
|token|string|Token |浏览器打开[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken)链接获取|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|id|Long|是|日历ID|250975|
|taskId|Long|是|任务ID|722170|
|isDeleted|Integer|是|是否删除|1|
|taskInfo|object|是|task任务详情|{            "id":722170 }|

**参数**

```
[
    {
        "id":250975,
        "taskId": 722170,
        "taskInfo":{
            "id":722170
        },
        "isDeleted": 1
    }
]
```


**返回数据**

```
{
    "code": 0,
    "msg": "success",
    "requestId": "20260316-server-03-abf1-e223e341d167",
    "owner": "wushaoshan",
    "data": null
}
```
# 二、更新任务排期
**功能**

> 更新任务排期


**接口信息**

> 地址：https://testone.baidu-int.com/api/calendar/updateCalenderList
> 方法：POST


**Header**

|字段|类型|含义|获取方式|
|-|-|-|-|
|username|string|用户名|浏览器打开[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken)链接获取|
|token|string|Token |浏览器打开[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken)链接获取|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|id|Long|是|日历ID|250975|
|taskId|Long|是|任务ID|722170|
|taskInfo|object|是|task任务详情|{            "id":722170 }|
|isDeleted|Integer|是|是否删除|0|
|startTime|Date|是|排期开始时间|2026-03-16 14:00:00|
|endTime|Date|是|排期结束时间|2026-03-18 18:00:00|

**参数**

```
[
    {
        "id": 250975,             // 日历ID
        "taskId": 722170,         // 任务ID
        "taskInfo":{
            "id":722170
        },
        "isDeleted":0,
        "startTime": "2026-03-16 14:00:00",  // 开始时间
        "endTime": "2026-03-18 18:00:00"     // 结束时间
    }
]
```


**返回数据**

```
{
    "code": 0,
    "msg": "success",
    "requestId": "20260316-server-03-abf1-e223e341d167",
    "owner": "wushaoshan",
    "data": null
}
```
