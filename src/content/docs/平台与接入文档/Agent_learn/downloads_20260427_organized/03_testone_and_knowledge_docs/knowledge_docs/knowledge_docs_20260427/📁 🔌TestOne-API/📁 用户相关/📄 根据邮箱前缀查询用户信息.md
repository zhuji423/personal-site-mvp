根据邮箱前缀查询用户信息

**功能**

> 根据邮箱前缀查询用户信息，返回中文姓名等数据




**接口信息**

> 地址：https://testone.baidu-int.com/engine/infoflow/getUserInfo
> 方法：GET


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string||application/json|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|xxxx|



**cURL**

```
curl --location 'https://testone.baidu-int.com/engine/infoflow/getUserInfo?username=lijiaxin11' \
--header 'username: xxx' \
--header 'token: xxx'
```


**返回示例**

```
{
    "code": 0,
    "msg": "success",
    "requestId": "20260123-engine-01-863b-4c86f49281b5",
    "data": {
        "username": "lijiaxin11",
        "name": "黎佳欣",
        "email": "lijiaxin11@baidu.com",
        "hiNumber": "GaZnLi",
        "orgChainNameCn": "移动生态事业群组/*/移动生态质量效能部/健康质量效能组"
    }
}
```
