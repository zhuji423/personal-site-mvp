## JSON解析HTML和MD接口 /kuJsonParse
接口地址：http://testone-test.bcc-szzj.baidu.com:8080/kuJsonParse  

注意：由于后续知识库可能会直接提供MD/HTML 或者提供统一的转化服务，目前我们的场景单一，且流量很低，故临时搭建一个线下服务

#### 接口说明
`/kuJsonParse` 提供将特定格式的JSON数据解析为HTML或Markdown（MD）文本的功能。此服务旨在作为临时解决方案，满足快速将结构化数据转换为可阅读文本的需求。

#### 请求方法
**POST**

`'Content-Type: application/json'`

#### 请求URL
`/kuJsonParse`



#### 请求参数
|参数名|类型|说明|是否必填|
|-|-|-|-|
|type|string|输出类型，可选值为`html`或 `markdown`|是|
|json|object[]|从知识库获取的文档 json 文件|是|

#### 响应参数
|参数名|类型|说明|
|-|-|-|
|`code`|number|响应状态码，`0`表示成功，`400` 表示错误|
|`message`|string|响应状态信息，成功时为`success`，错误时提供错误描述|
|`data`|string | null|解析后的HTML或Markdown文本内容|



#### 示例请求
```
{
  "type": "html",
  "json": [
        {
            "type": "paragraph",
            "children": [
                {
                    "text": "这个是morpho的json数据"
                }
            ]
        },
        {
            "type": "paragraph",
            "children": [
                {
                    "text": "是知识库文档本质"
                }
            ]
        },
        {
            "type": "heading",
            "blockId": "docyg-4dd8a990-0305-11f0-920e-87ec44cd5687",
            "children": [
                {
                    "text": "大标题"
                }
            ],
            "level": 1
        },
        {
            "type": "heading",
            "blockId": "docyg-4a0421f0-0305-11f0-920e-87ec44cd5687",
```

若请求参数不符合要求或解析过程中发生错误，接口将返回相应的错误状态码和信息。请根据错误信息调整请求参数或联系技术支持。

## HTML和MD解析JSON接口 /kuMdHtmlToJson
接口地址：http://testone-test.bcc-szzj.baidu.com:8080/kuMdHtmlToJson

#### 接口说明
`/kuMdHtmlToJson` 提供将HTML或Markdown解析为JSON

#### 请求方法
**POST**

`'Content-Type: application/json'`

#### 请求URL
`/kuMdHtmlToJson`

#### 请求参数
|参数名|类型|说明|是否必填|
|-|-|-|-|
|type|string|输入类型，可选值为`html`或 `markdown`|是|
|data|string|对应类型的数据|是|

#### 响应参数
|参数名|类型|说明|

# 已知问题：
## 部分情况下使用 /kuMdHtmlToJson 报错 cheerioHTML is not a function
```
{
    "code": 400,
    "message": "解析时发生错误",
    "data": "cheerioHTML is not a function"
}
```
临时服务系统库node版本低问题导致，可以自行使用 node版本>=22 的服务解析
