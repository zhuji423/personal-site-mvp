**功能**

> 查询集成视图下的需求卡片


**接口信息**

> 地址：https://testone.baidu-int.com/api/task/getTasksByVersionAndClient
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|YOUR_NAME|
|token|string|Token |YOUR_TOKEN|



**参数**

```
{

    "subDirection": "基础",
    "hostClient": "Web",
    "version": "15.32.0"
}
```
