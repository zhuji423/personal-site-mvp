需求筛选接口

**功能**

> 查询业务需求卡片列表


**接口信息**

> 地址：https://testone.baidu-int.com/api/task/getTasksV2
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|pageNum|int|是|第几页|1|
|pageSize|int|是|每页的数量（最多允许200）|50|
|data|object|是|筛选参数||
|        data.deptId|int|否|业务线ID|222|
|        data.subDirection|string|否|业务子方向|搜索|
|        data.clientList|array[string]|否|端类型列表，多选，可选项：AndroidiOSHarmonyServerWeb|[ "Android", "iOS"]|
|        data.cardTypeList|array[string]|否|iCafe卡片类型|[ "Feature", "Story"]|
|        data.versionList|array[string]|否|版本列表|["13.75.0"]|
|        data.icafeStatusList|array[string]|否|iCafe状态列表|[ "新建","开发中"]|
|        data.dimensionStatusList|array[string]|否|卡片在TestOne的状态列表|[ "新建","开发中"]|
|        data.rdSelfTest|bool|否|是否自主测试|false|
|        data.rdList|array[string]|否|RD邮箱前缀列表|["guyouda", "wangshitao"]|
|        data.qaList|array[string]|否|QA邮箱前缀列表|["guyouda", "wangshitao"]|
|        data.submitTestAfter|string|否|*提测时间大于等于 submitTestAfter*|2024-10-01 00:00:00|
|        data.submitTestBefore|string|否|提测时间小于等于 submitTestBefore|2024-11-01 00:00:00|
|        data.onlineTimeAfter|string|否|上线时间大于等于 onlineTimeAfter|2024-11-01 00:00:00|
|        data.onlineTimeBefore|string|否|上线时间小于等于 onlineTimeBefore|2024-11-01 00:00:00|
|        data.cardCreateAfter|string|否|卡片创建时间大于等于 cardCreateAfter|2024-11-01 00:00:00|
|        data.cardCreateBefore|string|否|卡片创建时间小于等于 cardCreateBefore|2024-11-01 00:00:00|
||||||

```
# !/usr/bin/python3

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2024/11/20
@desc:   
"""
import json

import requests


def sample():
    url = "https://testone.baidu-int.com/api/task/getTasksV2"
    headers = {
        'username': YOUR_NAME,
        'token': YOUR_TOKEN,
        'Content-Type': 'application/json'
    }

    data = {
        "pageNum": 1,
        "pageSize": 50,
        "data": {
            "deptId": 222,
            "subDirection": "基础",
            "cardTypeList": [
                "Feature",
                "Story"
            ],
            "versionList": [
                "13.75.0"
            ],
            "icafeStatusList": [
                "开发中",
                "已上车",
                "测试中"
            ]
        }
    }

    response = requests.post(url, headers=headers, data=json.dumps(data))

    print(response.text)


if __name__ == '__main__':
    sample()

```
