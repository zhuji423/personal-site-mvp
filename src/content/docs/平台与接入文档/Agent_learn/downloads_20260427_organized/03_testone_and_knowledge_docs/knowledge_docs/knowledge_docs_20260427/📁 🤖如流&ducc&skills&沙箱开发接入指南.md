> 可以把我们理解为OpenClaw的精简版🐶，目的就是让大家可以低成本的使用AI帮自己完成各种工作
> OpenClaw现阶段的几个点有一定的欠缺，个人玩很不错，但是团队使用场景有一定欠缺
> * 想定制开发改造成本太大
> * 多用户场景
> * 任务串行排队
> * 不能自己控制会话记忆机制
> 
> 
> 我们的特色：
> * 和如流数字员工+侧边栏整合，可以直接在如流单聊/群聊@数字员工调起，执行过程流式回复
> * 定制开发成本极低，支持大家结合自己的业务需要低成本开发落地应用
> * ToB+ToC两条线：
>     * ToB：支持大家低成本定制开发落地（openClaw的复杂度可不是你想该就能改的）
>     * ToC：平台直接上传自己的SKILL，选择其他公开的SKILL即可直接使用
