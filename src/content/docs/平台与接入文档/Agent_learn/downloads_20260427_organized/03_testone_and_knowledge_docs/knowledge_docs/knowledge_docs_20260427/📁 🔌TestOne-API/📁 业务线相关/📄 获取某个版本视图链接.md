获取某个版本视图链接

## 1、获取业务线的项目模式配置


**接口信息**

> 地址：https://testone.baidu-int.com/api/conf/customProjectMode/getConfByType?deptId=xxx&subDirection=xxx&modeType=x
> 方法：GET


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|guyouda|
|token|string|Token |xxxxxx|



**参数**

|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|deptId|int|是|业务线ID|222|
|subDirection|string|是|业务子方向|搜索|
|modeType|int|是|业务模式类型，随版模式填0，非随填1|0|



**返回**

```

    "data": {

        "modeType": 0,
        "defaultMode": 0,
        "isRelease": 0,
        "followHost": 1,
        "hosts": "百度APP",
        "template": null,
        "creator": "gaolizhe",

        "operator": "gaolizhe",

    }
}
```
## 2、获取版本视图中的版本列表
**接口信息**

> 地址：https://testone.baidu-int.com/api/version/getVersionList
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|guyouda|
|token|string|Token |xxxxxx|



**参数**

```
{
    "deptId": 222,
    "subDirection": "搜索",
    "isRelease": 0,
    "version": "13.53.0",
    "hostClient": "iOS"
}
```
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|deptId|int|是|业务线ID|222|
|subDirection|string|是|业务子方向|搜索|
|isRelease|int|是|是否发版，可通过上一个接口获取|0:不发版，1:发版|
|version|string|否|版本|13.53.0|
|hostClient|string|否|端类型|iOS|



**返回**

```
{
    "code": 0,
    "msg": "success",
    "requestId": "62c3123f-cf83-471f-99eb-0a2f31a7fe7a",
    "data": [

            "id": 5419,
            "deptId": 222,
            "subDirection": "搜索",
            "versionType": "VERSION",
            "version": "13.53.0",
            "versionCalendar": null,
            "host": "",
            "hostClient": "iOS",
            "hostVersion": "",
            "hostCalendar": null,
            "creator": "TestOne",
            "operator": "TestOne",
            "createdTime": "2024-02-26 20:37:30",

}
```
## 3、拼接某个版本视图链接
https://testone.baidu-int.com/#/testone/task/detail?id=xxx&type=1&isRelease=0

* isRelease：第一个接口返回数据中isRelease字段
* type：固定值为1，表示版本视图
* id：第二个接口返回数据中的id
