查询工具执行历史记录

**功能**

> 分页查询工具的历史执行记录


**接口信息**

> 地址：https://testone.baidu-int.com/engine/storyAgent/executeResult/getToolResultWithStoryAgent
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|pageNum|int|是|第几页|1|
|pageSize|int|是|每页的条数 （1~200）|20|
|data|object|是|||
|        toolId|string|是|工具ID|01b82eb75363e86049b50271214e11dd|
|        startTime|string|否|开始时间|2025-01-01 00:00:00|
|        endTime|string|否|结束时间|2025-02-01 00:00:00|
|        deptId|int|否|业务线ID|222|
|        subDirection|string|否|业务子方向|基础|

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2024/11/20
@desc:   
"""
import json

import requests


def sample():
    url = "https://testone.baidu-int.com/engine/storyAgent/executeResult/getToolResultWithStoryAgent"
    headers = {
        'username': YOUR_NAME,
        'token': YOUR_TOKEN,
        'Content-Type': 'application/json'
    }

    data = {
            "pageSize": 20,
            "pageNum": 1,
            "data":{
                "toolId":"01b82eb75363e86049b50271214e11dd",
                "deptId":26674,
                "startTime":"2025-03-01 00:00:00",
                "endTime":"2025-03-05 00:00:00"
            }
        }

    response = requests.post(url, headers=headers, data=json.dumps(data))

    print(response.text)


if __name__ == '__main__':
    sample()
