# 3、准入阶段
## 3.1、申请准入豁免
```
curl --location 'https://testone.baidu-int.com/api/testCard/openApi/operate' \
--header 'username: YOUR_NAME' \
--header 'token: YOUR_TOKEN' \
--header 'Content-Type: application/json' \
--data '{
    "icafeId": "youtrack-12345",
    "operate": 12,
    "step": 3,
    "operator": "",
    "reason": "为什么要申请豁免"
}'
```
|字段|类型|含义|
|-|-|-|
|icafeId|string|iCafe卡片ID|
|operate|int|固定填12|
|step|int|3|
|operator|string|操作人|
|reason|string|操作原因|

# 4、测试阶段
## 4.1、开始测试
```

--header 'username: YOUR_NAME' \
--header 'token: YOUR_TOKEN' \
--header 'Content-Type: application/json' \
--data '{
    "icafeId": "youtrack-12345",
    "operate": 2,
    "step": 4,
    "operator": "",
    "reason": "xxx点击了开始测试"
}'
```
|字段|类型|含义||
