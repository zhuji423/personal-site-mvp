获取业务线QA排期

**功能**

> 查询业务线QA排期数据


**接口信息**

> 地址：https://testone.baidu-int.com/api/calendar/getCalenderListByDept
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|deptIds|List|是|部门id及子方向|["222@基础", "222@搜索"]|
|userType|string|是|用户类型：0：正式， 1：外包， 2：实习生，空字符串表示全部类型|“1”|
|users|string|否|指定用户名|zhangsan|
|taskTypeIds|List|是|任务类型：0：其他任务  1：模块测试任务  2：集成测试任务  3：写Case   4：值班  5：休假  6：业务Topic   -1：全部类型|["0"]|
|icafeCardTypes|List|是|卡片类型：Story、Feature、all|["Feature"]|
|startTime|String|是|开始时间|"2025-05-15 00:00:00"|
|endTime|String|是|结束时间|"2025-05-26 23:59:59"|

**参数**

```
{
    "deptIds": [
        "222@基础",
        "222@搜索"
    ],
    "userType": "2",
    "taskTypeIds": [
        "-1"
    ],
    "icafeCardTypes": [
        "all"
    ],
    "startTime": "2025-05-15 00:00:00",
    "endTime": "2025-05-26 23:59:59",
    "users": [

    ]
}
```
