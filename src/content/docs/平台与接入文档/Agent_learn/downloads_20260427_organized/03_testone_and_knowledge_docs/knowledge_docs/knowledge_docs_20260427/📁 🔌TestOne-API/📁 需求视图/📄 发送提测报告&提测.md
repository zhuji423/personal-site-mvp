发送提测报告&提测

**功能**

> 发送提测报告


**接口信息**

> 地址：https://testone.baidu-int.com/api/testCard/report/send
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string||application/json|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

> 针对非必填项，不传此字段，表示不限制
|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|**dimensionId**|int|是|卡片在TestOne平台的唯一ID。获取方式 [根据iCafeId查询任务详情](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/3LoFUu-M_a/U-RwwdZ7ut/a714d3205caf49?t=mention&mt=doc&dt=doc)|**152861**|
|**dimensionType**|int|是|类型：固定0|0|
|**sceneType**|int|是|场景：固定0|0|
|**report**|object|否|报告详细内容针对不需要填写提测报告的业务，直接null即可{
    "qaList": {
        "value": [    // 若无QA负责人, value=[]
            "nieyuxin"     
        ]
    },
    "rdList": {
        "value": [
            "guyouda"     // 若无RD负责人, value=[]
        ]
    },
    "selfTest": {
        "value": false   // 是否自主测试(必填, true or false)
    },
    "receiveEmailList": {
        "value": [       // 收件人邮箱前缀列表, 无需收件人 value=[]
            "nieyuxin"
        ]
    },
    "carbonCopyEmailList": {
        "value": [      //  抄送人邮箱前缀列表, 无需抄送收件人 value=[]

        ]
    },
    "otherFields": [   //   其他业务自定义字段

    ]
}||
||||||



**返回**

```
{
    "code": 0,      // 0: 成功   其他:失败，失败原因详见msg字段
    "msg": "success",
    "requestId": "121f7326-966d-47bf-9dd8-28965acdb90f",
    "owner": "guyouda",
    "data": null
}
```
