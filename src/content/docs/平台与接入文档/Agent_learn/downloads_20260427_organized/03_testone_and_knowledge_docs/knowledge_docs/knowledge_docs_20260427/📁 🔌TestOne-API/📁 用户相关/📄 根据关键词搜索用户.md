根据关键词搜索用户

**功能**

> 根据邮箱前缀查询用户信息，返回中文姓名等数据，模糊查询




**接口信息**

> 地址：https://testone.baidu-int.com/engine/infoflow/searchUser
> 方法：GET


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string||application/json|
|username|string|用户名|xxxxxx|
|token|string|Token |xxxxxx|



**参数**

|字段|类型|含义|示例|
|-|-|-|-|
|key|string|用户名|xxxx|



**cURL**

```
curl --location 'https://testone.baidu-int.com/engine/infoflow/searchUser?key=lijiaxin' \
--header 'username: xxx' \
--header 'token: xxx'
```
