环境搭建组件

注意:  qep-delivery-component  需要升级到  **0.0.2.0 或者更高版本**



# 1、环境搭建执行流程
针对可以做到完全自动部署的业务/需求，建议以下流程：

* TestOne调起业务Agent
* 业务Agent调起环境部署工具，自动部署(或者获取已经部署的环境信息)，直接通过表格  富文本等样式封装返回在前端展示即可



本文的流程仅仅是针对需要用户手动填写信息才能部署环境的场景设计



# 2、环境搭建工具开发
## 2.1、实现Tool
在Agent代码的  tools包下新增一个文件   deploy_test_env.py

在工具内，实现搭建环境依赖的前端输入组件下发

> 以下仅为参考示例，具体下发什么，根据业务需要自行决定
```
# !/usr/bin/python3

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2024/2/29
@desc:
"""

from qep_delivery_component import ComponentOperateConfig
from qep_delivery_component import DigitalFormDetail
from qep_delivery_component import EnvironmentSetupComponent
from qep_delivery_component import EnvironmentSetupDetail
from qep_delivery_component import InputTypeEnum
from qep_delivery_component import TableFormDetail
from qep_delivery_component import TableFormHeadConfig
from qep_delivery_component import TextFormDetail
from qep_delivery_tools import BaseTool
from qep_delivery_tools import Parameter
from qep_delivery_tools import ToolResult


class DeployTestEnvTool(BaseTool):
    """
    测试环境部署工具
    """

    def __init__(self):
        super().__init__("xxxxxxx")   # TODO  更换为自己业务的注册环境搭建工具ID
        self.kirin_env_setup_id = xxx   # TODO  更换为自己在麒麟注册的环境搭建策略ID （环境搭建比较耗时，策略建议异步）

    def execute(self, parameter: Parameter) -> ToolResult:
        """
        获取iCafe信息
        """
        component_operate_config = ComponentOperateConfig(expand=True, enable_refresh=False)
        form_list = [
            TextFormDetail(
                name="name",
                display_value="环境名字",
                required=True,
                default_value="需求xxx的测试环境"
            ),
            DigitalFormDetail(
                name="envId",
                display_value="环境ID(如果填写则复用)",
                required=False
            ),
            TableFormDetail(
                name="codeInfo",
                display_value="代码信息",
                head=[
                    TableFormHeadConfig(data_index="module", title="模块", copyable=True, ellipsis=False,
                                        type=InputTypeEnum.TEXT, edit=True
                                        ),
                    TableFormHeadConfig(
                        data_index="branch", title="分支", copyable=True, ellipsis=False
                    ),
                    TableFormHeadConfig(
                        data_index="pipelineName", title="流水线名称", copyable=True,
                        ellipsis=False
                    ),
                    TableFormHeadConfig(
                        data_index="eks", title="是否使用eks", copyable=True, ellipsis=True,
                        type=InputTypeEnum.SINGLE_SELECT, select_items=["是", "否"]
                    ),
                ],
                default_value=[
                    {"module": "baidu/ep-qa/testone-server1", "branch": "master", "pipelineName": None,
                     "eks": "是"},
                    {"module": "baidu/ep-qa/testone-server2", "branch": "master2",
                     "pipelineName": "ChangePipeline", "eks": "是"}
                ],
                required=True
            )
        ]
        environment_setup_component = EnvironmentSetupComponent(
            component_operate_config=component_operate_config,
            component_data=EnvironmentSetupDetail(env_strategy=self.kirin_env_setup_id, form_list=form_list))
        return ToolResult(self.tool_id, environment_setup_component)

```

# 3、环境部署麒麟策略开发
Agent里面的Tool只是下发了一个展示环境搭建依赖的组件信息，用户在点击“创建环境”按钮的时候，需要调起一个环境搭建的麒麟策略（仅支持麒麟）

环境搭建相对耗时，建议是麒麟异步策略

## 3.2、环境搭建逻辑实现

## 3.2、环境信息返回给平台
接口地址  https://testone.baidu-int.com/api/env/callbackEnvInfo

请求类型：POST

Header：

username: 自己的用户名

token:  自己在TestOne平台的Token， 获取方式： [https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken)
