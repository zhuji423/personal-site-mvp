获取业务线版本列表

**功能**

> 查询业务随版版本列表


**接口信息**

> 地址：https://testone.baidu-int.com/api/version/getHostInfoGroupByVersion
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string|-|application/json|
|username|string|用户名|guyouda|
|token|string|Token |xxxxxx|



**参数**

|字段|类型|必填|含义|示例|
|-|-|-|-|-|
|deptId|int|是|业务线ID|222|
|subDirection|string|是|业务子方向|搜索|
|clientList|List<String>|否|端类型|[    "Android"]|
|versionList|List<String>|否|版本号|[    "13.47.5"]|
