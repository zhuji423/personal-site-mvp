# 2、接口信息
**功能**

> 创建文档
> 知识库原始API定义请参考 [知识库OpenAPI - 创建文档](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/2tsPs8CtSd/Bu7DDg4dpB/6qO2n5_lXzrcN8?t=mention&mt=doc&dt=doc)
> TestOne仅仅是把相关能力直接封装，方便大家加个权限就可以直接使用


**接口信息**

> 地址：https://testone.baidu-int.com/api/ku/createKuDoc
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|Content-Type|string|-|application/json|
|username|string|用户名|xxxxx  TestOne平台右上角获取|
|token|string|Token |xxxxxx  TestOne平台右上角获取|

  - 子无序列表1

```
# !/usr/bin/python3

# -*- coding: utf-8 -*-

"""
@author: GuYouda
@date:   2025/7/1
@desc:   
"""

import json

import requests

# TODO 提供你自己的username  token
TESTONE_USERNAME = ''
TESTONE_TOKEN = ''


def create_doc():
    url = "https://testone.baidu-int.com/api/ku/createKuDoc"
    headers = {
        "username": TESTONE_USERNAME,
        "token": TESTONE_TOKEN,
        "Content-Type": "application/json"
    }

    body = {
        "createMode": 2,       # 创建模式，指定内容创建，固定2
        "repositoryGuid": "",  # 知识库ID
        "title": "指定Markdown创建的文档",  # 文档标题
        "parentDocGuid": "",  # 父文档ID
        "contentInfo":
            {
                "protocol": 2,       // 2： markdown格式
                "contentType": 1,    //1: 普通模式  2：卡片模式
                "text": "### 标题\n- 无序列表\n  - 子无序列表1\n  - 子无序列表2\n1. 有序列表1"
                
            }
    }

    response = requests.post(
        url=url, headers=headers,
        data=json.dumps(body, ensure_ascii=False).encode("utf-8"), ).json()
    print(response)


if __name__ == '__main__':
    create_doc()
```
