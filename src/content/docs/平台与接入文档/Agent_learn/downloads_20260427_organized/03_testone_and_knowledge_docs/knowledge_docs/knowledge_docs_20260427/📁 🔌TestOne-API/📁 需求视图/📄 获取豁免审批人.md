**接口信息**

> 地址：https://testone.baidu-int.com/api/conf/operateApprover/get
> 方法：POST


**Header**

|字段|类型|含义|示例|
|-|-|-|-|
|username|string|用户名|YOUR_NAME|
|token|string|Token |YOUR_TOKEN|

{
    "deptId": 222,
    "subDirection": "基础"
}
