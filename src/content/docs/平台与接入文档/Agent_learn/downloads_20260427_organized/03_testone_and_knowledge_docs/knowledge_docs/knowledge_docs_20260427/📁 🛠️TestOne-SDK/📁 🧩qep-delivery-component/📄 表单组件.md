表单组件

# 1、功能
* 业务开发者可以按照业务需求的需要下发一个表单输入组件
* 用户可以根据要求填写内容并提交
* 用户提交的数据会存储在TestOne平台（如果业务开发者需要感知到用户提交的数据并进行对应的业务逻辑处理，可以随表单组件下发一个麒麟服务ID，提交后平台也会自动调起该API）

![](/personal-site-mvp/img/doc-placeholder.svg "")
# 2、使用场景
* 发送报告
* 签章
* 测试过程信息提交记录
* 提测&测试报告
* 数据查询展示(待支持)
* 工具数据的标注
* ......

```
from qep_delivery_component import (
    FormComponent,
    SingleSelectFormDetail,
    TextFormDetail,
    TextareaFormDetail,
    CascadeRule
)

class CascadeFormTool(BaseTool):
    def execute(self, parameter):
        form = FormComponent(
            component_operate_config=ComponentOperateConfig(),
            component_data=[
                # 主控字段：导入方式
                SingleSelectFormDetail(
                    name="importType",
                    display_value="导入方式",
                    required=True,
                    select_items=["全量导入", "部分导入", "自定义导入"],
                    cascade_rules=[
                        # 规则1：选择"部分导入"时显示范围和详情
                        CascadeRule(
                            trigger_value="部分导入",
                            show_fields=[
                                {"name": "importRange", "required": True, "tip": "请指定导入范围"},
                                {"name": "importDetails"}
                            ]
                        ),
                        # 规则2：选择"自定义导入"时显示配置
                        CascadeRule(
                            trigger_value="自定义导入",
                            show_fields=[
                                {"name": "customConfig", "required": True}
                            ]
                        )
                    ]
                ),

                # 受控字段：默认隐藏，满足条件时显示
                TextFormDetail(
                    name="importRange",
                    display_value="导入范围",
                    required=False  # 被规则覆盖为 True
                ),
                TextareaFormDetail(
                    name="importDetails",
                    display_value="导入详情",
                    required=False
                ),
                TextareaFormDetail(
                    name="customConfig",
                    display_value="自定义配置",
                    required=False  # 被规则覆盖为 True
                )
            ],
            submit_btn_name="开始导入"
        )

        return ToolResult(self.tool_id, form, ToolExecuteStatusEnum.SUCCESS)
```
**工作原理**：

1. **初始状态**：只显示"导入方式"下拉框
2. **选择"部分导入"**：显示"导入范围"（必填）和"导入详情"
3. **选择"自定义导入"**：显示"自定义配置"（必填）
4. **提交**：只提交可见字段的值

## 表单类型完全参考
### 基础输入类（9种）
#### 1. TEXT - 单行文本输入
**用途**：短文本输入（如姓名、标题）

```
TextFormDetail(
    name="title",
    display_value="标题",
    required=True,
    min_length=5,      # 最小长度
    max_length=100,    # 最大长度
    default_value="",
    tip="请输入标题（5-100字符）",
    disabled=False,
    col_span=2,        # 占用宽度：1-6（页面均分为6块）
    hidden=False
)
```
**前端渲染**：`ProFormText`
**提交值类型**：`string`

---

#### 2. TEXTAREA - 多行文本输入
**用途**：长文本输入（如描述、备注）

```
TextareaFormDetail(
    name="description",
    display_value="描述",
    required=False,
    min_length=10,
    max_length=1000,
    default_value="",
    col_span=4  # 通常占用更大宽度
)
```
**前端渲染**：`ProFormTextArea`（自动调整高度 1-6行）
**提交值类型**：`string`

---

#### 3. DIGITAL - 数字输入
**用途**：整数或浮点数输入

## 级联功能完全指南
### 核心概念
#### 1. 受控字段
* **定义**：出现在任何 `cascadeRules.showFields` 中的字段
* **默认状态**：隐藏（不渲染，不验证，不提交）
* **显示条件**：满足任一触发条件时显示
* **固定位置：**根据拼装的位置展示表单项

#### 2. 非受控字段
* **定义**：不受任何级联规则控制的字段
* **默认状态**：始终显示

#### 3. 触发值（Trigger Value）
* **类型**：`string` 
* **作用**：定义何时显示受控字段

#### 4. 属性覆盖（Field Override）
* **作用**：动态修改受控字段的配置
* **可覆盖属性**：`required`, `disabled`, `tip`等
* **不可覆盖属性**：`name`, `type`,`defaultValue`

---

### 触发逻辑详解
#### 单选类型（SINGLE_SELECT, RADIO）
```
# 触发条件：精确匹配
SingleSelectFormDetail(
    name="importType",
    select_items=["全量", "部分"],
    cascade_rules=[
        CascadeRule(
            trigger_value="部分",  # 字符串
            show_fields=[{"name": "range"}]
        )
    ]
)

# 前端判断逻辑：
# currentValue === "部分"  → 显示 range
```
#### 多选类型（MULTI_SELECT）
**模式1：单个触发值（包含判断）**

```
MultiSelectFormDetail(
    name="testTypes",
    select_items=["功能测试", "性能测试", "安全测试"],
    cascade_rules=[
        CascadeRule(
            trigger_value="性能测试",  # 字符串
            show_fields=[{"name": "performanceConfig"}]
        )
    ]
)

# 前端判断逻辑：
# ["功能测试", "性能测试"].includes("性能测试")  → True（显示）
# ["功能测试", "安全测试"].includes("性能测试")  → False（隐藏）
```
**模式2：多个触发值（包含任一）**

```
MultiSelectFormDetail(
    name="testTypes",
    select_items=["功能测试", "性能测试", "压力测试", "安全测试"],
    cascade_rules=[
        CascadeRule(
            trigger_value="性能测试",
            show_fields=[{"name": "performanceConfig"}]
        ),
        CascadeRule(
            trigger_value="压力测试",
            show_fields=[{"name": "performanceConfig"}]
        )
    ]
)

# 前端判断逻辑：
# 当前值: ["功能测试", "性能测试"]
# → ["性能测试", "压力测试"].some(v => ["功能测试", "性能测试"].includes(v))
# → True（包含"性能测试"，显示）

# 当前值: ["功能测试", "安全测试"]
# → ["性能测试", "压力测试"].some(v => ["功能测试", "安全测试"].includes(v))
# → False（无交集，隐藏）
```

### 属性覆盖机制
#### 可覆盖属性清单
|属性|类型|说明|适用字段类型|
|-|-|-|-|
|`required`|`bool`|是否必填|所有|
|`disabled`|`bool`|是否禁用|所有|
|`tip`|`str`|提示信息|所有|
|`colSpan`|`int`|列宽（1-6）|所有（除 RICH_TEXT）|
|`min`|`int/float`|最小值|DIGITAL|
|`max`|`int/float`|最大值|DIGITAL|
|`minLength`|`int`|最小长度|TEXT, TEXTAREA, URL, KU_CRAWL|
|`maxLength`|`int`|最大长度|TEXT, TEXTAREA, URL, KU_CRAWL|
|`selectItems`|`List`|选项列表|SINGLE_SELECT, MULTI_SELECT, RADIO, TAG|

#### 不可覆盖属性
* `name`：字段名（用于匹配）
* `type`：字段类型（不允许改变类型）
* `defaultValue`：默认值

#### 覆盖示例
```
CascadeRule(

    show_fields=[
        {
            "name": "timeout",
            "required": True,        # 覆盖为必填

            "max": 7200,             # 覆盖最大值
            "tip": "高级模式建议设置较长超时"  # 覆盖提示
        }
    ]
)
```

### 限制和约束
#### ⚠️ 只支持一层联动
**允许**：A 控制 B、C

```
# ✅ 正确
[
    SingleSelectFormDetail(name="A", cascade_rules=[
        CascadeRule(trigger_value="x", show_fields=[{"name": "B"}, {"name": "C"}])
    ]),
    TextFormDetail(name="B"),
    TextFormDetail(name="C")
]
```
**不允许**：A 控制 B，B 再控制 C

```
# ❌ 错误：B 是受控字段，不能再有 cascade_rules
[
    SingleSelectFormDetail(name="A", cascade_rules=[
        CascadeRule(trigger_value="x", show_fields=[{"name": "B"}])
    ]),
    SingleSelectFormDetail(name="B", cascade_rules=[  # 报错！
        CascadeRule(trigger_value="y", show_fields=[{"name": "C"}])
    ]),
    TextFormDetail(name="C")
]
```
**Python SDK 校验**：

```
# form_component.py:800
if field.name in controlled_fields:
    raise ValueError(
        f'字段 "{field.name}" 是受控字段，不允许设置 cascade_rules（只支持一层联动）'
    )
```
---

#### ⚠️ 触发值必须在 selectItems 中
```
# ❌ 错误
SingleSelectFormDetail(
    name="status",
    select_items=["待处理", "处理中", "已完成"],
    cascade_rules=[
        CascadeRule(
            trigger_value="已关闭",  # 不在 select_items 中！
            show_fields=[{"name": "closeReason"}]
        )
    ]
)

# Python SDK 校验：
# form_component.py:212
if rule.trigger_value not in valid_values:
    raise ValueError(
        f'trigger_value "{rule.trigger_value}" 不在 select_items 中: {valid_values}'
    )
```
---

#### ⚠️ 只有选择类字段支持级联
**支持的类型**：

* `SINGLE_SELECT`
* `MULTI_SELECT`
* `RADIO`

**不支持的类型**：

* TEXT, TEXTAREA, DIGITAL, DATE, DATE_TIME 等

```
# ❌ 错误
TextFormDetail(
    name="username",
    cascade_rules=[...]  # 报错：TEXT 类型不支持级联
)

# Python SDK 校验：

    raise ValueError(
        f'只有选择类字段(SINGLE_SELECT/MULTI_SELECT/RADIO)可以设置 cascade_rules'
    )
```
---

#### ⚠️ 引用的字段必须存在
```
# ❌ 错误
SingleSelectFormDetail(
    name="type",
    cascade_rules=[
        CascadeRule(
            trigger_value="A",
            show_fields=[{"name": "nonExistentField"}]  # formList 中不存在！
        )
    ]
)

# Python SDK 校验：
# form_component.py:809

    raise ValueError(
        f'字段 "{field.name}" 的 cascade_rules 引用了不存在的字段: "{field_name}"'
    )
```
