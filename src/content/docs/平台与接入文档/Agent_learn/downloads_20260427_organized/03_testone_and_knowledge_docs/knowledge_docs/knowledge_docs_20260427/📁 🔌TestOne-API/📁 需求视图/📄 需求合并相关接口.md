需求合并相关接口

# 1、新建/修改需求分组关系
允许合并的要求：

* 必须同业务的卡片
* 卡片类型必须是Story
* 卡片在TestOne平台的状态必须一致
* 父卡片必须都为空或者是同一张父卡片

**接口地址：**

https://testone.baidu-int.com/api/taskGroup/updateTaskGroup

**请求类型：**

POST

**Header:**

username: 个人邮箱前缀

token: 个人在TestOne平台Token (获取方式：[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken) )

**请求参数：**

|字段|类型|是否必须|含义|示例|
|-|-|-|-|-|
|icafeIds|List[string]|是|Icafe卡片列表|[
    "youtrack-911",
    "youtrack-914",
    "youtrack-952",
    "youtrack-928"
]|
|operator|string|否|操作人|"zhangsan"|

示例：

```
curl --location 'https://testone.baidu-int.com/api/taskGroup/updateTaskGroup' \
--header 'username: TESTONE_USERNAME' \
--header 'token: TESTONE_TOKEN' \
--header 'Content-Type: application/json' \
--data '{
    "icafeIds": [
        "youtrack-911",
        "youtrack-914",
        "youtrack-913",
        "youtrack-928"
    ],
    "operator": "zhangsan"
}'
```


# 2、解除合并
**接口地址：**

https://testone.baidu-int.com/api/taskGroup/delTaskGroupById

**请求类型：**

GET

**Header:**

username: 个人邮箱前缀

token: 个人在TestOne平台Token (获取方式：[https://testone.baidu-int.com/api/getToken](https://testone.baidu-int.com/api/getToken) )

**请求参数：**

|字段|类型|是否必须|含义|示例|
|-|-|-|-|-|
|groupId|Long|是|分组ID|59243606916988928|
|operator|string|否|操作人|"zhangsan"|

示例：

```
curl --location 'localhost:8088/api/taskGroup/delTaskGroupById?groupId=111222333&operator=zhangsan' \
--header 'username: TESTONE_USERNAME' \
--header 'token: TESTONE_TOKEN'
```
