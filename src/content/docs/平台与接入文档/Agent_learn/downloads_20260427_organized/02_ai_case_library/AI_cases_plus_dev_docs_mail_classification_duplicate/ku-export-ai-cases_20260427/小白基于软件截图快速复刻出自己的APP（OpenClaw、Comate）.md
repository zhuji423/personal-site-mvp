### 最后：
1. 厂内的 comate 也可以做到，相对来说修改会更方便，但是有一定专业性。
2. 软件不满意的地方需要再次截图+描述，让 ai 修改。
3. 这个软件是纯前端 APP，不涉及后端逻辑，所以难度较低。对于大型 APP 还是得让 Ai 先给出完整的 Plan，按照 Plan 来写。（优先推荐 comate））

# 核心要点：
* 选择**多模态模型**，如 Claude、Kimi-K2.5，保证 OpenClaw 具有读图能力
* 发送软件所有**界面截图+界面操作描述**，如“图1是首页，点击右下角的定时器后会弹出图 2”，减少歧义。
* **发送软件安装包**，让龙虾可以利用软件安装包内的原有资源，保证Ui相似度
* **多次反复调整**，利用截图+描述，调整不合适的地方
