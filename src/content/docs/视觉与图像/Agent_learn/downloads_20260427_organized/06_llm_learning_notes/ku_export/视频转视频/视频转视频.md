# 视频转视频
一、原理视频转视频会经过下面接个流程：

将原始视频进行关键帧抽帧，使用Animatediff的情况下，大约是每8帧抽1帧，一个10秒，30fps的视频，全部300帧，进行关键帧抽帧后约38个关键帧。将关键帧进行controlnet的预处理，一般采用lineart + openpose，或者lineart + depth，这里取决于要转换的视频风格选不同的预处理方式，一般真人转动漫的情况下。使用lineart + openpose控制上可能更好一些。  3. 将关键帧经过controlnet的转换成38组图片。

  4. 每组图片经过animatediff处理成8帧每秒的视频，进行补帧。

  5. 出图尺寸一般收本地显存影响，都选取了短边512（1080p的视频缩短到512 x 901左右）的规则，所以在视频合成之前对视频再进行一次放大处理（恢复1080p）。

  6. 视频合成，恢复到30fps的视频。

二、已有产品Tonic：Tonic是一个视频转视频生成工具+短视频分享平台。类似AI视频版本的抖音快手。

Domoai：最近新起的discord上的应用，支持视频转视频，图转视频和文生图功能。
