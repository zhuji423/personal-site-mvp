1、可视化import torchimport numpy as npimport matplotlib.pyplot as pltfrom pathlib import Pathimport torchvision.transforms.functional as Fdef show(imgs):    if not isinstance(imgs, list):        imgs = [imgs]    fig, axs = plt.subplots(ncols=len(imgs), squeeze=False)    for i, img in enumerate(imgs):        img = img.detach()        img = F.to_pil_image(img)        axs[0, i].imshow(np.asarray(img))        axs[0, i].set(xticklabels=[], yticklabels=[], xticks=[], yticks=[])2、关键点检测from torchvision.models.detection import keypointrcnn_resnet50_fpn, KeypointRCNN_ResNet50_FPN_Weightsfrom torchvision.io import read_imageperson_int = read_image(str(Path("data") / "person1.jpg"))weights = KeypointRCNN_ResNet50_FPN_Weights.DEFAULTtransforms = weights.transforms()model = keypointrcnn_resnet50_fpn(weights=weights, progress=False)model = model.eval()person_float = transforms(person_int)outputs = model([person_float])print(outputs)输出列表的长度为batch_size。列表中的每个条目对应于一个输入图像，它是一个包含键box、labels、Scores、keypoint和keypoint_scores的字典。在上面的例子中，图像中检测到 2 个实例。

kpts = outputs[0]['keypoints']scores = outputs[0]['scores']print(kpts)print(scores)设置阈值0.75，过滤掉人物对应的关键点。

detect_threshold = 0.75idx = torch.where(scores > detect_threshold)keypoints = kpts[idx]print(keypoints)每个关键点由 x、y 坐标和可见性表示。可以使用draw_keypoints()函数来绘制关键点。注意，需要 uint8 图像。

from torchvision.utils import draw_keypointsres = draw_keypoints(person_int, keypoints, colors="blue", radius=3)show(res)

可以使用连接参数轻松连接关键点。按以下顺序连接点来构建人体骨骼，这对于创建姿势检测或动作识别特别有用。

鼻子 -> 左眼 -> 左耳。(0, 1), (1, 3)鼻子 -> 右眼 -> 右耳。(0, 2), (2, 4)鼻子 -> 左肩 -> 左肘 -> 左手腕。(0, 5), (5, 7), (7, 9)鼻子 -> 右肩 -> 右肘 -> 右手腕。(0, 6), (6, 8), (8, 10)左肩 -> 左髋 -> 左膝 -> 左脚踝。(5, 11), (11, 13), (13, 15)右肩 -> 右髋 -> 右膝 -> 右脚踝。(6, 12), (12, 14), (14, 16)创建一个包含这些要连接的关键点 ID 的列表。

connect_skeleton = [    (0, 1), (0, 2), (1, 3), (2, 4), (0, 5), (0, 6), (5, 7), (6, 8),    (7, 9), (8, 10), (5, 11), (6, 12), (11, 13), (12, 14), (13, 15), (14, 16)]连接关键点。
