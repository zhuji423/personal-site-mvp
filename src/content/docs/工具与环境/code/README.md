"以下是通过ITP平台OpenAPI接口创建case的详细示例：\n\n## 创建Case的API接口\n\n### 1. 基础创建接口\n```http\nPOST itp/node/api/{type}\nContent-Type: application/json\n```\n\n**路径参数：**\n- `type`: 节点类型，可选值：`case`、`setup`、`teardown`\n\n**请求体参数：**\n```json\n{\n    \"parentId\": 12345,        // 必填，case所在的suite节点id\n    \"name\": \"测试用例\",        // 选填，case名称，默认为\"Case\"\n    \"source\": 1,              // 必填，case来源：1:iturbo, 2:报表平台, 3:bat, 4:nmtest, 5:sat\n    \"owner\": \"username\",      // 必填，case创建人\n    \"status\": 0,              // 选填，case启停状态：0启用 1暂停，默认0\n    \"readOnly\": 1             // 选填，是否只读，默认1\n}\n```\n\n### 2. CASE操作配置示例\n以下是包含详细operation配置的完整示例：\n\n```json\n{\n    \"parentId\": 12345,\n    \"name\": \"用户信息查询接口测试\",\n    \"source\": 1,\n    \"owner\": \"zhangsan\",\n    \"status\": 0,\n    \"operation\":[\n        {\n            \"type\": \"api\",\n            \"text\": \"获取用户信息\",\n            \"url\": \"/api/user/info\",\n            \"protocol\": \"http\",\n            \"method\": \"GET\",\n            \"params\": \"userId=test001\",\n            \"loginId\": 0,\n            \"header\": \"Content-Type: application/json\",\n            \"bodyType\": 2,\n            \"body\": \"{}\",\n            \"assertExpect\": 0,\n            \"assertExpectMap\": 0,\n            \"expectResponseMap\": \"[{\\\"key\\\":\\\"status\\\",\\\"value\\\":\\\"0\\\"},{\\\"key\\\":\\\"data.userId\\\",\\\"value\\\":\\\"test001\\\"}]\",\n            \"assertHeader\": 1,\n            \"expectHeader\": \"\"\n        }\n    ]\n}\n```\n\n### 3. 成功响应示例\n```json\n{\n    \"message\": \"success\",\n    \"status\": 0,\n    \"data\": {\n        \"caseId\": 2352717\n    }\n}\n```\n\n### 4. 关键参数说明\n\n**Operation配置说明：**\n- `bodyType`: 1 form-data, 2 raw-json, 3 soap, 4 ProtoBuf, 5 raw-text\n- `assertExpect`: 0有完全匹配断言, 1没有\n- `assertExpectMap`: 0有键值匹配断言, 1没有\n- `expectResponseMap`: 键值匹配预期，JSON数组格式\n\n**断言配置示例：**\n- 键值匹配断言：`[{\"key\":\"result\",\"value\":\"\\\"0\\\"\"}]`\n- JSON Schema校验：支持`expectJsonSchema`参数\n\n建议先通过`GET itp/node/api/trees?productId={productId}`接口获取suite节点ID，再使用上述API创建case。
