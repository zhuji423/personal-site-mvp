Mac Outlook配置邮箱

**Outlook为百度桌面标准软件****，****以下为Outlook 2019 for Mac配置方法，邮箱类型选择****Exchange**

**此文档仅适合配置专用邮箱和个人邮箱，****配置邮件组代发请参考**[邮件组代发](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/HXFtYvbMQj/y1yW8zs4WV/531H2t6fBDrk5X?t=mention&mt=doc&dt=doc)

### 1、点击进入Outlook程序，点击【工具】→【账户】，点击左下角➕添加账户
![](/personal-site-mvp/img/doc-placeholder.svg "")
![](/personal-site-mvp/img/doc-placeholder.svg "")
### 2、输入电子邮件地址
![](/personal-site-mvp/img/doc-placeholder.svg "")
### 3、填写邮箱信息，点击添加账户即可。
例如：zhangsan@baidu.com

          域\用户名：internal\(邮箱前缀)，

          密码：（邮箱密码）

          服务器地址：email.baidu.com

![](/personal-site-mvp/img/doc-placeholder.svg "")
